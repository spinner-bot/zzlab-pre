# D2 学习文档：井字棋强化学习智能体（Q-Learning）

## 1. 任务
用**强化学习（不借助任何现成强化学习第三方库）**实现井字棋智能体：棋盘环境构建、合法落子判断、胜负判断、奖励设计；训练优化落子策略，并给出训练曲线与可复现 demo。

## 2. 工程结构
```
Software_D2/
├── game.py    井字棋环境：棋盘、合法动作、胜负判定、奖励
├── train.py   Q-Learning 智能体 + AI vs AI 训练
├── main.py    Pygame 人机对战 + 学习曲线绘图 + 冻结/解冻控制
└── 学习文档.md
```

## 3. 核心设计
- **状态表示**：3×3 棋盘展平为字符串（0 空 / 1 X / -1 O）作 Q 表 key。
- **动作**：落子位置展平下标 `row*3+col`。
- **Q-Learning**：`Q(s,a) += lr*(reward - Q(s,a))`，n 步折扣回报 `reward*γ^i`。
- **探索/利用**：`ε-greedy`，训练中 ε 衰减；`freeze()` 冻结后 ε=0 纯利用（测试/部署）。
- **奖励**：赢=1、输=-1、平=0。

## 4. 修复的问题
1. **Q 表动作索引类型错误**：用元组 `(r,c)` 索引 list 崩溃，统一改为展平整数下标。
2. **人机对战 AI 先手死锁**：AI 执 X 先手却无触发，抽出 `ai_move()` 处理开局/每步/重开。
3. **Pygame SysFont 崩溃**：Python3.13 下系统字体枚举报错，改用内置字体 `Font(None)` + 中文字体加载器。
4. **模型路径**：锚定脚本目录，支持任意 cwd 启动；缺失时自动训练。

## 5. 运行
```bash
cd Software_D2
D:\Anaconda\python.exe main.py   # 菜单：1训练/2对战/3画曲线/4冻结切换
```

## 6. 结果
AI vs AI 训练后，Agent_X 胜率显著上升（滚动窗口 X/O/平 ≈ 49%/30%/21%），冻结后能以纯利用策略完成对局。
