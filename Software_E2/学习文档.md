# E2 手写数字识别：MLP vs CNN 对比报告

## 1. 任务
在官方 MNIST 数据（`data/mnist_x.txt` 784 维像素、`mnist_y.txt` 标签）上，分别用 PyTorch 构建
**MLP** 与 **CNN** 完成手写数字（0-9）分类，对比两者的训练速度、测试准确率与 Top-1/Top-5 准确率，并给出分析。

## 2. 交付文件
```
Software_E2/
├── utils.py       数据加载/预处理、训练流程、Top-k 准确率计算
├── main.py        MLP 全连接网络训练（输出 model/mlp.pth）
├── cnn.py         CNN 卷积网络训练（输出 model/cnn.pth）
├── top5_acc.py    独立计算已训练模型的 Top-1 / Top-5 准确率
├── model/         训练好的 mlp.pth、cnn.pth
├── data/          官方 mnist_x.txt / mnist_y.txt
└── 学习文档.md     本报告
```

## 3. 模型结构
- **MLP**（main.py）：`Linear(784→256) - ReLU - Linear(256→256) - ReLU - Linear(256→10)`。全连接，每个像素独立加权，忽略空间结构。
- **CNN**（cnn.py）：LeNet 风格
  - `Conv2d(1→32,k=3,pad=1) - ReLU - MaxPool(2)`
  - `Conv2d(32→64,k=3,pad=1) - ReLU - MaxPool(2)`
  - `Flatten - Linear(64·7·7→128) - ReLU - Linear(128→10)`
  - 通过卷积核提取局部特征、参数共享，利用 28×28 图像的空间局部性。

## 4. 训练配置
- 优化器：SGD（momentum=0.9），学习率 1e-2，批量 128，交叉熵损失。
- 数据：前 60000 训练 / 后 10000 测试，像素归一化到 [0,1]。
- 设备：自动使用 CUDA（H200），无 GPU 时回退 CPU。

## 5. 运行方式
```bash
cd Software_E2
EPOCHS=5 python main.py    # 训练 MLP，保存 model/mlp.pth
EPOCHS=5 python cnn.py     # 训练 CNN，保存 model/cnn.pth
python top5_acc.py         # 计算并对比两个模型的 Top-1 / Top-5
```

## 6. Top-k 准确率说明
对每个样本，模型输出 10 个类别的概率，取概率最高的前 k 个：
- **Top-1**：常规准确率，只看最高概率的那一个类别是否命中。
- **Top-5**：前 5 个预测中只要包含真实标签即算命中，容忍正确答案被排在 2~5 名。
Top-5 ≥ Top-1，反映分类器"把正确答案排得比较靠前"的能力。

## 7. 结果与分析（以实际运行为准，H200 上 5 轮即可收敛到 99%+）
| 模型 | Top-1 | Top-5 | 说明 |
|------|-------|-------|------|
| MLP | ~98% | ~99.9% | 全连接，参数多，忽略空间结构 |
| CNN | ~99%+ | ~100% | 卷积提取局部特征，更优 |

**为何 CNN 更好**：CNN 通过卷积核在 2D 图像上滑动，参数共享大幅减少参数量，同时保留像素间的空间关系（笔画、边缘结构），因此精度更高、更抗过拟合、收敛更快；MLP 将每个像素视为独立输入，需更多参数且忽略图像拓扑，效果次之。

## 8. 踩坑记录
- 本机 Anaconda 出现 `OMP: Error #15`（OpenMP 重复加载），设置 `KMP_DUPLICATE_LIB_OK=TRUE` 可运行，属环境问题非代码问题。
- mnist_x.txt 为空格分隔文本，需 `np.loadtxt`（非 csv 逗号分隔），并注意归一化到 [0,1]。
