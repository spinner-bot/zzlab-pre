🐍 Python → ⚙️ C++ 面向对象编程迁移指南

用你熟悉的 Python 知识来理解 C++ 的面向对象写法

1. 思维切换：最核心的差异

维度PythonC++
类型系统动态类型，运行时确定静态类型，编译时必须声明所有类型
编译/解释解释执行先编译成二进制，再执行
内存管理垃圾回收 (GC)，自动手动管理（new/delete），或借助 RAII
文件组织.py 单文件头文件 (.h) 声明 + 源文件 (.cpp) 实现
所有东西一切皆对象基本类型（int, double）不是对象
访问控制约定（_ 前缀）关键字 public / private / protected
关键心理模型：在 C++ 中，你写给编译器看的东西远比 Python 多。Python 省略的类型声明、访问控制，C++ 都要求你显式写出。

2. 类的定义

🐍 Python
class Dog:
    def __init__(self, name, age):
        self.name = name
        self.age = age

    def bark(self):
        print(f"{self.name} says woof!")
⚙️ C++
// --- 头文件 dog.h ---
#include <string>

class Dog {
private:              // 访问控制关键字！
    std::string name;   // 必须声明类型
    int age;

public:
    Dog(std::string n, int a);  // 构造函数
    void bark();                 // 方法声明
};

// --- 源文件 dog.cpp ---
#include "dog.h"
#include <iostream>

Dog::Dog(std::string n, int a) {   // Dog:: 表示属于 Dog 类
    name = n;
    age = a;
}

void Dog::bark() {
    std::cout << name << " says woof!" << std::endl;
}
对照要点： ① self.xxx → 直接写成员名 xxx，C++ 编译器自动知道你在访问成员
② C++ 方法实现写在类外时，需要用 类名::方法名
③ 成员变量必须在类体中先声明类型
④ C++ 语句以分号 ; 结尾，类定义的大括号后面也要加分号

3. 构造函数

🐍 Python
class Person:
    def __init__(self, name="Unknown"):
        self.name = name

p1 = Person("Alice")
p2 = Person()  # 默认值
⚙️ C++
class Person {
public:
    // 构造函数（与类同名，无返回类型）
    Person(std::string name = "Unknown") {
        // 推荐用初始化列表：
    }
    // 或更推荐的写法 —— 初始化列表
    Person(std::string name = "Unknown")
        : name(name) { }  // ← 冒号后面是初始化列表
private:
    std::string name;
};

Person p1("Alice");
Person p2;        // 默认值 "Unknown"
// C++ 也可以：
Person p3{};      // C++11 统一初始化
对照： __init__ → 与类同名的函数就是构造函数，没有返回类型。
__init__ 的默认参数 → C++ 构造函数也支持默认参数，语法一样。
初始化列表（: name(name)）是 C++ 推荐写法，比在函数体里赋值更高效。

4. 访问控制：public / private / protected

🐍 Python — 全靠约定
class Bank:
    def __init__(self):
        self.balance = 0       # 公开的
        self._secret   = 42     # "请别碰"
        self.__hidden  = 99    # 名称改编，更难访问
⚙️ C++ — 编译器强制执行
class Bank {
private:              // 只有类内部能访问
    double balance;
    int secret;

protected:            // 子类也能访问
    int protected_data;

public:               // 谁都能访问
    void deposit(double amount) {
        balance += amount;  // ✓ 类内可访问 private
    }
};

// 外部：
Bank b;
b.deposit(100);       // ✓ public 方法
b.balance;             // ✗ 编译错误！private
快速记忆：先把所有成员变量放在 private，对外提供的方法放在 public。protected 初学阶段很少用到。

5. 继承

🐍 Python
class Animal:
    def __init__(self, name):
        self.name = name

    def speak(self):
        pass

class Cat(Animal):           # 继承
    def __init__(self, name, color):
        super().__init__(name)  # 调父类
        self.color = color

    def speak(self):
        print("Meow!")
⚙️ C++
class Animal {
protected:               // 子类可访问
    std::string name;
public:
    Animal(std::string n) : name(n) { }
    virtual void speak() { }  // virtual = 可被重写
};

//        ↓ 继承方式（通常用 public）
class Cat : public Animal {
private:
    std::string color;
public:
    Cat(std::string n, std::string c)
        : Animal(n), color(c) { }  // 调父类构造

    void speak() override {   // override = 明确重写
        std::cout << "Meow!" << std::endl;
    }
};
对照： ① Python class Cat(Animal) → C++ class Cat : public Animal（多了个 public 继承方式）
② Python super().__init__() → C++ 在初始化列表中直接写父类名 : Animal(n)
③ C++ 中只有声明为 virtual 的方法才能被子类重写（这是 Python 没有的概念！）
④ override 关键字可选但强烈推荐 —— 编译器会帮你检查是否真的重写了父类方法
⚠️ 关键区别：Python 所有方法默认都是"虚的"（可重写），C++ 必须显式标记 virtual。如果你忘了写 virtual，通过父类指针调用方法时不会调用子类版本！

6. 多态：virtual 与纯虚函数（= 抽象类）

🐍 Python — abc 抽象基类
from abc import ABC, abstractmethod

class Shape(ABC):
    @abstractmethod
    def area(self):
        pass

class Circle(Shape):
    def area(self):
        return 3.14 * self.r ** 2
⚙️ C++ — 纯虚函数
class Shape {          // 抽象类
public:
    virtual double area() = 0;  // = 0 → 纯虚函数
    virtual ~Shape() { }       // 虚析构（见第9节）
};

class Circle : public Shape {
public:
    double area() override {
        return 3.14 * r * r;
    }
};

// Shape s;  ← 编译错误！抽象类不能实例化
快速记忆：Python 的 @abstractmethod ≈ C++ 的 virtual ... = 0;（纯虚函数）。有纯虚函数的类就是抽象类，不能直接实例化。

7. 静态成员 & 类方法

🐍 Python
class Math:
    PI = 3.14159          # 类变量

    @staticmethod
    def add(a, b):
        return a + b

    @classmethod
    def info(cls):
        return cls.PI
⚙️ C++
class Math {
public:
    static constexpr double PI = 3.14159;

    static int add(int a, int b) {
        return a + b;
    }

    static double info() {
        return PI;
    }
};

// 调用方式一样：
Math::add(3, 4);     // 类名::静态方法
Math::PI;            // 类名::静态变量
对照：Python @staticmethod 和 @classmethod → C++ 统一用 static 关键字。C++ 没有 cls 参数的概念，静态方法内只能访问静态成员。

8. 运算符重载

🐍 Python — dunder methods
class Vector:
    def __init__(self, x, y):
        self.x = x; self.y = y

    def __add__(self, other):
        return Vector(self.x+other.x,
                      self.y+other.y)

    def __str__(self):
        return f"({self.x},{self.y})"
⚙️ C++ — operator 关键字
class Vector {
public:
    double x, y;
    Vector(double x, double y) : x(x), y(y) { }

    Vector operator+(const Vector& other) const {
        return Vector(x + other.x, y + other.y);
    }

    friend std::ostream& operator<<(
        std::ostream& os, const Vector& v) {
        os << "(" << v.x << "," << v.y << ")";
        return os;
    }
};
对照： Python __add__ → C++ operator+
Python __str__ → C++ 重载 operator<<（输出流，最常用）
Python __eq__ → C++ operator==
规律：C++ 就是 operator + 符号

9. 析构函数（Python __del__ 的对照）

🐍 Python
class Resource:
    def __init__(self):
        print("acquired")

    def __del__(self):
        print("released")

# __del__ 调用时机不确定（GC决定）
⚙️ C++
class Resource {
public:
    Resource()  { std::cout << "acquired"; }
    ~Resource() { std::cout << "released"; }
    // ↑ 析构函数：~类名()，无参数无返回
};

// 析构时机确定：
{
    Resource r;  // 构造
}                // r 离开作用域 → 析构自动调用！
⚠️ 关键：C++ 的析构函数是确定的 —— 对象离开作用域立刻调用。这是 C++ 的 RAII（资源获取即初始化）机制的基础，也是 C++ 不需要 with 语句来管理资源的原因。另外，如果类可能被继承，析构函数要写 virtual ~ClassName() { }。

12. 一个完整类：边看边比

🐍 Python — 学生成绩管理
class Student:
    def __init__(self, name, id):
        self.name = name
        self.id = id
        self._scores = []

    def add_score(self, s):
        self._scores.append(s)

    def average(self):
        if not self._scores:
            return 0.0
        return sum(self._scores) \
               / len(self._scores)

    def __str__(self):
        return f"{self.name}({self.id}):\
                {self.average():.1f}"

s = Student("Alice", "001")
s.add_score(85)
s.add_score(92)
print(s)
⚙️ C++ — 学生成绩管理
// student.h
#pragma once
#include <string>
#include <vector>
#include <iostream>

class Student {
private:
    std::string name;
    std::string id;
    std::vector<int> scores;      // 类似 list

public:
    Student(std::string n, std::string i)
        : name(n), id(i) { }

    void add_score(int s) {
        scores.push_back(s);        // ≈ append
    }

    double average() const {
        if (scores.empty()) return 0.0;
        double sum = 0;
        for (int s : scores) sum += s;
        return sum / scores.size();
    }

    friend std::ostream&
        operator<<(std::ostream& os,
                    const Student& s) {
        os << s.name << "(" << s.id
           << "): " << s.average();
        return os;
    }
};

// main.cpp 中使用：
Student s("Alice", "001");
s.add_score(85);
s.add_score(92);
std::cout << s << std::endl;
🎯 起步建议：刚开始写 C++ 时，先把所有代码写在一个 .cpp 文件里（不分头文件），等熟悉语法后再拆分 .h / .cpp。这样心理负担小很多。
