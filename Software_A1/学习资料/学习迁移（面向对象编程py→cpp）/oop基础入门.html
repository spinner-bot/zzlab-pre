🧱 面向对象编程（OOP）基础入门

用最朴素的方式理解 OOP —— 不跳跃，不假设你"已经懂了"

1. 为什么要"面向对象"？

假设你写一个学生成绩管理系统。没有 OOP 时，你可能会这样写：

# 用"散装变量"管理数据
student1_name = "Alice"
student1_id   = "001"
student1_score1 = 85
student1_score2 = 92

student2_name = "Bob"
student2_id   = "002"
student2_score1 = 73
student2_score2 = 88

# 你要算平均分？自己写：
def average(scores):
    return sum(scores) / len(scores)

print(average([student1_score1, student1_score2]))  # 每次都要手动拼

问题很明显：数据和操作数据的逻辑是分离的。一旦学生多了、字段多了，代码就变成一团乱麻。

🏭 类比：工厂 vs 手工作坊
手工作坊：每个产品（学生）的数据散落在各处，工人（函数）要自己去找材料。
工厂流水线：每个产品自带说明书（类），机器（方法）知道怎么加工它，数据和处理逻辑打包在一起。

OOP 的核心思想就一句话：把数据和处理数据的方法绑定在一起，形成一个"对象"。

2. 类（Class）和对象（Object）—— 蓝图和房子

📐 类比：建筑图纸 vs 实际的房子
类（Class） = 建筑图纸。它描述了"这个房子有什么属性（几室几厅）和什么功能（门怎么开）"，但你不能住进图纸里。
对象（Object） = 照图纸盖出来的真实房子。你可以住进去，每个房子可以有不同的装修、住不同的人。 
class Student:                    # ← 这是"图纸"（类）
    pass

s1 = Student()                      # ← 这是"房子"（对象/实例）
s2 = Student()                      # ← 又一栋房子

print(type(s1))                   # <class '__main__.Student'>
print(s1 is s2)                    # False —— 两栋不同的房子
术语："实例"（instance）就是"对象"的同义词。s1 = Student() 可以读作"用 Student 图纸创建了一个实例 s1"。

3. 属性（Attribute）—— 对象"有什么"

属性就是属于某个对象的数据。每个对象可以有自己的属性值。

class Student:
    pass

s1 = Student()
s1.name = "Alice"      # 动态添加属性（只有 Python 能这么干）
s1.age  = 20

s2 = Student()
s2.name = "Bob"        # s2 有自己的 name
s2.age  = 22

print(s1.name)          # Alice
print(s2.name)          # Bob

但这种"事后贴标签"的方式容易出错。正确的做法是用 __init__ 在创建对象时自动初始化属性——这就引出了下一节。

4. __init__ —— 对象的"出生设置"

__init__ 是一个特殊方法，在对象被创建时自动运行。你可以把它理解为"出厂配置"。

🏗️ 类比：房子盖好那一刻，自动通水通电——你不需要手动去拧阀门。__init__ 就是对象创建时自动执行的初始化工作。 
class Student:
    def __init__(self, name, age):   # self 见第5节
        self.name = name           # 把参数 name 存到对象的 name 属性
        self.age  = age
        self.scores = []           # 不需要从外部传入，直接初始化

s1 = Student("Alice", 20)          # __init__ 自动被调用
s2 = Student("Bob", 22)

print(s1.name, s1.age, s1.scores) # Alice 20 []
关键理解：__init__ 的工作就是把"外部传入的值"保存到"对象自己的属性"里。你传了 "Alice"，它就帮你设置 self.name = "Alice"。

5. self —— "我自己"

这是初学者最容易困惑的地方。简单说：self 就是"当前这个对象本身"。

class Student:
    def __init__(self, name):
        self.name = name       # self 指"正在被创建的那个对象"

    def introduce(self):
        # self 指"调用这个方法的那个对象"
        print(f"我叫{self.name}")

s1 = Student("Alice")
s1.introduce()             # 等价于 Student.introduce(s1)

s2 = Student("Bob")
s2.introduce()             # 等价于 Student.introduce(s2)
一步步拆解 s1.introduce()：
① Python 看到你调用了 s1 的方法
② Python 自动把 s1 作为第一个参数传给方法 → 这就是 self 的值
③ 方法内部的 self.name 实际上就是 s1.name
所以 def introduce(self) 定义时写 self，调用时却不需要传——Python 帮你自动传了。

6. 方法（Method）—— 对象"能做什么"

方法就是定义在类里面的函数，专门用来操作对象的属性。它和普通函数的唯一区别：第一个参数必须是 self。

class Student:
    def __init__(self, name):
        self.name = name
        self.scores = []

    def add_score(self, score):        # 方法：操作对象自己的数据
        self.scores.append(score)       # self.scores → 这个对象的 scores

    def average(self):                # 方法：基于自己的数据计算结果
        if not self.scores:
            return 0
        return sum(self.scores) / len(self.scores)

s = Student("Alice")
s.add_score(85)                     # 数据和处理逻辑在一起
s.add_score(92)
print(s.average())                # 88.5   —— 不用手动传 scores 列表
对比普通函数：普通函数要你把数据作为参数传进去；方法是数据已经在对象里了（通过 self），你只需要告诉它"做什么"。

7. 封装（Encapsulation）—— "别乱动我的东西"

封装的意思是：把数据藏起来，只暴露必要的操作接口。这样外部代码就不能随意破坏对象内部状态。

class BankAccount:
    def __init__(self, owner):
        self.owner = owner
        self._balance = 0            # 单下划线：约定"请勿直接访问"

    def deposit(self, amount):        # 公开方法：正确的操作入口
        if amount > 0:
            self._balance += amount

    def get_balance(self):
        return self._balance

acc = BankAccount("Han")
acc.deposit(100)                    # ✓ 通过方法修改
print(acc.get_balance())            # ✓ 通过方法读取

# acc._balance = -9999  ← 技术上能写，但别人知道这违反约定
🔒 类比：银行不会让你直接进金库改余额——你必须通过柜台（公开方法）存钱/取钱。柜台会检查：金额不能为负、不能超额取款……这些校验逻辑就是封装的价值。
Python 的做法：Python 没有真正的 private，靠命名约定——_xxx（单下划线）表示"这是内部的东西，别碰"，__xxx（双下划线）会触发名称改编让外部更难访问。但这是"君子协定"，不是编译器强制。

8. 继承（Inheritance）—— "我继承了你的东西，还能加自己的"

继承让你基于已有的类创建新类，复用代码，同时添加或修改功能。

🧬 类比：你爸会修自行车。你继承了这个技能（不用从头学），但你还会修电动车（这就是你扩展的部分）。 
class Animal:                        # 父类（基类）
    def __init__(self, name):
        self.name = name

    def eat(self):
        print(f"{self.name} 在吃东西")

class Dog(Animal):                   # 子类：继承 Animal
    def bark(self):                 # 子类新增的方法
        print(f"{self.name} 汪汪叫!")

class Cat(Animal):                   # 另一个子类
    def eat(self):                 # 重写父类方法：猫吃东西的方式不同
        print(f"{self.name} 在优雅地吃猫粮")

d = Dog("旺财")
d.eat()                             # 继承自 Animal  → "旺财 在吃东西"
d.bark()                            # Dog 自己的方法 → "旺财 汪汪叫!"

c = Cat("咪咪")
c.eat()                             # Cat 重写后的  → "咪咪 在优雅地吃猫粮"
什么时候用继承？只有当"B 是 A 的一种"时。狗是动物 ✓，猫是动物 ✓。如果仅仅是"B 用到 A 的某个功能"，那应该用"组合"（把 A 的对象作为 B 的属性），而不是继承。

9. 多态（Polymorphism）—— "同一个指令，不同对象做不同的事"

多态的意思是：不同的类可以有同名方法，调用时自动选择正确的版本。

class Dog:
    def speak(self):
        return "汪汪"

class Cat:
    def speak(self):
        return "喵喵"

class Duck:
    def speak(self):
        return "嘎嘎"

# 多态的核心：不关心具体是什么类，只管调用 speak()
def make_sound(animal):
    print(animal.speak())

make_sound(Dog())     # 汪汪
make_sound(Cat())     # 喵喵
make_sound(Duck())    # 嘎嘎
🔌 类比：USB 接口。电脑不知道你插的是鼠标还是键盘还是 U 盘——它只管"插上"这个动作。每个设备自己知道插上后该干什么。多态让代码可以对不同类型统一操作，而不用写一堆 if/else。
Python 的鸭子类型：Python 不需要继承同一个父类就能实现多态。只要你这个类有 speak() 方法，就能传给 make_sound()。这就是"如果它走路像鸭子、叫起来像鸭子，那它就是鸭子"。

10. 静态方法 & 类方法 —— "不是每个方法都需要 self"

有些方法不需要访问对象的数据，它只是一个放在类里的工具函数。

class MathHelper:
    PI = 3.14159                         # 类变量：所有对象共享

    @staticmethod                      # 静态方法：不需要 self
    def add(a, b):                     # 就是一个普通的工具函数
        return a + b                    # 不能访问 self.xxx

    @classmethod                       # 类方法：第一个参数是类本身
    def get_pi(cls):                   # cls 是 MathHelper 这个类
        return cls.PI                     # 可以访问类变量

print(MathHelper.add(3, 5))         # 8    —— 不需要创建对象就能调用
print(MathHelper.get_pi())           # 3.14159
什么时候用？
• @staticmethod：方法逻辑上和类相关，但不需要访问对象的任何数据。比如数学计算。
• @classmethod：需要访问类级别的变量，或者用来创建"替代构造函数"（比如 from_string() 从字符串创建对象）。
• 普通方法（有 self）：最常用，操作具体对象的数据。

11. 特殊方法（Dunder Methods）—— 让对象像内置类型一样好用

以双下划线开头和结尾的方法（所以叫 "dunder" = double underscore），让自定义对象支持 +、print()、len() 等操作。

class Vector:
    def __init__(self, x, y):
        self.x = x
        self.y = y

    def __add__(self, other):            # 定义 + 的行为
        return Vector(self.x + other.x,
                      self.y + other.y)

    def __str__(self):                 # 定义 print() 的输出
        return f"Vector({self.x}, {self.y})"

    def __len__(self):                 # 定义 len() 的返回值
        return 2  # 二维向量长度为2

v1 = Vector(1, 2)
v2 = Vector(3, 4)
v3 = v1 + v2                          # 实际调用 v1.__add__(v2)
print(v3)                           # 实际调用 v3.__str__()
print(len(v3))                       # 实际调用 v3.__len__()

常用特殊方法速查：

方法触发方式用途
__init__(self)创建对象时自动初始化属性
__str__(self)print(obj)给人看的字符串
__repr__(self)repr(obj)给开发者看的字符串（调试用）
__len__(self)len(obj)返回"长度"
__add__(self, o)obj + o加法运算
__eq__(self, o)obj == o相等比较
__lt__(self, o)obj < o小于比较（排序用）
__getitem__(self,k)obj[k]用方括号访问

12. 完整示例：把所有概念串起来

这是一个简单的"图书馆借书"系统，用到了上面所有概念：

class Book:
    def __init__(self, title, author):
        self.title = title              # 属性
        self.author = author
        self._is_borrowed = False      # 封装的内部状态

    def borrow(self):                    # 公开方法
        if self._is_borrowed:
            print(f"《{self.title}》已被借出")
            return False
        self._is_borrowed = True
        print(f"✓ 借到《{self.title}》")
        return True

    def return_book(self):
        self._is_borrowed = False
        print(f"✓ 归还《{self.title}》")

    def __str__(self):                 # 特殊方法
        status = "已借出" if self._is_borrowed else "可借"
        return f"《{self.title}》— {self.author} [{status}]"


class EBook(Book):                      # 继承 Book
    def __init__(self, title, author, file_size):
        super().__init__(title, author)    # 调用父类 __init__
        self.file_size = file_size        # 子类新增属性

    def __str__(self):                 # 重写父类方法
        base = super().__str__()         # 复用父类逻辑
        return f"{base} [电子书 {self.file_size}MB]"


# ===== 使用 =====
b1 = Book("三体", "刘慈欣")
b2 = EBook("流浪地球", "刘慈欣", 5)

print(b1)        # 《三体》— 刘慈欣 [可借]
print(b2)        # 《流浪地球》— 刘慈欣 [可借] [电子书 5MB]

b1.borrow()        # ✓ 借到《三体》
b1.borrow()        # 《三体》已被借出
print(b1)        # 《三体》— 刘慈欣 [已借出]
b1.return_book()   # ✓ 归还《三体》

13. 总结：OOP 的四个核心概念

概念 一句话 Python 实现
① 封装 把数据藏起来，暴露安全接口 _ 前缀约定 + 公开方法
② 继承 复用已有代码，添加新功能 class Child(Parent)
③ 多态 不同对象响应同一指令 同名方法 + 鸭子类型
④ 抽象 隐藏复杂细节，只暴露接口 ABC + @abstractmethod
🎯 建议的学习路径：
第一步：反复写 class Xxx: def __init__(self, ...):，直到"self 是什么"不再困惑。
第二步：练习封装——所有属性用 _ 前缀，用方法读写。
第三步：练习继承——找一个合适的"A 是 B 的一种"关系来写。
第四步：回头看多态和特殊方法。
关键在于：写代码，别光看。
