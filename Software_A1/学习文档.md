# A1 学习文档：C++ 有理数类 Rational

## 1. 任务
用 C++ 设计 `Rational` 有理数类，支持**分数的化简（约分）、加/减/乘/除四则运算、规范化输出**，并体现**封装、构造函数重载、数据安全性**。

## 2. 实现要点（`有理数类.cpp`）
- **数据成员私有**（`int num` 分子、`int den` 分母），体现封装，外部只能通过公有接口访问。
- **构造函数重载**：`Rational()` 默认 0、`Rational(int n)` 整数、`Rational(int n, int d)` 分数，构造时自动约分。
- **约分 `simplify()`**：用**辗转相除法**求最大公约数约分，并保证分母恒为正（符号归一到分子）。
- **四则运算重载**：`operator+ - * /`，均为 `const` 成员函数（不修改对象），返回最简新对象。
- **规范化输出**：友元 `operator<<`，分母为 1 时只输出分子，否则输出 `分子/分母`。
- **数据安全性**：分母为 0 或除以 0 时抛 `invalid_argument` 异常，杜绝非法对象状态。

## 3. 关键代码片段
```cpp
void simplify() {
    if (den < 0) { num = -num; den = -den; }   // 符号归一
    int g = gcd(num, den);
    num /= g; den /= g;
}
Rational operator+(const Rational& r) const {
    return Rational(num*r.den + r.num*den, den*r.den);
}
```

## 4. 踩坑记录
- 除零/分母零必须显式抛异常，否则对象处于非法状态、后续运算出错。
- 约分前先处理符号，保证分母为正，输出才规范。
- 运算符重载若不加 `const`，无法在常量对象上调用。

## 5. 运行
```bash
# 需 C++ 编译器，如 g++ 有理数类.cpp -o rational && ./rational
```
测试：`1/2 + 1/3 = 5/6`、`1/2 / 1/3 = 3/2`、`2/-4 自动约分为 -1/2`。
