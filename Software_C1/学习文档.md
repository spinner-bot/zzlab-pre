# C1 学习文档：OpenCV 基础图像处理 + 人脸检测实时模糊

## 1. 任务
掌握 OpenCV 基础，用 Python 实现：图像加载与裁剪、对比度/亮度增强、高斯模糊；并在此基础上**检测人脸并对人脸区域自动模糊**（含实时摄像头版）。

## 2. 交付文件
```
Software_C1/
├── cv_basics.py     独立脚本（含注释）
├── test_input.jpg   演示输入图（社区人员照片，检测到 1 个人脸）
├── output/          处理前后效果截图

│   ├── 3_brightness_contrast.png   亮度+对比度增强
│   ├── 4_gaussian_blur.png         整图高斯模糊
│   └── 5_face_blur.png             仅人脸区域模糊
└── 学习文档.md      本文档
```

## 3. 实现要点与常用函数（`cv_basics.py`）
- **加载/保存（兼容中文路径）**：`np.fromfile(path) -> cv2.imdecode`；`cv2.imencode -> buf.tofile`。Windows 上 `cv2.imread` 读不了含中文路径，这是常用解法。
- **裁剪**：`img[y0:y1, x0:x1]`（注意 OpenCV 是 (x=列, y=行)）。
- **亮度/对比度增强**：`cv2.convertScaleAbs(img, alpha, beta)`，`dst = saturate(alpha·src + beta)`，`alpha>1` 提对比度、`beta>0` 提亮度。
- **高斯模糊**：`cv2.GaussianBlur(img, ksize, sigmaX)`，核越大越模糊。
- **人脸检测**：OpenCV 自带 Haar 级联 `haarcascade_frontalface_default.xml`（`cv2.data.haarcascades`），`detectMultiScale(gray, scaleFactor=1.1, minNeighbors=5)` 返回 `(x,y,w,h)`。
- **人脸区域模糊**：对每个检测框 ROI 单独 `GaussianBlur` 再贴回，实现"只糊脸、不糊背景"。

## 4. 运行
```bash
cd Software_C1
D:\Anaconda\python.exe cv_basics.py test_input.jpg   # 处理单张图，输出到 output/
D:\Anaconda\python.exe cv_basics.py --realtime       # 打开摄像头，实时人脸模糊，q 退出
```

## 5. 效果验证
- 输出 `5_face_blur.png` 中，人脸区域像素与原图差异均值 **56.78**（重度模糊），而背景区域差异仅 **0.05**（几乎不变）→ 精准只模糊人脸。
- 检测到 1 个人脸（`[727,409,29,29]`）。

## 6. 踩坑记录
- Windows + 中文路径：`cv2.imread`/`cv2.imwrite` 会失败，需用 `imdecode/fromfile`、`imencode/tofile`。
- Haar 级联对小脸或角度大的脸检测率有限，`minNeighbors` 调低可提高召回但会引入误检，需权衡。
