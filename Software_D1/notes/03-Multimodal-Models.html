第一章 · 奠基与探索期（2020–2022）

📐 时代特征

"模态独立处理" — 各模型在单一模态任务上取得突破，但模型间相互独立，缺乏深度融合。

1.1 🏛️ ViT (Vision Transformer) — 打破架构壁垒

📄 An Image is Worth 16x16 Words — Google, Oct 2020. ICLR 2021

作者: Alexey Dosovitskiy 等 | 引用: 50,000+

在 ViT 之前，计算机视觉由 CNN（卷积神经网络）统治了整整十年。ViT 做了一个激进的事情：把图像切成固定大小的 patch，像处理文本 token 一样喂给纯 Transformer。这个看似简单的改变证明了 Transformer 在视觉任务上比 CNN 更有效——只要数据够多。

# ViT 的核心思想（伪代码）
class VisionTransformer(nn.Module):
    def forward(self, image):  # image: [B, 3, 224, 224]
        # 1. 将图像切成 16×16 的 patches
        patches = rearrange(image, 'b c (h p1) (w p2) -> b (h w) (c p1 p2)',
                           p1=16, p2=16)  # → [B, 196, 768]

        # 2. 线性投影 + 位置编码 → 变成 "visual tokens"
        tokens = self.patch_embed(patches) + self.pos_embed
        tokens = torch.cat([self.cls_token, tokens], dim=1)  # [CLS] token

        # 3. 喂给标准 Transformer（和 BERT 一模一样！）
        for layer in self.transformer_layers:
            tokens = layer(tokens)

        return self.mlp_head(tokens[:, 0])  # [CLS] → 分类

历史意义：ViT 证明了 Transformer 是模态无关的通用架构——处理图像和处理文本可以用同一个 backbone。这为后来的多模态融合铺平了道路。

1.2 🔗 CLIP — 图文语义的"罗塞塔石碑"

📄 Learning Transferable Visual Models From Natural Language Supervision — OpenAI, Jan 2021

4 亿图文对训练 | 零样本 ImageNet 77.9% (ResNet-50×64) | 引用: 30,000+

CLIP 是整个多模态领域的基石。它的核心思想非常简单：在 4 亿个（图像，文字）对上做对比学习，让匹配的图文对在嵌入空间中靠近，不匹配的远离。

核心架构：双塔 + 对比损失

# CLIP 的训练逻辑
# 视觉塔: ViT 或 ResNet → 图像嵌入 [B, dim]
# 文本塔: Transformer → 文本嵌入 [B, dim]

# 对比损失 (InfoNCE) —— CLIP 的灵魂
def clip_loss(image_embeds, text_embeds, temperature=0.07):
    # 归一化
    image_embeds = F.normalize(image_embeds, dim=-1)
    text_embeds = F.normalize(text_embeds, dim=-1)

    # 计算相似度矩阵 [B, B]
    logits = (image_embeds @ text_embeds.T) / temperature

    # 对角线 = 匹配的图文对（正样本）
    labels = torch.arange(len(logits))

    # 双向对比损失
    loss_i = F.cross_entropy(logits, labels)       # 图像→文本
    loss_t = F.cross_entropy(logits.T, labels)     # 文本→图像

    return (loss_i + loss_t) / 2
$$\mathcal{L}_{\text{CLIP}} = -\frac{1}{2B}\sum_{i=1}^B \left[\log\frac{\exp(\mathbf{v}_i \cdot \mathbf{t}_i / \tau)}{\sum_j \exp(\mathbf{v}_i \cdot \mathbf{t}_j / \tau)} + \log\frac{\exp(\mathbf{t}_i \cdot \mathbf{v}_i / \tau)}{\sum_j \exp(\mathbf{t}_i \cdot \mathbf{v}_j / \tau)}\right]$$

为什么 CLIP 如此重要？它证明了自然语言可以作为视觉模型的超级监督信号。CLIP 之后，几乎所有多模态模型（DALL·E 2、Stable Diffusion、LLaVA、GPT-4V 的视觉编码器）都建立在 CLIP 的图文嵌入空间之上。

1.3 🎨 文生图的爆发：DALL·E → Stable Diffusion

DALL·E (2021.01) — 首个大规模文本→图像生成

基于 VQ-VAE + 自回归 Transformer，将图像编码为离散 token 序列，像 GPT 一样自回归生成。展示了"文本→图像"这个方向的可能性，但生成质量有限。

DALL·E 2 (2022.04) — 扩散模型 + CLIP 引导

关键创新：① 用扩散模型替代自回归生成，大幅提升质量；② 用 CLIP 嵌入作为语义引导信号——文本经过 CLIP 编码后作为扩散过程的条件。

Stable Diffusion (2022.08) — 让 AI 绘画"大众化"

💡 SD 的核心创新：潜空间扩散

不在像素空间直接做扩散（太慢），而是用 VAE 将图像压缩到潜空间（latent space），在潜空间做扩散，再用 VAE 解码回像素。这使得在单张消费级 GPU 上运行成为可能。

# Stable Diffusion 的核心流程
# 1. VAE Encoder: 图像 → 潜空间表示 z (压缩 8×)
# 2. UNet + CLIP Text Encoder: 在潜空间做条件扩散
# 3. VAE Decoder: 潜空间 → 图像

def sd_sampling(prompt, num_steps=50):
    text_embed = CLIP_text_encoder(prompt)  # CLIP 文本嵌入作为条件
    z = torch.randn(1, 4, 64, 64)           # 随机噪声（潜空间）

    for t in reversed(range(num_steps)):
        noise_pred = UNet(z, t, text_embed)  # 预测噪声（条件 = 文本嵌入）
        z = denoise_step(z, noise_pred, t)    # 去噪一步

    image = VAE_decoder(z)  # 潜空间 → 像素
    return image

1.4 🔌 桥接视觉与语言：Flamingo → BLIP-2

模型架构核心贡献
Flamingo (DeepMind, 2022.04)冻结 LLM + 视觉编码器 + 交叉注意力首个大规模 VLM，80B 参数，Few-shot
BLIP-2 (Salesforce, 2023.01)Q-Former 桥接冻结 ViT → 冻结 LLM轻量桥接，7B-13B，高效 VQA
💡 桥接模式的核心创新

不需要训练 ViT 或 LLM——两者都冻结。只训练一个轻量的"翻译层"（Q-Former / Perceiver Resampler），将视觉 token 翻译成 LLM 能理解的语言。这大大降低了训练成本。

第二章 · 视觉语言大模型崛起（2023）

📐 时代特征

"让大语言模型睁开眼睛" — 视觉理解能力直接集成到对话系统中，用户可上传图像进行问答与推理。

2.1 🔥 GPT-4V — LLM "睁开眼"

📄 GPT-4V(ision) — OpenAI, Sep 2023

首个广泛可用的视觉版大语言模型，支持复杂图像理解与多步视觉推理。GPT-4 的多模态版本在 2023 年 3 月限量发布，9 月通过 ChatGPT 广泛推出。

GPT-4V 的意义远超技术本身。它向世界证明了：一个已经精通语言的模型，加上视觉能力后，可以产生"协同效应"——它不仅能看图说话，还能结合视觉信息进行推理。

2.2 🦙 LLaVA — 开源 VLM 的崛起

📄 Visual Instruction Tuning — UW-Madison / Microsoft, Apr 2023. NeurIPS 2023 Oral

LLaVA 是 GPT-4V 的开源对应物。它的核心创新是 视觉指令微调（Visual Instruction Tuning）——用 GPT-4 生成图像问答对话数据，然后训练 VLM。

# LLaVA 的极简架构
# 图像 → CLIP ViT → 视觉嵌入 (576 tokens)
# 文本 → Tokenizer → 文本嵌入 (N tokens)
# 视觉嵌入 → MLP投影 → [IMG1]...[IMG576] + 文本 tokens
# → 喂给 Vicuna LLM → 自回归生成回答

LLaVA-1.5 (Oct 2023) 仅用 13B 参数就在多项视觉问答基准上接近 GPT-4V，成为 最广泛使用的开源 VLM 基线。

2.3 🌟 Gemini 1.0 — 首个原生多模态架构

📄 Gemini: A Family of Highly Capable Multimodal Models — Google DeepMind, Dec 2023

与 LLaVA "先看图再说话"的 bolt-on 方式不同，Gemini 从架构设计之初就将多模态作为一等公民。32 项基准中 30 项超越 GPT-4。

💡 Gemini 的关键区分

"Bolt-on" VLM（如 LLaVA）= 视觉编码器 + 翻译层 + 语言模型（两个独立模块拼在一起）。
"Native" VLM（如 Gemini）= 一个统一的 transformer，从训练开始就交替喂入图像 patch 和文本 token。

后者是真正的"原生多模态"。

第六章 · 核心技术深潜

6.1 🔗 对比学习：CLIP 的数学本质

CLIP 训练的是最大化匹配图文对的互信息。InfoNCE 损失可以理解为：在 batch 内，正确的图文对是正样本，其余所有 B²-B 对都是负样本。

# CLIP 训练的核心（完整版）
def clip_training_step(images, texts, model, optimizer):
    # 1. 前向传播
    img_emb = model.encode_image(images)  # [B, dim]
    txt_emb = model.encode_text(texts)    # [B, dim]

    # 2. 归一化
    img_emb = F.normalize(img_emb, dim=-1)
    txt_emb = F.normalize(txt_emb, dim=-1)

    # 3. 可学习的温度参数（初始化为 0.07）
    logit_scale = model.logit_scale.exp()

    # 4. 计算相似度矩阵
    logits_per_image = logit_scale * img_emb @ txt_emb.T  # [B, B]
    logits_per_text = logits_per_image.T

    # 5. 对角线 = 正样本
    labels = torch.arange(B, device=device)

    # 6. 双向交叉熵
    loss = (F.cross_entropy(logits_per_image, labels) +
            F.cross_entropy(logits_per_text, labels)) / 2

    optimizer.zero_grad()
    loss.backward()
    optimizer.step()
    return loss.item()

6.2 🌀 扩散模型：从噪声到图像

扩散模型的核心思想是学习一个反向过程——正向过程（fixed）逐步添加噪声直至纯噪声；反向过程（learned）逐步去除噪声恢复原始数据。

$$\text{Forward: } q(x_t|x_{t-1}) = \mathcal{N}(x_t; \sqrt{1-\beta_t}x_{t-1}, \beta_t\mathbf{I})$$ $$\text{Reverse: } p_\theta(x_{t-1}|x_t) = \mathcal{N}(x_{t-1}; \mu_\theta(x_t, t), \sigma_t^2\mathbf{I})$$ 
# 扩散模型的训练（DDPM 简化版）
def diffusion_training_step(model, x_0, t, noise):
    """预测添加到 x_0 上的噪声"""
    # 正向：加噪声
    alpha_bar = cumulative_product(alphas)[t]
    x_t = sqrt(alpha_bar) * x_0 + sqrt(1 - alpha_bar) * noise

    # 反向：预测噪声
    noise_pred = model(x_t, t)  # U-Net 或 DiT

    # 损失：预测噪声 vs 真实噪声的 MSE
    loss = F.mse_loss(noise_pred, noise)
    return loss

# 条件生成（文本→图像）：将文本嵌入注入每一步
def diffusion_sampling_with_text(model, text_embed, num_steps=50):
    x_t = torch.randn(1, 3, 512, 512)  # 纯噪声
    for t in reversed(range(num_steps)):
        noise_pred = model(x_t, t, text_embed)  # 文本 = 条件！
        x_t = denoise(x_t, noise_pred, t)
    return x_t  # 生成的图像

6.3 🔌 Q-Former：轻量跨模态翻译器

BLIP-2 的 Q-Former 是 VLM "bolt-on" 时代的标志性设计。它的结构：

# Q-Former 的架构
# 输入侧：可学习的 query tokens [32, 768] + 图像特征（从 ViT 获得）
# 输出侧：32 个 query tokens 的更新版本 → 送到 LLM

class QFormer(nn.Module):
    def __init__(self, num_queries=32, hidden_dim=768):
        self.queries = nn.Parameter(torch.randn(num_queries, hidden_dim))
        self.cross_attention = nn.MultiheadAttention(...)
        self.self_attention = nn.MultiheadAttention(...)
        self.ffn = FeedForward(...)

    def forward(self, image_features):
        # image_features: [B, 257, 1024] (ViT 输出)
        x = self.queries.unsqueeze(0).expand(B, -1, -1)  # [B, 32, 768]

        # Self-attention among queries
        x = self.self_attention(x, x, x)

        # Cross-attention: queries attend to image features
        x = self.cross_attention(x, image_features, image_features)

        # Feed-forward
        x = self.ffn(x)

        return x  # [B, 32, 768] → 送到 LLM 作为 "visual tokens"

为什么 32 个 query 就够了？Q-Former 学会了将 257 个图像 patch token 压缩为 32 个高质量的视觉 token，只保留对语言理解最重要的信息。这比直接喂 257 个 token 给 LLM 更高效。
