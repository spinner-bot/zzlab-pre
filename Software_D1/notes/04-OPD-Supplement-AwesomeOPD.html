OPD 的严格定义

AwesomeOPD 使用两条件严格定义 OPD：

🎯 OPD = C1 + C2

C1：学生在训练期间采样自己的轨迹 $y \sim \pi_{\text{student}}(\cdot|x)$
C2：教师在这些学生样本上提供逐 token / 序列级监督

OPSD（在线策略自蒸馏）：C1 + C2，但教师 = 同一模型（特权上下文条件 / 早期 checkpoint）
