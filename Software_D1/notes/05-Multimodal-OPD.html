◆ ◆ ◆

核心问题与研究动机

2025–2026 年间，多模态大模型（MLLM / LVLM / LALM）进入 RL 后训练时代。GRPO、DAPO、PPO 等方法在纯文本 LLM 上取得了显著推理能力提升（DeepSeek-R1、Qwen3），但当这些范式迁移到多模态模型时，遇到了三个根本性瓶颈：

⚠️ 多模态 RL 后训练的三大瓶颈

1. 稀疏奖励问题（Sparse Reward）：可验证奖励（verifiable reward）仅对最终答案打分，失败 rollout 中每个 token 获得相同的惩罚信号，导致信用分配（credit assignment）失效——模型无法知道是「看错了」还是「推错了」。

2. 感知-推理耦合退化（Perception-Reasoning Entanglement）：RL 优化可能牺牲视觉感知来换取文本推理的奖励提升，导致模型学会「蒙答案」而非「读图」——这正是笔记 03 中讨论的 shortcut learning 问题。

3. 分布漂移（Distribution Drift）：SFT → RLVR 的 pipeline 中，SFT 阶段基于静态数据，RL 阶段基于自采样轨迹，两个分布之间的 gap 导致训练不稳定甚至灾难性遗忘。

正是在这三个瓶颈的交汇处，在线策略蒸馏（Online Policy Distillation, OPD）——特别是其自蒸馏变体 OPSD（On-Policy Self-Distillation）——作为解决方案迅速崛起。其核心洞见极其简单：

💡 OPD 在多模态中的核心公式

学生用自己的策略生成轨迹 → 教师在相同轨迹上提供逐 token 密集监督 → 对齐两者的分布。

在多模态语境下，"教师"和"学生"通常是同一个模型的冻结副本和训练副本——区别仅在于教师看到了特权信息（privileged information）：可能是答案参考、裁剪区域、生成式视觉思维、或未来帧。

数学上，这等价于在 on-policy 轨迹上的分布匹配：

$$\mathcal{L}_{\text{OPD}} = \sum_{t} D_{\text{KL}}\big(p_{\theta_{\text{old}}}(\cdot|x_{\text{priv}}, y_{<t}) \;\|\; p_\theta(\cdot|x_{\text{student}}, y_{<t})\big)$$
◆ ◆ ◆

一、多模态 OPD 范式：从文本到多模态的迁移

1.1 文本 OPD vs 多模态 OPD

笔记 02 详细梳理了文本域 OPD 的发展（REOPOLD、PW-OPSD、GAR 等）。多模态 OPD 在此基础上引入了三个新维度：

维度文本 OPD多模态 OPD
特权信息类型参考答案、推理链（rationale）参考答案 + 视觉裁剪 + 生成式视觉思维 + 注意力图 + 未来帧 + 音频
教师-学生差异同一模型，有无参考文本同一模型，跨模态上下文差异（crop vs full image, text+audio vs text-only, VT vs no-VT）
核心风险答案泄漏（answer leakage）多模态 shortcut：模型用文本参考而非视觉证据来对齐分布——PALR 诊断揭示 17–26% 的 token 级监督来源于文本而非图像
散度选择Forward KL / JSDReverse KL / JSD / Top-K JSD：防止跨模态分布差异导致的熵爆炸（Forward KL mode-covering 在视觉 token 上尤为严重）

1.2 多模态 OPD 的四大范式

截至 2026 年 7 月，多模态 OPD 研究已分化出四个清晰的范式：

范式 1：同模型跨上下文 OPSD

核心论文：Vision-OPD、Visual-OPSD、ViGOS、ViCuR。教师=冻结副本，学生=训练副本，差异仅在视觉上下文（crop vs full，VT vs no-VT）。零外部依赖，只需图文对。

范式 2：跨模态教师蒸馏

核心论文：VOLD、X-OPD、CORD、SightSound-R1。教师和学生来自不同模态（text LLM → VLM，VLM → audio LM），通过 on-policy 轨迹对齐实现能力迁移。需要冷启动 SFT 对齐。

范式 3：OPD + RL 混合

核心论文：PRISM、PTD-PO、Distill-R1。OPD 作为 RL 的预对齐阶段或辅助损失，提供逐 token 的 dense signal 来补充稀疏的序列级奖励。

范式 4：生成式 OPD

核心论文：D-OPSD、LiveTalk、OmniOPSD。将 OPSD 扩展到扩散模型和生成任务——学生采样噪声轨迹，教师用多模态条件（text+image）提供更强的速度场/分布预测。

1.3 时间线：多模态 OPD 的爆发式增长

2025.10 · 奠基

VOLD 首次将 on-policy distillation 引入 VLM 训练，证明文本 LLM 的推理能力可通过 GRPO + distillation 迁移到 VLM。SightSound-R1 跨模态蒸馏（视觉→音频）。

2026.01–02 · 扩展

CORD 提出音频-文本加权 on-policy 跨模态蒸馏。Video-OPD 将 OPD 引入时序视频定位。RAL (Google) 提出注意力层级 OPD——优化"看哪里"而非"说什么"。

2026.03–04 · 系统化

Distill-R1 首个开源 VLM RL+蒸馏框架。 PRISM 提出黑盒对抗 OPD 预对齐。VLA-OPD 将 OPD 引入机器人 VLA 模型。X-OPD (Tencent) 跨模态语音 LLM 蒸馏。

2026.05 · 成熟

Vision-OPD 区域到全局的自蒸馏。D-OPSD (Alibaba) 将 OPSD 引入扩散模型。PeRL-VL 感知-推理解耦。

2026.06 · 爆发

Visual-OPSD 统一多模态推理 14.3× 加速。ViGOS 感知-推理三教师解耦。PTD-PO 特权辅导蒸馏。ViCuR 视觉线索作为可恢复特权。V-Zero 无标签 OPD。HDPO 混合蒸馏策略优化。OmniOPSD 情感计算。

2026.07 · 前沿

H-OPD 异构多教师 token 级仲裁。Nemotron Audex (NVIDIA) 统一音频智能的多域 OPD。

◆ ◆ ◆

二、视觉域：VLM 的 OPD/OPSD

这是多模态 OPD 中论文最密集、方法论最成熟的子领域。截至 2026 年 7 月，已有超过 15 篇高质量论文直接讨论 VLM 的 online policy distillation。核心脉络从"能否做"到"如何做得更好"再到"如何防止做坏"。

2.1 奠基之作：VOLD（CVPR 2026）

📄 VOLD: Reasoning Transfer from LLMs to Vision-Language Models via On-Policy Distillation

作者：Walid Bousselham, Hilde Kuehne, Cordelia Schmid (CVPR 2026, pp.26209–26218)

arXiv：2510.23497（2025.10，2026.06 更新）

核心问题：多模态推理数据稀缺（图文+推理链），但纯文本推理数据丰富——能否将文本 LLM 的推理能力蒸馏到 VLM？

方法：GRPO + on-policy distillation。VLM 学生自采样轨迹，文本 LLM 教师在相同轨迹上提供 token 级分布监督。关键发现：冷启动 SFT 对齐是必不可少的——没有它，文本教师的分布与 VLM 学生的采样分布差距过大，蒸馏完全失败。

基准：MMMU-Pro、MathVision、MathVista、LogicVista。

意义：首次在严格意义上将 on-policy distillation 范式引入 VLM 训练，被 CVPR 2026 收录，成为后续所有 VLM OPD 工作的核心参考点。

2.2 同模型自蒸馏：Vision-OPD 与 Visual-OPSD

📄 Vision-OPD: Learning to See Fine Details for Multimodal LLMs via On-Policy Self-Distillation

作者：Qianhao Yuan 等 | arXiv：2605.18740（2026.05）

核心发现：区域到全局的感知差距（Regional-to-Global Perception Gap）——MLLM 在证据中心裁剪（evidence-centered crop）上回答细粒度问题的准确率显著高于全图条件。这意味着模型具备"看细节"的能力，但不具备在全图上下文中调用该能力的策略。

方法：

  • 教师：相同的 MLLM，条件为裁剪后的证据区域（privileged crop）
  • 学生：相同的 MLLM，条件为完整图像（标准推理条件）
  • 损失：token 级 KL 散度，在学生的 on-policy rollout 上计算
  • 零外部依赖：无需外部教师模型、无需 ground-truth 标签、无需奖励验证器、无需推理时工具

意义：证明了"视觉放大"（visual zooming）能力可以通过自蒸馏内化到模型中，而非依赖推理时的外部工具调用。

📄 Visual-OPSD: Cross-Modal On-Policy Self-Distillation for Efficient Unified Multimodal Reasoning

作者：Pengyu Li 等（西安交通大学）| arXiv：2606.18974（2026.06）| 代码：github.com/TiezMind/Visual-OPSD

核心发现（极具洞察力）：统一多模态模型（UMMs，如 ThinkMorph）中，生成式"视觉思维"（Visual Thoughts, VTs）通过多步扩散生成，推理成本约为纯文本的 14 倍（142.8s vs 10.0s/sample），但——移除或扰动 VTs 几乎不改变准确率。这意味着渲染的像素本身不是答案的载体，但生成路径中编码了有效的推理知识（经 KL 诊断确认）。

方法：

  • 教师：UMM，条件为生成的 VTs（特权视觉思维）
  • 学生：UMM，条件仅为文本问题（无视觉思维生成步骤）
  • 损失：token 级 JSD，沿学生 on-policy 轨迹

效果：+3.40pp 超越生成式教师（即学生蒸馏后比教师本身更强），14.3× 推理加速，VSP 基准 +63.83pp 超越同规模 VLM。

意义：这是多模态 OPSD 最引人注目的结果之一——学生不仅追平了教师，还超越了教师，且推理速度快一个数量级。其深层启示：多模态推理中，关键信息比显式像素承载的多得多。

2.3 防 Shortcut 三连：ViGOS、ViCuR、V-Zero

2026 年 6 月，三篇独立论文几乎同时指出多模态 OPSD 的一个核心风险：教师特权信息可能引导学生走"文本捷径"而非利用视觉证据，并各自提出了不同的解决方案。

📄 ViGOS: Seeing Before Reasoning — Shortcut-Resilient Multimodal On-Policy Self-Distillation

作者：Sihan Wang 等（中科院）| arXiv：2606.19120（2026.06）

核心发现：提出 PALR（Privileged Answer Leakage Rate） 诊断指标——量化教师监督中有多大比例来自文本参考而非图像内容。跨三个基准的测量显示 17–26% 的 token 级监督是"答案驱动"而非"图像驱动"。

方法 — 三教师解耦：

  • 仅图像感知教师：监督视觉描述段落（不接触参考答案）
  • 特权推理教师：监督推理/答案段落（接触参考答案，但仅作用于推理段）
  • 参考教师：回退——仅在学生 rollout 无效时介入，用于格式恢复

意义：首次量化了多模态 OPSD 的 shortcut 严重程度，并提出了解耦范式——让视觉描述由视觉监督，让推理由推理监督。

📄 ViCuR: Visual Cues as Recoverable Privilege for Multimodal On-Policy Distillation

作者：Kanghui Tian 等 | arXiv：2606.05718（2026.06）

核心洞察：在多模态 OPD 中，教师特权的设计与教师强度同等重要。如果特权信息在推理时不可获得（如参考答案），学生永远无法真正学会在没有特权时表现好。

方法：将教师特权从"答案侧"（参考答案）替换为"视觉线索"（输入图像中与查询相关的证据区域）——这些线索在训练时作为特权给教师，但推理时学生有可能自己恢复它们（通过更好的视觉注意力）。这建立了训练-推理之间的一致性。

意义：重新定义了多模态 OPD 的特权设计原则——"可恢复特权"（recoverable privilege）优于"不可恢复特权"（unrecoverable privilege）。

📄 V-Zero: Answer-Label-Free On-Policy Distillation with Contrastive Evidence Gating for Fine-Grained Visual Reasoning

作者：Haoxiang Sun 等（四川大学、北大、中国电信 TeleAI）| arXiv：2606.25319（2026.06）| 代码：github.com/eVI-group-SCU/V-Zero

核心突破：完全不需要文本答案标签的 OPD。这是多模态 OPD 最激进的范式——连答案都不需要。

方法：

  • 正/负视觉证据视图：正视图=目标区域裁剪，负视图=无关区域下采样
  • 教师重放在正/负视图下的相同轨迹，计算 log-prob 支持度差异 → 对比证据门 \( w(g) \)
  • 门控信号按轨迹级调节蒸馏强度：良好视觉基础的轨迹被放大，差基础的被抑制
  • 将 OPD 重新解释为"无负样本的停梯度对齐"（negative-free stop-gradient alignment）

效果：Qwen3.5-4B +3.1 平均分，训练速度 5× 快于 SFT、10× 快于 RL 基线。

意义：如果 V-Zero 范式的有效性被进一步验证，将极大降低多模态模型后训练的数据门槛。

2.4 解耦感知与推理的其他尝试

📄 PeRL-VL: Perception & Reasoning Learning for Vision-Language Models

作者：Yoon 等 | arXiv：2512.12487（2025.12）

方法：将感知与推理显式解耦为两个优化目标：(1) VLM 评判的描述奖励（faithfulness + sufficiency 打分），(2) 文本推理 SFT 叠加在 RLVR 之上。关键设计：门控奖励组合（gated reward composition）比简单聚合更有效地抑制 reward hacking。

效果：Qwen2.5-VL-7B 从 63.3% → 68.8% 平均 Pass@1。

📄 Decomposed On-Policy Distillation for Vision-Language Reasoning: Steering Gradients for Visual Grounding

作者：Yoon 等 | Semantic Scholar（2026）

方法：数学上将蒸馏损失分解为语言先验分量和视觉基础分量。提出 VGS（Visual Gradient Steering）——动态重定向更新向量以优先更新视觉子空间。

◆ ◆ ◆

三、视频域：时序 OPD

视频域的多模态 OPD 面临独特挑战：长时序依赖、稀疏关键帧、以及 GRPO 的多 rollout 训练在长视频上的计算灾难。

📄 Video-OPD: Efficient Post-Training of MLLMs for Temporal Video Grounding via On-Policy Distillation

作者：Jiaze Li, Hao Yin 等 | arXiv：2602.02994（2026.02，2026.06 修订）

核心问题：GRPO 类方法（如 Time-R1）在时序视频定位（Temporal Video Grounding, TVG）上存在两个致命缺陷：

  1. 稀疏序列级奖励 → 无法对视频中间的错误进行信用分配
  2. 多 rollout 训练 → 长视频上计算成本 prohibitive（每步需要 8–16 个完整 rollout）

方法：

  • 用固定前沿教师（frontier teacher）的逐 token Reverse KL 散度替代稀疏序列级奖励
  • 保持严格的 on-policy 优化：所有训练轨迹均由当前策略采样
  • TVDF（Teacher-Validated Disagreement Focusing）：优先训练教师-学生分歧大的轨迹的课程策略——确保每条轨迹要么是可靠的（teacher-validated）、要么是信息量最大的（max informative）

效果：Charades-TimeLens、ActivityNet-TimeLens、QVHighlights-TimeLens 上平均 ~17% 提升（vs GRPO ~12%），且收敛更快、计算成本更低。

📄 PF-OPSD: Privileged-Future On-Policy Self-Distillation（世界模型 + MLLM）

作者：Yucheng Zhou 等 | arXiv：2606.03603（2026.06）

核心概念：将世界模型（world model）与 MLLM 结合——教师看到真实未来帧作为特权上下文，学生在 on-policy rollout 中仅看到当前帧。这让学生学会在没有未来信息时进行稳健推理。

效果：VRQABench +10.6%、OpenWorldQA +10.9%。

深层含义：这一范式将 OPD 扩展到了时序预测——特权不再仅仅是"更好的视觉"，而是"未来的知识"。

◆ ◆ ◆

四、音频/语音域：跨模态 OPD

音频和语音 LLM 长期面临一个困境：端到端语音模型在推理能力上落后于文本 LLM 10–15 个百分点——这被称为"跨模态对齐差距"（cross-modal alignment gap）。OPD 正成为弥合这一差距的核心技术。

4.1 语音 LLM 的 OPD

📄 X-OPD: Cross-Modal On-Policy Distillation for Capability Alignment in Speech LLMs

作者：Tencent Hunyuan × 浙江大学 | arXiv：2603.24596（2026.03）

核心问题：端到端语音 LLM 在各种基准上的表现始终落后于其文本对应物——平均差距 11.29%（语音）和 5.51%（文本）。

方法：文本 LLM 教师对语音 LLM 学生的 on-policy rollout 提供逐 token 反馈。学生自己用语音条件生成，教师用文本条件在相同轨迹上提供分布监督。

效果：差距从 11.29% → 3.43%（语音），5.51% → 0.97%（文本），横跨 BIG Bench Audio、Audio Multi-Challenge、VoiceBench。

📄 CORD: Bridging the Audio-Text Reasoning Gap via Weighted On-policy Cross-modal Distillation

作者：（2026.01）| arXiv：2601.16547

方法：在单一模型内使用文本模态作为内部教师，音频模态作为学生。结合 token 级 Reverse KL（重要性感知加权）和序列级 GRPO。仅需 80k 合成样本即可实现一致的音频条件推理提升。

意义：证明了 OPD 在极小数据规模下仍然有效——这对音频/语音域特别重要，因为该域的标注数据远比视觉域稀缺。

📄 Data-Efficient On-Policy Distillation for Automatic Speech Recognition（Ark-ASR OPD）

作者：AutoArk-AI | arXiv：2605.28139（2025/2026）

核心发现：仅用 100k 小时音频（vs Qwen3-Omni 的 20M 小时），0.6B OPD 训练的学生模型在 4/5 基准上超越 Qwen3-ASR-0.6B。使用 union top-k KL 目标。

意义：这是 OPD 在工业级 ASR 上的重要验证——说明 OPD 可以极大降低训练数据需求。

4.2 跨模态推理迁移

📄 SightSound-R1: Cross-Modal Reasoning Distillation from Vision to Audio Language Models

作者：Qiaolin Wang 等 | arXiv：2509.15661（2025.09）| ICASSP 2026

三步流水线：

  1. 教师推理生成：VLM 教师从无声视频+问题生成多条音频聚焦的 CoT，仅保留所有路径答案一致的轨迹（自洽性过滤）
  2. 音频基础事实验证（AGFV）：独立音频检查器（GPT-4o-audio）验证教师声学声明的真实性——过滤 VLM 教师"听不到"导致的幻觉
  3. 学生训练：验证后的 CoT 做 SFT → GRPO 精炼

效果：MMAU Test-mini (Sound) 66.1%，MUSIC-AVQA 59.5%（temporal 62.7%，comparative 63.3%）。

局限性：语音和音乐任务上性能下降——精细声学属性缺乏视觉关联。

4.3 工业级统一音频 OPD

📄 Nemotron Audex: Unified Audio Intelligence Without Regressing on Text Intelligence

作者：Zhifeng Kong 等（NVIDIA）| arXiv：2607.05196（2026.07）

架构：30B-A3B MoE 音频-文本 LLM。多阶段监督训练 + 多域 on-policy distillation（ASR、TTS、音频生成、语音到语音等多个域各有一个 OPD 教师）。SOTA 音频理解 + ASR + TTS + 音频生成 + 语音到语音——同时保持文本推理能力不退化。

意义：这是第一个证明 OPD 可以在多域统一模型中同时提升所有模态（包括原始文本能力）的工业级验证。

◆ ◆ ◆

五、Agent 与具身智能：OPD 走向物理世界

机器人领域的 VLA（Vision-Language-Action）模型面临比 VLM 更严峻的挑战：稀疏环境奖励、高采样成本、以及分布漂移导致的灾难性遗忘。OPD 在这里展现出了超越传统 RL 和 SFT 的独特优势。

📄 VLA-OPD: Bridging Offline SFT and Online RL for Vision-Language-Action Models via On-Policy Distillation

作者：Zhide Zhong 等 | arXiv：2603.26666（2026.03）

核心创新 — Reverse-KL 目标：

目标问题VLA 中的后果
Forward KLMode-covering（覆盖所有教师模式）熵爆炸 → 动作过于随机
Hard CE确定性模仿熵坍塌 → 丧失探索能力
Reverse KLMode-seeking（寻求教师高概率模式）过滤教师认知不确定性，同时保持动作多样性

效果：LIBERO 和 RoboTwin2.0 上显著提升采样效率（vs RL）和鲁棒性（vs SFT），有效缓解灾难性遗忘。

意义：首次将 OPD 范式系统性地引入 VLA 模型后训练，并确立了 Reverse KL 在连续动作空间中的优势。

📄 M2Distill: Multi-Modal Distillation for Lifelong Imitation Learning

作者：Kaushik Roy 等 | 发表：ICRA 2025 | arXiv：2410.00064

场景：终身/持续模仿学习——机器人需要不断增加新技能而不遗忘旧技能。

方法：多模态蒸馏保持视觉、语言、动作分布之间一致的潜在空间，通过规范化增量步骤间的潜在表示漂移和 GMM 策略差异来防止灾难性遗忘。

📄 ACGD: Asymmetric Critic Guided Distillation for Visual Multitask Policy Learning

作者：Srinivasan 等（NVIDIA / Stanford / Georgia Tech）| 发表：2025

方法：单任务专家策略 + 评论家（拥有特权状态信息）蒸馏到统一多任务学生（VQ-VAE + Transformer）。灵巧操作基准提升 10–15%。

◆ ◆ ◆

六、RL + OPD 混合系统

2026 年最重要的工程趋势之一是 OPD 不再作为独立范式，而是与 RLVR（GRPO/DAPO/GSPO）深度集成。OPD 提供逐 token 的密集信号，RLVR 提供序列级的稀疏目标——两者互补形成完整的监督体系。

6.1 三阶段 Pipeline：PRISM

📄 PRISM: Beyond SFT-to-RL — Pre-alignment via Black-Box On-Policy Distillation for Multimodal RL

作者：Sudong Wang 等（HKUST(GZ), 清华, NTU, 人大, 中科大）| arXiv：2604.28123（2026.04）| 代码：github.com/XIAO4579/PRISM

核心问题：SFT → RLVR 的标准 pipeline 中，SFT 引入的分布漂移会严重损害多模态模型——感知错误和推理失败在 RL 阶段复合放大。

三阶段流水线：

  1. SFT（冷启动）：1.37M 演示数据（1.26M Gemini 公开数据 + 113K Gemini 3 Flash 精选高质量样本——带密集视觉基础和逐步推理）
  2. PRISM 对齐（OPD 阶段）：黑盒对抗游戏——MoE 判别器包含两个专家：
    • 感知专家 \( D_v \)：评估视觉基础质量
    • 推理专家 \( D_r \)：评估逻辑一致性
    判别分数 \( r(x,y) = \alpha \cdot D_v(x,c) + (1-\alpha) \cdot D_r(x,t) \)——无需教师 logits，支持黑盒 API 模型。
  3. RLVR（最终优化）：GRPO/DAPO/GSPO 在已对齐策略上优化

效果（Qwen3-VL）：4B +4.4 / 8B +6.0 平均准确率提升。增益跨 RL 算法类型泛化。

意义：首次系统性地证明OPD 预对齐是 SFT→RLVR 的必要中间步骤，且支持黑盒教师——极大降低了实际部署门槛。

6.2 特权辅导：PTD-PO 与 HDPO

📄 PTD-PO: Teaching the Way, Not the Answer — Privileged Tutoring Distillation for Multimodal Policy Optimization

作者：Shizhe Xiang 等（天大、北理工、新加坡管理大学、小米）| arXiv：2606.07000（2026.06）| 代码：github.com/XszNeverSleep/PTD-PO

核心哲学 — "教方法不教答案"：传统 OPD 的特权包含参考答案，可能导致 shortcut。PTD-PO 构造不暴露答案的特权提示（空间注意力引导 + 中间推理步骤），教师通过 in-context learning 利用这些提示生成逐步 token 分布监督。

关键技术：

  • Top-K JSD 稳定化：在引导/非引导上下文分布偏移下聚焦信息量最高的 token 概率
  • Learning-with-Privileged-Information 范式：学生仍在原始无答案条件下优化

效果：2B–8B LVLM 上持续超越 RLVR 和蒸馏基线，有效缓解熵坍塌。

📄 HDPO: Hybrid Distillation Policy Optimization via Privileged Self-Distillation

作者：Ke Ding 等 | arXiv：2603.23871（2026.03）

核心发现：过滤后的特权生成在硬阈值极限下精确恢复最优 KL 正则化 RL 策略——这为 OPD+RL 混合方法提供了理论保证。

6.3 开源框架：Distill-R1

📄 Distill-R1: Multi-Modality RL Training with Teacher-Student Distillation

作者：ByungKwan Lee 等 | 代码：github.com/ByungKwanLee/Distill-R1（2026.03）

贡献：首个开源 VLM RL+在线师生蒸馏框架。教师生成自己的 rollout，学生同时训练。支持 Qwen2-VL / Qwen2.5-VL / Qwen3-VL，兼容 GRPO / DAPO / REINFORCE++ / RLOO / GSPO / CISPO / SAPO。

意义：标准化了 VLM OPD+RL 的实验基准和工程实践。

◆ ◆ ◆

七、扩散与生成：OPD 超越判别模型

2026 年 5–6 月，OPD 范式开始扩展到生成模型——这是 OPD 从"优化策略分布"走向"优化生成分布"的标志性跨越。

📄 D-OPSD: On-Policy Self-Distillation for Continuously Tuning Step-Distilled Diffusion Models

作者：Dengyang Jiang 等（阿里巴巴 Z-Image × 港科大 × UCSD × 港中文）| arXiv：2605.05204（2026.05）| 项目页：vvvvvjdy.github.io/d-opsd/

核心发现：现代 LLM/VLM 编码器的扩散模型可以继承编码器的上下文学习能力——当同时输入文本提示和目标图像的多模态特征作为条件时，模型无需额外训练就能生成保留目标概念/风格的变体图像。

方法 — OPSD 在扩散模型中的迁移：

  • 学生分支：仅基于文本条件进行少步采样（rollout）
  • 教师分支：基于文本+目标图像的多模态特征，提供更强的速度场预测
  • 损失：在相同 on-policy 轨迹上对齐学生的速度预测（MSE）

关键优势：

  • ✅ 在线策略：始终在学生自身的 rollout 上优化，消除训练-推理分布偏移
  • ✅ 无需奖励模型：仅需图文对，无需偏好数据或 reward function
  • ✅ 学新不忘旧：LoRA 定制 + 全量微调均保留原始少步能力

深层意义：这证明 OPSD 不是 LLM 特化的技巧，而是一种通用的分布匹配范式——只要存在"教师有更多上下文→更强预测"的信息不对称，OPSD 就可以工作。

📄 LiveTalk: Real-Time Multimodal Interactive Video Diffusion via Improved On-Policy Distillation

作者：（2025.12）| arXiv：2512.23576

应用：实时多模态（文本、图像、音频）交互式视频生成。改进的 on-policy distillation 解决多模态条件下的视觉伪影问题。

效果：20× 推理加速并保持质量匹配；实时化身系统在多轮一致性上超越 Sora2 和 Veo3。

八、新兴方向

8.1 多教师异构 OPD：H-OPD

📄 H-OPD: Confidence Aware Heterogeneous Multi-Teacher Multimodal On-policy Distillation

作者：Qixiang Yin 等（北邮、字节跳动、中科大）| arXiv：2607.02592（2026.07）| 代码：github.com/buptyqx/H-OPD

关键洞察：现有 OPD 使用静态教师路由（按模态/任务分配教师），但不同的解码步骤可能需要不同的教师专长——视觉基础步需要 VLM 教师，抽象推理步需要文本 LLM 教师。

方法：

  • Token 级教师仲裁：沿共享学生轨迹，每步动态决定哪个教师更可信
  • 视觉到语言描述迁移：让纯文本教师也能访问视觉语义
  • 置信度感知仲裁机制：动态融合 VLM 和文本教师在每个 token 的预测

评估：11 个推理基准上验证（MMFineReason-123K 数据集，过滤到 ~55K 高质量样本）。

意义：多教师 OPD 可能是下一阶段的核心范式——如同 MoE 中不同专家负责不同 token，未来 OPD 可能每个 token 都由最优教师组合来监督。

8.2 注意力层级 OPD：RAL

📄 RAL: Reinforced Attention Learning — Optimizing Where to Look, Not What to Say

作者：Bangzheng Li 等（UC Davis、Princeton、Google、Google DeepMind）| arXiv：2602.04884（2026.02）

范式转变：传统 RL/OPD 优化的是"生成什么 token"，RAL 直接优化"注意力该放在哪里"——将模型内部注意力分布作为策略梯度优化的策略。

方法：

  • 注意力分布策略：每个生成 token 对所有前序位置（视觉+文本）的注意力权重 = 可学习的"策略"
  • 优势加权注意力散度损失：JSD，高奖励拉近，低奖励推远
  • 联合优化：token 级 RL 损失 + 注意力级 RL 损失

惊人发现 — RAL-zero：完全去掉 <think> 推理文本（仅输出答案），仅靠优化注意力分布就超过了 GRPO。这证明：优化"看哪里"本身就能提升推理能力，不依赖显式 CoT。

On-Policy Attention Distillation：进一步提出注意力蒸馏——让学生用自己的策略采样轨迹，再用教师的注意力分布做对齐。相比传统知识蒸馏（仅对齐 logits），注意力蒸馏同时传递"答案是什么样的"和"证据该从哪里找"。

意义：RAL 将多模态后训练从"输出空间"推进到"内部表示空间"，为理解多模态推理的本质机制开辟了新路径。

8.3 世界模型 + OPD

📄 World Models Meet Language Models: On the Complementarity of Concrete and Abstract Reasoning

作者：Yucheng Zhou 等 | arXiv：2606.03603（2026.06）

方法：将世界模型（生成未来视频帧）与 MLLM 的抽象推理能力结合。教师看到真实未来帧（特权），学生在 on-policy rollout 中仅基于当前观测推理。通过 OPSD 让学生学会在没有未来信息时做出稳健推理。

启示：这打开了 OPD + 世界模型的新维度——特权不再局限于"同一时刻的更多信息"，而是跨时间的因果信息。

8.4 情感计算中的 OPD

📄 OmniOPSD: Rationale-Privileged On-Policy Self-Distillation for Affective Computing

作者：Zebang Cheng 等 | arXiv：2606.15920（2026.06）

方法：使用前沿模型生成的推理依据（rationale）作为教师侧特权证据——而非学生模仿目标。学生在无特权条件下自采样，教师用 rationale 提供密集监督。MER-UniBench 上 SOTA 84.19。

意义：将 OPSD 扩展到情感计算——一个需要细粒度跨模态理解但对 ground-truth 标签高度敏感的领域。

十、开放问题与未来方向

10.1 理论开放问题

🔮 待解决的理论问题

1. 多模态 OPD 的收敛性保证：笔记 02 中 Czarnecki 2019 的 Theorem 1（梯度场不存在定理）在纯文本域已确立——多模态条件下的梯度场行为是否不同？跨模态梯度分量的相互作用尚无理论分析。

2. 最优特权设计：ViCuR 提出了"可恢复特权"概念，但什么样的特权在数学上是最优的？是否存在一个类似信息瓶颈（Information Bottleneck）的框架来形式化特权质量？

3. 多教师仲裁的最优性：H-OPD 的 token 级教师仲裁是启发式的——能否从决策论或贝叶斯模型平均的角度给出最优仲裁策略？

4. 视觉注意力的可优化性边界：RAL 证明了注意力分布可以通过策略梯度优化——注意力的哪些性质是可优化的？是否存在注意力的"可达集"（reachable set）概念？

10.2 工程挑战

⚡ 关键工程瓶颈

1. 计算开销：on-policy 采样需要每步生成完整 trajectory，对于长视频和高分辨率图像，这仍然是显著的 overhead。TVDF 等课程策略是第一步，但更高效的重要性采样方法尚未开发。

2. 教师质量依赖性：几乎所有 OPD 方法都假设教师比学生"更好"——但当师生差距过大（如 Visual-OPSD 中 VT 生成质量差）或过小（教师没有增量信息），OPD 如何自适应调节？

3. 多模态多教师协调：H-OPD 引入了异构教师——但在 3+ 教师场景下，仲裁机制的计算开销和教师间的冲突如何解决？

4. 灾难性遗忘的持续监控：VLA-OPD 在机器人域证明了 OPD 有助于缓解遗忘——但缺乏在线遗忘检测和自动恢复的机制。

10.3 前沿方向

方向描述代表工作
无标签 OPD 在没有任何 ground-truth 标签的条件下进行 OPD——仅靠视觉证据对比 V-Zero
注意力 OPD 将优化目标从 token 分布扩展到内部注意力分布——"教模型看哪里" RAL
多教师异构 OPD 不同解码步动态切换最优教师——token 级教师组合优化 H-OPD
时序 OPD 特权来自未来信息——OPD 与世界模型的交叉 PF-OPSD, Video-OPD
生成式 OPD 将 OPSD 扩展到扩散/生成模型——从"优化离散策略"到"优化连续分布匹配" D-OPSD, LiveTalk
持续 OPD 终身学习场景中的 OPD——新任务不断加入，旧能力不能遗忘 M2Distill, VLA-OPD

10.4 预测与展望

🔭 2026–2027 展望

短期（6 个月内）：多教师 OPD 将成为标准配置；OPD + RLVR 三阶段 pipeline（SFT → OPD → RLVR）将被主流框架（TRL、verl）原生支持。

中期（12 个月内）：第一个"全模态统一 OPD"模型出现——同时覆盖视觉、视频、音频、语音、文本的单一 OPD 框架。Nemotron Audex 已经接近这个目标。

长期（18–24 个月）：OPD 可能演变为多模态模型的默认训练范式——就像当年的 ImageNet 预训练之于计算机视觉。Attention OPD 和生成式 OPD 将成为两个最活跃的子方向。
