第一章 · 知识蒸馏的起源

1.1 📜 模型压缩的史前时代

在深度学习统治世界之前，研究者们就面临一个朴素的问题：

💡 核心问题

一个大模型（ensemble）学到的知识，能不能"灌"进一个小模型里？

这个问题有着极大的现实意义。深度神经网络虽然在图像识别、语音处理等任务上取得了惊人的成绩，但它们太大、太慢了。一个典型的深度模型可能有数千万甚至数十亿参数，部署到手机、嵌入式设备上几乎不可能。研究者们需要一种 "压缩魔咒"——保持精度，大幅缩小体积。

1997
Pedro Domingos 最早探索了从多个模型中提取知识的思想，研究了如何将多个模型的 "知识" 合并到一个单一模型中。这是知识蒸馏的哲学雏形。
2006
Bucilă, Caruana & Niculescu-Mizil 发表题为 "Model Compression" 的论文，是 KD 的 直接前身。他们证明：一个大型模型集成可以被压缩为一个轻量级单一模型，且几乎不损失准确率。核心思想是让学生模型去 拟合教师模型的输出概率分布，而非直接学习原始标签。
2014
Lei Jimmy Ba & Rich Caruana 在论文 "Do Deep Nets Really Need to be Deep?" 中提出：浅层网络可以通过模仿深层网络来达到相近性能。他们训练浅层网络去拟合深层网络的 logit 输出——而非仅仅最终的分类结果——这为 2015 年 Hinton 的突破做好了最后的铺垫。

🧪 实例：为什么模型压缩如此重要？

以 ResNet-50 和 MobileNet-V2 为例直观感受（ImageNet 分类任务）：

蒸馏后的 MobileNet 在不增加任何参数和推理时间的情况下，准确率跃升了 +2.2 个百分点。对于边缘设备来说，这是免费的午餐。

1.2 🏛️ Hinton et al. 2015 —— 蒸馏时代的开山之作

📄 论文信息

标题: "Distilling the Knowledge in a Neural Network"
作者: Geoffrey Hinton, Oriol Vinyals, Jeff Dean（Google）
发表: NIPS 2015 Deep Learning Workshop  |  arXiv: 1503.02531

这篇仅仅 9 页的 workshop 论文做了三件开创性的事情：

  1. ✨ 提出了 "暗知识"（Dark Knowledge） 的概念
  2. 🌡️ 引入 温度参数 $T$，将 softmax 推广为可调节软度的概率输出
  3. 📐 定义了标准的 "蒸馏损失"框架，至今仍是行业标配

🔮 暗知识（Dark Knowledge）—— 被丢弃的宝藏

考虑一个图像分类任务：输入一张"猫"的图片。

训练方式🐱 猫🐶 狗🐯 虎🚗 汽车蕴含的信息
硬标签100%0%0%0%仅知道这是猫
软标签（教师输出）90%8%2%~0%猫≈狗>虎≫汽车
💡 暗知识的本质

硬标签丢弃了"猫和狗长得像，猫和汽车完全不像"这类类间相似性信息。这些被丢弃的微小概率差异，就是 暗知识。软标签中编码了教师对类间关系的全部理解。

Hinton 用一个极端的 MNIST 实验展示了暗知识的强大：使用软标签训练，学生只需要 3% 的训练数据 就能达到使用全部硬标签数据训练的模型水平。暗知识充当了强大的 正则化器——它告诉学生"别把 3 当成 8，它们虽然有点像但不是一回事"。

🌡️ 温度参数 $T$ —— 控制知识的"软硬"

S温度参数 $T$ 是整个知识蒸馏中最核心的数学工具，没有之一。 Hinton 对标准的 softmax 做了一个精妙的推广：

$$p_i = \frac{\exp(z_i / T)}{\sum_j \exp(z_j / T)}$$

其中 $z_i$ 是类别 $i$ 的 logit（softmax 前的原始输出），$T$ 是温度。

$T$ 值效果直观理解
$T \to 0^+$趋近 argmax（one-hot）❄️ 极冷——只有最大值有概率
$T = 1$标准 softmax🌡️ 常温——原始概率分布
$T > 1$（典型 2~20）软目标🔥 温暖——显露出暗知识
$T \to \infty$趋近均匀分布💨 极热——所有信息被"蒸发"

🧪 动手实验：温度的可视化

以 logits = [3.0, 1.0, 0.2] 为例，观察温度如何改变概率分布：

import matplotlib.pyplot as plt

def softmax_with_temperature(logits, T):
    """带温度的 softmax"""
    exp_z = np.exp(logits / T)
    return exp_z / exp_z.sum()

temperatures = [0.1, 0.5, 1.0, 2.0, 5.0, 10.0, 50.0]

🔑 温度的工作原理（直觉）

温度越高，logit 之间的差异被"抹平"越多。在 $T = 0.1$ 时，类别 A 几乎占据全部概率；在 $T = 10$ 时，三个类别的概率已经非常接近——教师关于"B 和 C 哪个更像 A"的全部认知，都编码在这个平滑化的分布中。

🧪 完整实现：一个极简的 PyTorch 知识蒸馏

让我们实现一个完整的蒸馏训练循环。这是理解蒸馏的最快方式——亲手写一遍。

import torch
import torch.nn as nn
import torch.nn.functional as F
import torch.optim as optim
from torch.utils.data import DataLoader
from torchvision import datasets, transforms

# ═══════════════════════════════════════
# 1. 蒸馏损失函数（Hinton 2015）
# ═══════════════════════════════════════
def distillation_loss(student_logits, teacher_logits, true_labels,
                      T=4.0, alpha=0.9):
    """
    完整的知识蒸馏损失

    参数:
        student_logits: 学生模型的原始输出 [batch, num_classes]
        teacher_logits: 教师模型的原始输出 [batch, num_classes]
        true_labels:    真实标签 [batch]
        T:              蒸馏温度（典型值 2~20）
        alpha:          蒸馏损失的权重（0~1）
                        alpha 越大 → 越依赖教师
                        1-alpha  → 越依赖硬标签

    返回:
        标量损失值
    """
    # ── 软损失（蒸馏损失）：学生 vs 教师的软目标 ──
    soft_student = F.log_softmax(student_logits / T, dim=1)
    soft_teacher = F.softmax(teacher_logits / T, dim=1)
    # KL 散度：D_KL(teacher || student)
    loss_soft = F.kl_div(soft_student, soft_teacher,
                         reduction='batchmean') * (T * T)

    # ── 硬损失：标准交叉熵（地面真相） ──
    loss_hard = F.cross_entropy(student_logits, true_labels)

    # ── 加权组合 ──
    return alpha * loss_soft + (1 - alpha) * loss_hard


# ═══════════════════════════════════════
# 2. 一个完整的训练 epoch
# ═══════════════════════════════════════
def train_epoch_with_distillation(student, teacher, dataloader,
                                   optimizer, device, T=4.0, alpha=0.9):
    student.train()
    teacher.eval()  # 教师固定，不参与梯度计算
    total_loss = 0.0
    correct = 0
    total = 0

    for images, labels in dataloader:
        images, labels = images.to(device), labels.to(device)

        # 教师推理（不计算梯度）
        with torch.no_grad():
            teacher_logits = teacher(images)

        # 学生推理
        student_logits = student(images)

        # 计算蒸馏损失
        loss = distillation_loss(student_logits, teacher_logits,
                                  labels, T=T, alpha=alpha)

        # 反向传播
        optimizer.zero_grad()
        loss.backward()
        optimizer.step()

        total_loss += loss.item()
        _, preds = student_logits.max(1)
        correct += preds.eq(labels).sum().item()
        total += labels.size(0)

    return total_loss / len(dataloader), 100. * correct / total

# 3. 使用示例（伪代码——你需要自己的教师和学生模型）

⚠️ 关键注意点
  • 教师固定（frozen）：蒸馏过程中教师不参与梯度计算。使用 torch.no_grad() 或 teacher.eval()
  • $T^2$ 系数：软损失需要乘以 $T^2$ 来补偿温度对梯度尺度的缩小
  • 推理时使用 $T=1$：部署时学生模型完全独立运行，不使用高温
  • 温度不是越高越好：过高温度会导致信息稀释，典型最佳范围是 2~10

第二章 · 蒸馏的核心数学框架

📐 本章目标

从第一性原理出发，完整推导知识蒸馏涉及的每一个数学组件：softmax → 温度 → 交叉熵 → KL 散度 → Forward/Reverse KL → 完整损失函数。如果你是第一次接触这些概念，不要跳读——每个概念都是构建下一个概念的基石。

2.1 🔤 硬标签 vs 软标签 —— 信息编码的两种方式

硬标签（Hard Label / One-hot Encoding）

对于一个 $K$ 类分类问题，硬标签是一个 $K$ 维向量：

$$\mathbf{y}_{\text{hard}} = [0, 0, 0, \underbrace{1}_{\text{正确类别}}, 0, ..., 0]$$

特点：

  • ✅ 包含"哪个是正确答案"的信息
  • ❌ 丢弃了所有"哪些错误答案比另一些错得更离谱"的信息
  • ❌ 极端稀疏、信息密度极低（$K$ 维向量中只有 1 bit 非零）

软标签（Soft Label / Probability Distribution）

$$\mathbf{y}_{\text{soft}} = [0.02,\; 0.85,\; 0.08,\; 0.03,\; 0.01,\; 0.01]$$

特点：

  • ✅ 包含正确答案（0.85 峰值在类别 2）
  • ✅ 包含 类间关系（类别 3 的 0.08 比类别 1 的 0.02 更像正确答案）
  • ✅ 密度丰富——每个位置都承载信息
💡 信息论视角

软标签的熵（entropy） 高于硬标签。更高的熵 = 更多的信息。硬标签的熵为 0（完全确定），而软标签的熵 > 0，包含了"不确定哪些类别也有关联"的宝贵认知。蒸馏的本质，就是让学生从高熵的教师输出中，学到比硬标签更多的信息。

2.2 🌡️ Softmax + Temperature —— 完整的数学推导

标准 Softmax

给定 logits $\mathbf{z} = [z_1, z_2, ..., z_K]$，标准 softmax 为：

$$\sigma_i(\mathbf{z}) = \frac{e^{z_i}}{\sum_{j=1}^{K} e^{z_j}}$$

这个公式保证了输出是一个合法的概率分布（所有值非负且和为 1）。每个 $z_i$ 的指数运算 $e^{z_i}$ 将"任意实数"映射到"正实数"。但这里有一个微妙的问题：指数函数的陡峭程度是固定的。两个 logit 值之间的差异被 $e$ 的指数放大得一样多——我们没有办法调节这个"放大倍数"。

温度推广 —— Hinton 的天才之举

$$\boxed{p_i(\mathbf{z}, T) = \frac{\exp(z_i / T)}{\sum_{j=1}^{K} \exp(z_j / T)}}$$

$T$ 出现在分母中，这意味着：

  • $T$ 大 → $z_i/T$ 小 → $\exp(z_i/T) \approx 1 + z_i/T$ → 所有类别概率接近
  • $T$ 小 → $z_i/T$ 大 → $\exp(z_i/T)$ 差异极大 → 概率集中在最大值
  • $T=1$ → 标准 softmax

关键引理：温度如何影响概率比

对于任意两个类别 $i$ 和 $j$：

$$\frac{p_i}{p_j} = \frac{\exp(z_i/T)}{\exp(z_j/T)} = \exp\left(\frac{z_i - z_j}{T}\right)$$

推论：

温度范围概率比行为含义
$T \to 0^+$$\frac{p_i}{p_j} \to \begin{cases} \infty & z_i > z_j \\ 0 & z_i < z_j \end{cases}$退化为 argmax（硬标签）
$T = 1$$\frac{p_i}{p_j} = e^{z_i - z_j}$标准 softmax
$T \to \infty$$\frac{p_i}{p_j} \to 1$均匀分布——所有信息被"加热蒸发"

🧪 实验：可视化温度的影响

import numpy as np
import matplotlib.pyplot as plt

def softmax_T(logits, T):
    """计算带温度的 softmax"""
    z = np.array(logits) / T
    z_shifted = z - np.max(z)  # 数值稳定技巧
    exp_z = np.exp(z_shifted)
    return exp_z / exp_z.sum()

# 二维 logits [2.0, 0.5]
logits_2d = [2.0, 0.5]
Ts = [0.1, 0.5, 1.0, 2.0, 5.0, 10.0, 100.0]

print(f"{'T':>6}  {'类别A':>8}  {'类别B':>8}  {'比值 A/B':>10}")
print("-" * 40)
for T in Ts:
    p = softmax_T(logits_2d, T)
    ratio = p[0] / p[1] if p[1] > 0 else float('inf')
    bar_A = '█' * int(p[0] * 40)
    bar_B = '█' * int(p[1] * 40)
    print(f"{T:6.1f}  {p[0]:8.4f}  {p[1]:8.4f}  {ratio:10.2f}   {bar_A} | {bar_B}")

2.3 📊 信息论基础：熵、交叉熵与 KL 散度

知识蒸馏的损失函数实质上是一组紧密关联的信息论概念的巧妙组合。理解它们的内在关系，是真正理解蒸馏的必经之路。

熵（Entropy）—— 不确定性的度量

$$H(P) = -\sum_{i} P(i) \cdot \log P(i)$$
  • 熵衡量一个概率分布的不确定性
  • 均匀分布熵最大 → 最不确定 → $H = \log K$
  • 硬标签熵 = 0 → 完全确定 → 只有一个类别有概率
  • 软标签熵 > 0 → 包含了"不确定哪些类别也有关联"的信息

交叉熵（Cross-Entropy）—— 用 Q 去编码 P 的代价

$$H(P, Q) = -\sum_{i} P(i) \cdot \log Q(i)$$

直观理解：

  • 真实分布是 $P$（地面真相），但我们的模型输出的是 $Q$
  • 交叉熵 = 用 $Q$ 的概率去编码实际从 $P$ 中采样的数据所需要的平均 bit 数
  • $Q$ 越接近 $P$，交叉熵越小
  • 关键关系：$H(P, Q) = H(P) + D_{KL}(P \| Q)$

KL 散度（Kullback-Leibler Divergence）—— 两个分布的"距离"

$$\boxed{D_{KL}(P \;\|\; Q) = \sum_{i} P(i) \cdot \log\frac{P(i)}{Q(i)} = \underbrace{H(P, Q)}_{\text{交叉熵}} - \underbrace{H(P)}_{\text{P 的熵}}}$$

关键性质：

  • $D_{KL}(P \| Q) \geq 0$，当且仅当 $P = Q$ 时等于 0（Gibbs 不等式）
  • 非对称性：$D_{KL}(P \| Q) \neq D_{KL}(Q \| P)$ —— 这是理解 OPD 的关键！
  • 不是真正的"距离"（不满足对称性和三角不等式），但可以作为"差异度量"

🧪 代码实验：KL 散度的非对称性

import numpy as np

def kl_divergence(p, q, eps=1e-10):
    """计算 KL(P || Q)，添加小值防止 log(0)"""
    p = np.clip(p, eps, 1.0)
    q = np.clip(q, eps, 1.0)
    return np.sum(p * np.log(p / q))

# 双峰分布（教师有"A大B小"的偏好）
P_teacher = np.array([0.8, 0.15, 0.05])  # 高度集中在 A
Q_student = np.array([0.5, 0.30, 0.20])  # 更均匀

# Forward KL:  D_KL(Teacher || Student)
forward = kl_divergence(P_teacher, Q_student)
# Reverse KL:  D_KL(Student || Teacher)
reverse = kl_divergence(Q_student, P_teacher)

print(f"Forward KL (Teacher→Student): {forward:.4f}")
print(f"Reverse KL (Student→Teacher): {reverse:.4f}")
print(f"差异: Forward KL < Reverse KL? {forward < reverse}")
print()
print("→ 两者不相等！KL 散度是非对称的。")
print("  Forward KL 惩罚'学生没覆盖教师的模式'")
print("  Reverse KL 惩罚'学生有但教师不认可的模式'")

# 直观对比
# Forward KL = 0.8*ln(0.8/0.5) + 0.15*ln(0.15/0.30) + 0.05*ln(0.05/0.20)
#             = 0.8*0.470 + 0.15*(-0.693) + 0.05*(-1.386)
#             ≈ 0.376 - 0.104 - 0.069 ≈ 0.203
#
# Reverse KL = 0.5*ln(0.5/0.8) + 0.3*ln(0.3/0.15) + 0.2*ln(0.2/0.05)
#             = 0.5*(-0.470) + 0.3*0.693 + 0.2*1.386
#             ≈ -0.235 + 0.208 + 0.277 ≈ 0.250

2.4 ↔️ Forward KL vs Reverse KL —— 截然不同的行为

这是整个蒸馏理论中最重要的一个概念。它会直接影响你对 OPD 篇的理解。

Forward KL（前向 KL）—— 均值追寻（Mean-Seeking）

$$D_{KL}(P_{\text{teacher}} \;\|\; P_{\text{student}})$$
特性描述
学生学到什么教师的所有模式（包括不重要的）
对教师分布 low-prob 区域用极小的 student prob 去拟合 → 惩罚巨大
结果学生分布比教师更宽泛、更"安全"
类比学生试图覆盖教师所有的知识

Reverse KL（反向 KL）—— 模式追寻（Mode-Seeking）

$$D_{KL}(P_{\text{student}} \;\|\; P_{\text{teacher}})$$
特性描述
学生学到什么教师的主要模式（忽略不重要的模式）
对学生分布 low-prob 区域学生选择不给该区域分配概率 → 无惩罚
结果学生分布比教师更尖锐、更"冒险"
类比学生只学教师最擅长的部分

🎨 直观可视化：双峰分布下的 Forward vs Reverse KL

import numpy as np
import matplotlib.pyplot as plt
from scipy.optimize import minimize

# 真实教师分布：双峰（两个主要模式+小噪声）
x = np.linspace(-3, 3, 200)
teacher = 0.7 * np.exp(-(x+1)**2/0.3) + 0.3 * np.exp(-(x-1.5)**2/0.5)
teacher /= teacher.sum()

# 学生分布：单高斯 N(μ, σ²)
def student(x, mu, sigma):
    y = np.exp(-(x-mu)**2 / (2*sigma**2))
    return y / y.sum()

# 分别用 Forward KL 和 Reverse KL 优化学生参数
def forward_kl(params):
    s = student(x, params[0], params[1])
    return np.sum(teacher * np.log(teacher / (s + 1e-10)))

def reverse_kl(params):
    s = student(x, params[0], params[1])
    return np.sum(s * np.log(s / (teacher + 1e-10)))

# Forward KL 优化
res_fwd = minimize(forward_kl, [0.0, 1.0], bounds=[(-3,3), (0.1,2.0)])
# Reverse KL 优化
res_rev = minimize(reverse_kl, [0.0, 1.0], bounds=[(-3,3), (0.1,2.0)])

# Forward KL 学生：宽泛，覆盖两个峰
# → μ≈0, σ≈1.2 —— 试图覆盖整个教师分布
# Reverse KL 学生：尖锐，只追踪主峰
# → μ≈-1, σ≈0.3 —— 只追踪最大的那个峰
⚠️ 对 OPD 篇的关键预告

在线策略蒸馏（OPD）使用 Reverse KL。这意味着：

  • 学生只关注教师认为最可能的动作
  • 学生忽略教师不确定的区域 → 高效但有风险
  • 这既是 OPD 高效的原因（专注主要模式），也是它容易"熵崩塌"的根源

2.5 📐 蒸馏损失函数的完整形式

现在可以写出知识蒸馏的完整损失函数：

$$\boxed{\mathcal{L}_{\text{KD}} = (1 - \alpha) \cdot \underbrace{\mathcal{L}_{\text{CE}}(\mathbf{y}_{\text{true}}, \sigma(\mathbf{z}_S; T=1))}_{\text{硬标签损失（地面真相）}} + \alpha \cdot T^2 \cdot \underbrace{D_{KL}\big(\sigma(\mathbf{z}_T; T=\tau) \;\big\|\; \sigma(\mathbf{z}_S; T=\tau)\big)}_{\text{蒸馏损失（教师暗知识）}}}$$

其中：

符号含义典型值
$\mathbf{z}_T$教师 logits—
$\mathbf{z}_S$学生 logits—
$\tau$蒸馏温度2 ~ 20
$\alpha$蒸馏权重0.5 ~ 0.9
$T^2$梯度尺度补偿$\tau^2$

为什么蒸馏损失要乘 $T^2$？—— 梯度尺度的"隐形杀手"

当 $T$ 很大时，softmax 输出接近均匀分布，其梯度被显著缩小。我们来定量分析：

对 softmax 求导（使用商法则）：

$$\frac{\partial p_i}{\partial z_k} = \frac{1}{T} \cdot p_i \cdot (\delta_{ik} - p_k)$$

当 $T$ 较大时，$p_i \approx 1/N$（接近均匀），因此梯度约为 $\frac{1}{T \cdot N}(\delta_{ik} - \frac{1}{N})$。梯度量与 $1/T$ 成正比。

进一步，对于交叉熵损失 $\mathcal{L} = -\sum_i p_i^T \log p_i^S$，当 $p_i^T$ 和 $p_i^S$ 都接近均匀时，损失关于 student logits 的二阶梯度约与 $1/T^2$ 成正比。因此需要在蒸馏损失上乘以 $T^2$ 来补偿。

✅ 训练技巧速查
  • 推理时设置 $T=1$：蒸馏只在训练时使用高温
  • 教师冻结：torch.no_grad() 或 teacher.eval()
  • 温度调参：师生容量差距大 → 更高温度；任务简单 → 较低温度
  • $\alpha$ 调参：$\alpha \approx 0.9$ 时以蒸馏信号为主；纯蒸馏 ($\alpha=1.0$) 也能工作

2.6 🔬 数学本质：蒸馏到底在做什么？

从优化的角度看，蒸馏损失实际上是让学生输出的 logits 去逼近教师的 logits。

高温极限下的等价性（$T \to \infty$）：

$$p_i = \frac{1 + z_i/T + O(1/T^2)}{K + \sum_j z_j/T + O(1/T^2)} \approx \frac{1}{K}\left(1 + \frac{z_i - \bar{z}}{T}\right)$$

此时 KL 散度简化为：

$$D_{KL}(p_T \| p_S) \approx \frac{1}{2T^2} \cdot \frac{1}{K} \sum_i (z_i^T - z_i^S)^2$$
💡 核心洞察

当温度足够高时，蒸馏退化为在 logit 空间的均方误差回归。学生模型实际上在"模仿"教师的 logit 输出，而非仅仅匹配概率。教师 logit 包含了关于特征空间的拓扑结构信息——这种结构信息无法从硬标签中获取。这就是为什么蒸馏比从头训练更好：学生在学习一个更丰富、更结构化的目标。

🅰️ Response-based（响应式蒸馏）

这是 Hinton 的经典范式。学生只模仿教师的最终输出——最纯粹、最简单的蒸馏形式。关键变体：DKD（Decoupled KD, Zhao 2022）将 KL 解耦、"目标类"和"非目标类"分开处理，发现非目标类的知识才是蒸馏效果的关键；CTKD（Li 2023）温度动态调整；Logit Standardization（Sun 2024）对 logit 标准化后再蒸馏。

🅱️ Feature-based（特征式蒸馏）

FitNets (Romero et al., 2015) —— 开创者。在学生中间层插入适配层（regressor）：

$$\mathcal{L}_{\text{feature}} = \| \mathbf{W}_r \cdot \mathbf{F}_S - \mathbf{F}_T \|_2^2$$
class FeatureDistillationLoss(nn.Module):
    def __init__(self, student_dim, teacher_dim):
        super().__init__()
        self.regressor = nn.Sequential(
            nn.Linear(student_dim, teacher_dim),
            nn.ReLU(),
            nn.Linear(teacher_dim, teacher_dim))
    def forward(self, s_feat, t_feat):
        return F.mse_loss(self.regressor(s_feat), t_feat)

其他里程碑：Attention Transfer (2017) 匹配注意力图；FSP (2017) 匹配 Gram 矩阵；PKT (2018) 概率建模特征空间。

4.2 🏛️ Policy Distillation (Rusu et al., 2015)

📄 Policy Distillation — Google DeepMind, ICLR 2016

紧接 DQN 征服 Atari 之后。arXiv: 1511.06295。定义了 RL 策略蒸馏的三种模式，其中第三种就是 OPD 的雏形。

核心挑战：Q 值不是概率分布

RL 中 DQN 输出的是 Q 值——实数范围的无界标量。Rusu 的技巧：用温度 softmax 强行转换：

$$\boxed{p_T(a|s) = \frac{\exp(Q_T(s, a) / \tau)}{\sum_{a'} \exp(Q_T(s, a') / \tau)}}$$

三种蒸馏模式

模式数据来源意义
① 单任务蒸馏教师轨迹~15×压缩，性能不降
② 多任务蒸馏所有教师轨迹部分超越专家
③ 在线蒸馏学生自己生成轨迹← 🔥 OPD 原型！
🔥 第三种 = OPD 起源

学生用自己的轨迹训练，面对自己探索产生的状态分布，而非教师的分布。这是 OPD 最核心的特征。

🧪 极简实现：DQN 策略蒸馏

def policy_distillation_loss(student_q, teacher_q, T=0.01):
    """DQN策略蒸馏损失。Q值范围大，用较小温度0.01~0.1"""
    teacher_probs = F.softmax(teacher_q / T, dim=1)
    student_log_probs = F.log_softmax(student_q / T, dim=1)
    return F.kl_div(student_log_probs, teacher_probs,
                    reduction='batchmean') * (T * T)

def online_distillation_step(student, teacher, env, optimizer):
    """在线策略蒸馏：学生自己交互→教师给信号→学生更新"""
    trajectory = []
    state = env.reset()
    while not done:  # 学生自己的策略收集轨迹
        q = student(state); action = q.argmax().item()
        next_s, reward, done, _ = env.step(action)
        trajectory.append((state, action, reward, next_s, done))
        state = next_s
    states_t = torch.stack([t[0] for t in trajectory])
    with torch.no_grad(): teacher_q = teacher(states_t)  # 教师评分
    student_q = student(states_t)
    loss = policy_distillation_loss(student_q, teacher_q)
    optimizer.zero_grad(); loss.backward(); optimizer.step()
    return loss.item()

4.3 🎭 Actor-Mimic (Parisotto et al., 2016)

📄 Actor-Mimic — U. Toronto, ICLR 2016

两个关键扩展：① 学生用 ε-greedy 自生成轨迹；② Q 值阈值截断——教师也不确定的状态跳过蒸馏：

$$\mathcal{L}_{\text{distill}}(s) = \begin{cases} D_{KL}(p_T\|p_S) & \text{if } \max_a Q_T(s,a) > \theta \\ 0 & \text{otherwise} \end{cases}$$
