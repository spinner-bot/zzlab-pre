时代背景

RL 后训练：从文本到多模态的迁移

2025–2026 年间，GRPO、DAPO、PPO 等强化学习方法在纯文本 LLM 上取得显著推理能力提升：

🔹 DeepSeek-R1：纯 RL 驱动的推理涌现
🔹 Qwen3：RLVR 规模化验证

然而，当这些范式迁移到多模态模型（MLLM / LVLM / LALM）时——遇到了三个根本性瓶颈。

⚠️ 三大瓶颈：RL 后训练在多模态的困境

瓶颈 1
稀疏奖励
Sparse Reward
可验证奖励仅对最终答案打分，失败 rollout 中每个 token 获得相同惩罚 → 信用分配失效，模型无法区分「看错」vs「推错」
瓶颈 2
感知-推理耦合退化
Entanglement
RL 优化可能牺牲视觉感知换取文本推理的奖励提升 → 模型学会「蒙答案」而非「读图」→ shortcut learning
瓶颈 3
分布漂移
Distribution Drift
SFT 基于静态数据，RL 基于自采样轨迹 → 两分布 gap 导致训练不稳定，甚至灾难性遗忘

瓶颈 1 深度分析

稀疏奖励 → 信用分配失效

RL 后训练的标准范式是 RLVR（RL with Verifiable Rewards）：模型生成完整 rollout，用验证器给最终答案打分。但——

❌ 每条失败的 rollout 中，每个 token 获得相同的惩罚信号

这导致根本性的信用分配（Credit Assignment）问题：

🔸 模型不知道是「看错了」（视觉编码器提取了错误的特征）
🔸 还是「推错了」（语言解码器在正确特征上推理失败）

对于纯文本 LLM，这还可以接受（只有一种模态）；但对于 MLLM，视觉感知的错误和文本推理的错误被混为一谈，优化信号完全模糊。

瓶颈 2 深度分析

感知-推理耦合退化 → Shortcut Learning

RL 优化的目标是最大化最终答案奖励。在多模态场景下，这产生了一个危险的捷径：

模型可以通过「猜测」正确答案的文本质地
来获得高奖励，而不真正依赖图像内容

具体机制：

🔸 RL 梯度倾向于增强「奖励最大化的路径」
🔸 如果文本先验（language prior）已足够强 → 图像信号被边缘化
🔸 最终：模型在 benchmark 上分数可能不降，但视觉基础（visual grounding）完全丧失

这是笔记 03 中讨论的 shortcut learning 问题在 RL 阶段的复现——而且比 SFT 阶段更隐蔽，因为 RL 的探索机制会主动寻找这类捷径。

瓶颈 3 深度分析

分布漂移 → SFT → RLVR 的鸿沟

主流的 MLLM 后训练 pipeline 是两阶段串行：

📌 第一阶段 SFT：在静态标注数据上监督微调，数据分布固定
📌 第二阶段 RLVR：模型自采样轨迹，用奖励模型打分

两个阶段的数据分布之间存在本质 gap：

🔸 SFT 阶段：模型「阅读」人类写好的教材
🔸 RL 阶段：模型「自己解题」，但题目来自它自己的生成分布

后果：训练不稳定、loss 剧烈震荡、灾难性遗忘（RL 阶段损失 SFT 已学到的能力）。这一 gap 在多模态模型中比纯文本模型更大——因为模态间的对齐本身就很脆弱。

解决方案

💡 OPD / OPSD 的核心洞见

核心理念
学生用自己的策略生成轨迹 → 教师在相同轨迹上提供逐 token 密集监督 → 对齐两者的分布。

与传统 RL 的稀疏序列级奖励不同，OPD 提供：

✅ 逐 token 的密集信号 → 信用分配问题被自然解决
✅ 教师与学生共享轨迹 → 感知-推理耦合可被诊断和分离
✅ 分布匹配而非奖励最大化 → 缓解 SFT→RLVR 的分布漂移

在多模态语境下，教师和学生通常是同一模型的冻结副本和训练副本——区别仅在于教师看到了特权信息（privileged information）。

数学框架

OPD 的核心公式

在 on-policy 轨迹上的分布匹配：

$$\mathcal{L}_{\text{OPD}} = \sum_{t} D_{\text{KL}}\big(p_{\theta_{\text{old}}}(\cdot|x_{\text{priv}}, y_{<t}) \;\|\; p_\theta(\cdot|x_{\text{student}}, y_{<t})\big)$$

其中：

🔸 p_θold：教师（冻结副本），条件为 $x_{\text{priv}}$ = 含特权信息的输入
🔸 p_θ：学生（训练副本），条件为 $x_{\text{student}}$ = 标准推理输入
🔸 D_KL：KL 散度（Forward KL / Reverse KL / JSD 视场景而定）
🔸 y_<t：前缀 token 序列（学生自采样的轨迹上下文）

本质上，这是在学生自己走出的路上，用教师的分布作为参照——而非让教师划定一条最优路径让学生盲从。

自蒸馏本质

为什么多模态 OPD 偏爱自蒸馏？

多模态 OPD 中，教师和学生通常是同一个模型的冻结副本和训练副本——这被称为 OPSD（On-Policy Self-Distillation）。

为什么是自蒸馏？

✅ 效率：无需依赖更大的外部模型（外部多模态教师稀缺）
✅ 数据瓶颈：多模态推理数据极度稀缺，自蒸馏可利用无标签图文对
✅ 跨模态对齐：同一模型架构保证教师-学生之间的特征空间兼容

教师与学生的唯一区别：

教师看到了「特权信息」——训练时可用、推理时无法获取的额外信息

特权信息

👑 什么是"特权信息"？

定义
特权信息（Privileged Information）是只在训练时可用、推理时无法获取的"开卷答案"。在标准教师-学生框架中，教师和学生看到同样的输入；而在特权教师设定中，教师能额外获得训练时独有的信息——就像老师拿着标准答案批改作业，考试时谁都看不到答案。

特权信息在 OPD 中的角色：

🔸 提供更高质量、信息更丰富的监督信号
🔸 提升学生模型的学习上限
🔸 但如果使用不当 → 特权幻觉（Privilege Illusion）

风险警示

⚠️ 特权幻觉（Privilege Illusion）

如果特权信息设计不当，会引发一系列连锁问题：

🔸 能力假象

教师的高性能源于信息不对称，而非真正的推理能力

🔸 学习偏差

学生模仿的是利用特权的「捷径」，而非可迁移的推理能力

🔸 泛化失败

学到的能力依赖特权 → 推理时无法获得 → 完全失效

🔸 训练崩溃

模型过早收敛（熵崩塌），甚至后期性能下降

🔸 抑制探索

学生被"喂答案" → 主动探索能力被摧毁

🔸 灾难性遗忘

特权移除后，模型性能断崖式下跌

🔑 特权信息的三种获取方式

方式一 · 高风险
📝 标准答案 / 推理链
教师直接使用标准答案（Ground Truth）或完整推理链（CoT）作为特权。教师「看着答案说理由」，表现虚高。
⚠️ 致命陷阱：学生学到的是「如何映射到答案分布」而非「如何看图理解」→ 熵崩塌 · 捷径学习
方式二 · 中风险
👁️ 视觉线索 · ViCuR
不告诉答案，只告诉「看哪里」——教师看到图像 + 高亮区域/边界框，学生仅看完整原图。
✅ 优势：学生学会「自动聚焦」能力 → 训练-推理较一致
⚠️ 风险：需区域标注，可能过度依赖视觉分支
方式三 · 零风险
🔬 局部感知 · Vision-OPD
完全不引入外部数据或标签。教师看裁剪的局部特写（细节清晰），学生看模糊全局图（视野广但细节丢失）。学生从全局中恢复教师从局部提取的特征。
✅ 最优：零外部依赖 · 训练推理完全对齐 · 强迫空间注意力缩放机制

核心风险

⚠️ 多模态 Shortcut：文本捷径的隐秘侵蚀

PALR 诊断 (Privileged Answer Leakage Rate) — ViGOS (2026.06)
跨三个基准的测量显示：17–26% 的 token 级监督来源于文本参考而非图像内容。教师传递的信号中，近四分之一是「答案驱动」而非「图像驱动」——学生被悄悄教会了「蒙答案」。

这意味着什么？

🔸 教师（冻结副本）给学生（训练副本）的监督信号中，有相当比例来自语言的统计相关性，而非视觉证据
🔸 学生在 OPD 过程中发展不均：文本推理能力飞速提升，视觉基础能力原地踏步
🔸 最终模型在 benchmark 上分数不降 → 但视觉注意力已悄然发散 → 幻觉、错误绑定随之而来

这是 Part 0 中「感知-推理耦合退化」的精确量化：RL/OPD 优化机制本身就会系统性地偏向文本捷径。

KL 散度战场

🔥 Forward KL：在视觉 token 上的灾难

Forward KL 的本质：Mode-Covering（模式覆盖）
$$\min_{\pi_S} D_{KL}(\pi_T \|\pi_S) = \min_{\pi_S} \sum \pi_T \log \frac{\pi_T}{\pi_S}$$ 学生必须覆盖教师的所有高概率区域——只要教师有概率的地方学生给不够，惩罚就爆炸。学生被迫保留所有可能性。

为什么视觉 token 上尤为严重？

🔸 视觉 token 天然高熵、多义——同一图像块可能对应多种合理描述，教师分布平滑、无锐利峰值
🔸 文本 token 有明显峰值（某个词往往是唯一正确），但视觉是宽泛的「语义场」
🔸 Forward KL 强制学生去匹配这个宽泛的支持集 → 学生把概率质量撒在极大空间上

📊 结果：熵爆炸——学生输出的视觉分布熵极高，丧失判别力，注意力发散

直观比喻：考试制度被恶意利用——学生发现把所有选项涂一点（全均值分布）就能在 Forward KL 下得「不错」的分数，于是心安理得地停在模糊状态，永远学不会精确的视觉辨别。

KL 散度战场

💎 Reverse KL / JSD / Top-K JSD 的救赎

🔄 Reverse KL · Mode-Seeking

$$\min_{\pi_S} D_{KL}(\pi_S \|\pi_T)$$ 学生只追教师的峰值——在教师低概率区浪费概率会被严惩。对抗熵爆炸，学生视觉决策变「尖」。代价：可能丢失多样性，但在多模态理解中锐度 > 多样性。

⚖️ JSD · 对称折中

$$\frac{1}{2}D_{KL}(\pi_T\|M)+\frac{1}{2}D_{KL}(\pi_S\|M)$$ 其中 \(M=(\pi_T+\pi_S)/2\)。不过度覆盖也不过度追寻，在锐度和多样性之间平衡。对视觉 token 既减轻熵爆炸，又不陷入极端模式崩塌。

✂️ Top-K 截断 · 噪声修剪

先截断教师分布到 Top-K，只在这 K 个 token 上计算散度。进一步排除尾部噪声——很多视觉 token 概率在教师那也是均匀噪声，直接裁剪掉避免学生浪费容量拟合无意义的背景模式。

💡 一句话：Forward KL = "覆盖所有可能"（被恶意利用→全均值） → Reverse KL = "精准命中峰值"（模型被迫学会真正的视觉辨别） → JSD / Top-K 是进一步的保险

横轴：教师-学生关系  |  纵轴：蒸馏目标类型

范式 ①

🟣 同模型跨上下文 OPSD

核心论文：Vision-OPD · Visual-OPSD · ViGOS · ViCuR

核心问题
如何在不依赖外部教师模型、不需要额外标注数据的情况下，提升 VLM 的视觉理解鲁棒性？
核心思想
教师和学生是同一个模型，只是看到的视觉上下文不同。教师=冻结副本看完整/高质量图像；学生=训练副本看被破坏/受限的视觉上下文。目标：让学生从部分推断整体。

运作机制：

① 冻结一份预训练 VLM 作为教师 → ② 同一图像，学生看裁剪版、教师看完整版 → ③ 同一问题，教师产生完整视野输出分布，学生产生受限视野分布 → ④ Reverse KL / JSD 让学生模仿教师的分布

✅ 零外部依赖：不需要更强的教师，不需要新数据，只需已有的图文对

典型实例：Vision-OPD 的 crop-vs-full 自蒸馏 → 将「视觉放大」能力内化到模型中，而非依赖推理时外部工具调用。

范式 ②

🔴 跨模态教师蒸馏

核心论文：VOLD · X-OPD · CORD · SightSound-R1

核心问题
如何将一种模态上已经训练好的强能力，迁移到另一种模态的模型上？（text LLM 推理能力 → VLM；VLM 视觉理解 → 音频模型）
核心思想
教师和学生来自不同模态，输入/输出空间可能完全不同。必须让学生在自己的模态里采样轨迹，教师评估轨迹质量后提供反馈——这正是"在线"的不可替代之处。

运作机制（四步）：

① 冷启动 SFT 对齐（必需前置）→ ② 在线采样：学生在目标模态生成轨迹 → ③ 教师评估：似然度打分 / 生成参考轨迹 / 价值函数评估 → ④ 策略更新：根据教师信号进行 RL 更新 + KL 约束防偏离

📌 关键：冷启动 SFT 是必不可少的——没有它，文本教师的分布与 VLM 学生的采样分布差距过大，蒸馏完全失败（VOLD 的核心发现）

典型场景：VOLD（Text LLM→VLM）· X-OPD（VLM→语音LLM）· SightSound-R1（多模态推理链蒸馏）

范式 ③

🟡 OPD + RL 混合系统

核心论文：PRISM · PTD-PO · HDPO · Distill-R1

核心问题
多模态任务的奖励通常极其稀疏（只有最终答案对错、生成质量评分），纯 RL 探索极难。如何提供逐 token 密集信号引导探索，同时保留 RL 对稀疏奖励的优化能力？
$$\mathcal{L} = \mathcal{L}_{\text{RL}} + \lambda \cdot \mathcal{L}_{\text{OPD}}$$

OPD 扮演的两种角色：

🔸 预对齐阶段：先用纯 OPD（大量教师数据）让学生学会基本合理行为，避免 RL 阶段从零开始乱撞
🔸 辅助损失（软护栏）：RL 训练中 OPD 损失一直存在，防止策略为追求稀疏奖励而崩溃——如防止模型为拿高分而输出乱码

典型论文：PRISM（黑盒对抗 OPD 预对齐）· PTD-PO（特权辅导+偏好优化）· Distill-R1（SFT蒸馏→RL微调的标准框架）

💡 核心挑战：λ 权重的平衡——OPD 太强→学生不敢探索；OPD 太弱→RL 阶段崩溃

范式 ④

🟢 生成式 OPD

核心论文：D-OPSD · LiveTalk · OmniOPSD

核心问题
如何将 OPD 从离散 token 的自回归生成，扩展到扩散模型等连续生成任务？——传统 KL 散度无法直接用于连续潜空间。
核心思想
学生采样噪声轨迹，教师用更强的多模态条件提供更准确的速度场/分布预测。「动作空间」从离散 token 变成了连续的去噪向量，但「在线策略」的灵魂完全保留——学生在自己搞出来的局面上接受纠正。

运作机制（与范式①—③的本质差异）：

① 学生（扩散模型）在潜空间采样噪声轨迹（随机噪声→生成图像的每一步中间状态）
② 教师（更强的扩散模型 / 带多模态条件）对同一中间状态预测更优的去噪方向
③ 蒸馏损失 = MSE / 余弦相似度（非 KL 散度）：学生预测的噪声 vs 教师预测的噪声

🔑 关键突破：OPD 从离散分布匹配 → 连续向量回归，扩散模型的去噪步骤天然构成"轨迹"，在线策略框架完美迁移

典型场景：D-OPSD（图像扩散）· LiveTalk（语音驱动数字人）· OmniOPSD（全模态生成）

奠基之作

🏛️ VOLD：文本 → VLM 的推理迁移 (CVPR 2026)

Walid Bousselham, Hilde Kuehne, Cordelia Schmid · arXiv:2510.23497

核心问题
多模态推理数据极度稀缺（图文+推理链标注成本极高），但纯文本推理数据丰富——能否将文本 LLM 的推理能力蒸馏到 VLM？
方法：GRPO + On-Policy Distillation
VLM 学生自采样轨迹 → 文本 LLM 教师在相同轨迹上提供 token 级分布监督 → 学生模仿教师的推理分布。关键在于：教师和学生看到的是同一问题，但教师只有文本输入、学生有图文输入。
⚠️ 关键发现
冷启动 SFT 对齐是必不可少的——没有它，文本教师的分布与 VLM 学生的采样分布差距过大（模态鸿沟），蒸馏完全失败。这是跨模态蒸馏的铁律。

基准：MMMU-Pro · MathVision · MathVista · LogicVista  |  意义：被 CVPR 2026 收录，成为后续所有 VLM OPD 工作的核心参考点。

自蒸馏 · 范式①典范

🔬 Vision-OPD：区域→全局的自蒸馏 (2026.05)

Qianhao Yuan 等 · arXiv:2605.18740

核心发现：区域到全局的感知差距
MLLM 在证据中心裁剪（crop）上回答细粒度问题的准确率显著高于全图条件。这意味着模型具备「看细节」的能力，但不具备在全图上下文中调用该能力的策略——就像有显微镜但不知道往哪看。

👨‍🏫 教师（冻结副本）

条件为裁剪后的证据区域（privileged crop）——细节清晰可见

🎓 学生（训练副本）

条件为完整图像（标准推理条件）——视野广但细节模糊

损失：token 级 KL 散度 · 零外部依赖：无需外部教师、无需 GT 标签、无需奖励验证器、无需推理时工具

💡 证明「视觉放大」能力可通过自蒸馏内化到模型中——而非依赖推理时外部工具调用

自蒸馏 · 里程碑

⚡ Visual-OPSD：14.3× 加速 · 学生超越教师 (2026.06)

Pengyu Li 等（西安交大）· arXiv:2606.18974 · github.com/TiezMind/Visual-OPSD

核心发现（极具洞察力）
统一多模态模型（UMMs）中，生成式「视觉思维」（Visual Thoughts, VTs）通过多步扩散生成，推理成本≈纯文本的 14 倍（142.8s vs 10.0s/sample），但——移除或扰动 VTs 几乎不改变准确率。渲染的像素本身不是答案载体，但生成路径中编码了有效的推理知识。

👨‍🏫 教师

UMM · 条件为生成的 VTs（特权视觉思维，需14步扩散）

🎓 学生

UMM · 条件仅为文本问题（无视觉思维生成步骤）

损失：token 级 JSD · 沿学生 on-policy 轨迹

🎯 +3.40pp 超越生成式教师 · 14.3× 推理加速 · VSP 基准 +63.83pp

深层启示：多模态推理中，关键信息比显式像素承载的多得多——蒸馏可以提取出比教师更强的推理能力。

第三波浪潮

⚠️ 防 Shortcut 三连：2026.06 的同频共振

2026 年 6 月，三篇独立论文几乎同时指出多模态 OPSD 的核心风险——教师特权信息可能引导学生走「文本捷径」而非利用视觉证据——并各自提出不同方案：

🔴 ViGOS · 诊断者

提出 PALR 指标首次量化 Shortcut 严重程度（17–26%），用三教师解耦：图像感知教师+特权推理教师+参考教师，让视觉由视觉监督、推理由推理监督。

🟣 ViCuR · 重构者

重新定义特权设计原则：「可恢复特权」优于「不可恢复特权」。将教师特权从「答案侧」替换为「视觉线索」（证据区域标注），建立训练-推理一致性。

🟢 V-Zero · 激进者

完全不需要文本答案标签——只需图文对。用正/负视觉证据视图的对比差异判断学生回答的视觉基础，门控调节蒸馏强度。5× 快于 SFT、10× 快于 RL。

💡 三篇同期论文，三种不同哲学——分别从诊断、重构、抛弃三个角度解决了同一个核心问题。

防 Shortcut · 诊断者

🔴 ViGOS：三教师解耦 + PALR 诊断 (2026.06)

Sihan Wang 等（中科院）· arXiv:2606.19120

核心发现：PALR 首次量化 Shortcut 严重程度
PALR（Privileged Answer Leakage Rate）——跨三个基准测量显示 17–26% 的 token 级监督是「答案驱动」而非「图像驱动」。首次用数据证明：多模态 OPSD 的教师信号被文本捷径污染了近四分之一。

方法：三教师解耦架构

👁️ 仅图像感知教师

监督视觉描述段落（不接触参考答案）。确保图像内容的描述来自视觉证据，而非文本先验。

🧠 特权推理教师

监督推理/答案段落（接触参考答案），但仅作用于推理段。将文本引导限定在合理范围。

🔄 参考教师

仅在学生 rollout 无效时介入，用于格式恢复。不参与正常内容的蒸馏，避免干扰。

💡 核心哲学：让视觉描述由视觉监督，让推理由推理监督——将 OPSD 的监督信号按来源解耦。

防 Shortcut · 重构者

🟣 ViCuR：可恢复特权 — 不告答案，只告「看哪里」(2026.06)

Kanghui Tian 等 · arXiv:2606.05718

核心洞察
在多模态 OPD 中，教师特权的设计与教师强度同等重要。如果特权信息在推理时不可获得（如参考答案），学生永远无法真正学会在没有特权时表现好。→ 「可恢复特权」优于「不可恢复特权」。

❌ 旧范式：答案侧特权

教师看到参考答案/推理链 → 学生无法自己恢复 → 训练-推理不一致 → 特权幻觉

✅ 新范式：视觉线索特权

教师看到图像证据区域（如高亮/边界框）→ 学生通过提升视觉注意力有可能自己恢复 → 训练-推理一致

💡 ViCuR 重新定义了多模态 OPD 的特权设计原则：特权应该是学生「可能学会自己找到的东西」——而非永远无法企及的外部答案。

防 Shortcut · 激进者

🟢 V-Zero：不需要答案标签的 OPD (2026.06)

Haoxiang Sun 等（川大·北大·TeleAI）· arXiv:2606.25319

核心突破
完全不需要文本答案标签的 OPD——只需图文对（问题和图像），无需答案、无需奖励函数。这是多模态 OPD 最激进的范式：连答案都不需要，怎么知道对错？→ 让教师评价学生回答的「视觉基础」强弱。
核心思想
教师虽然没有正确答案，但它有一个特权——同时看到两种版本的图像：① 正视图（目标区域裁剪放大）② 负视图（目标被替换/模糊）。如果学生的回答在正视图下概率高、负视图下概率低 → 视觉基础强 → 值得蒸馏；反之 → 可能是蒙的 → 抑制蒸馏。

效果：Qwen3.5-4B +3.1 平均分  |  训练速度 5× 快于 SFT、10× 快于 RL 基线

💡 意义：如果 V-Zero 范式被广泛验证，训练强视觉推理模型只需海量图文对——互联网上到处都是——完全不需要人工标注答案。

解耦感知与推理

🟡 PeRL-VL：门控奖励解耦感知与推理 (2025.12)

Yoon 等 · arXiv:2512.12487

核心问题
RLVR 能让模型学会推理，但存在奖励黑客（Reward Hacking）：模型用语法正确但无视觉依据的回答蒙混过关——验证器只看答案对错，不检查视觉依据。

📝 两个教师角色

推理教师：冻结 VLM，保持文本推理能力

描述评判：评分模块，对视觉描述打两个维度——忠实性（无幻觉？）+ 充分性（信息够不够？）

🔑 门控奖励组合

不是简单相加！动态调节权重：视觉描述占比高→描述奖励权重↑；纯文本推理→推理奖励权重↑。这直接抑制了纯文本 reward hacking 捷径。

效果：Qwen2.5-VL-7B 从 63.3% → 68.8% Pass@1  |  验证了分解+门控 > 单一奖励+简单聚合

解耦感知与推理

🟣 Decomposed OPD：VGS 梯度重定向 (2026)

Yoon 等 · Semantic Scholar (2026)

核心问题
标准在线蒸馏损失（KL 散度）整体计算，无法区分梯度中「语言先验成分」和「视觉基础成分」——视觉学习的梯度被语言部分淹没，模型在语言上自我陶醉、忽视看图。
$$\nabla_\theta \mathcal{L} = g_{\text{lang}} + g_{\text{vis}}$$

g_lang：语言模块（LLM注意力、FFN）的梯度分量 · g_vis：视觉模块（编码器、跨模态注意力）的梯度分量

VGS（Visual Gradient Steering）— 三步操作
① 检测当前梯度方向是否偏向语言子空间 → ② 若偏向语言，放大 g_vis 范数或将总梯度向视觉子空间旋转 → ③ 视觉模块获得不成比例的高质量梯度 → 从梯度流动的最底层纠正多模态蒸馏的不平衡。

💡 相当于训练时不断「提醒」模型：你的视觉部分还很弱，别老在语言上自我陶醉，多练练看图！

核心挑战

🔴 稀疏序列级奖励 → 信用分配失败

什么是「稀疏序列级奖励」？
在视频多模态任务中，奖励只在整个视频回答序列生成完后才给一次。比如看一段 10 分钟的做饭视频，问"他放了几勺盐？"，只有最终答案完全正确才给 +1，否则 0。在这条包含几百上千 token 的长推理链中，中间没有任何奖励信号告诉模型"你看懂了这段没"。
什么是「信用分配」（Credit Assignment）问题？
序列结束得到最终奖励时，怎么知道序列里哪一步做对了、哪一步做错了？视频中错误可能发生在：① 视觉识别阶段（勺子→叉子）② 时序关联阶段（第二次放盐误判为第一次）③ 推理阶段（识别都对但计算错了）。从稀疏奖励中，模型完全不知道哪一步导致了失败——就像考试错了却不知道哪道题错了一样。

⚡ 这就是 OPD 被引入视频任务的根本动因：将稀疏信用分配变成密集信用分配。

视频的特殊性

⚠️ 为什么视频场景特别严重？

📏 ① 视频序列极长

视频天然包含几十上百帧，每一步分析都依赖前面累积的理解。信用分配的延迟被几十倍放大——文本推理可能只需回溯几十 token，视频推理需回溯数百帧的视觉理解。

🔗 ② 错误累积效应

早期的一个视觉误判（比如没看清手里拿的什么）会在后续几十步推理中被当成事实，最终导致离谱结论。但最终奖励只会告诉你结论错了，不会指出那个最初的小错误。

🎲 ③ 纯 RL 探索无效

模型尝试修正自己，但因为不知道哪里错了，只能随机乱改。在海量 token 空间中，几乎不可能偶然碰对正确答案——RL 训练毫无进展。

对比文本域
文本推理的信用分配虽然也有延迟，但至少 token 本身就是离散符号，错误模式相对可诊断。视频中视觉表征是连续高维向量，错误不仅难以定位，甚至难以定义——"看错了"本身就是一个模糊的概念。

💡 结论：视频任务需要细粒度的时间理解，纯 RL 的稀疏反馈无法胜任。

OPD 解决方案

💡 OPD：将稀疏信用分配变成密集信用分配

❌ 纯 RL（GRPO 等）

• 仅在序列结束给一次稀疏奖励
• 不知道中间哪步错 → 随机探索
• 长视频中 8-16 rollout/步 → 计算灾难
• 信用分配延迟被几十倍放大
• 模型在黑暗中摸索

✅ OPD（教师逐 token 监督）

• 教师提供逐 token KL 散度监督
• 每一步偏差即时纠正 → 精准定位错误
• 单 rollout 即可高效训练
• 密集监督消除信用分配延迟
• 每一步都有老师盯着

核心转变
在学生自己采样生成的错误分析步骤（如错误识别了物体），教师立即在这一步给出高 KL 散度信号，指明"你这里不应该这么描述，应该像我这样描述"。不需要等到整个视频回答结束——每一步的偏差都被即时纠正。

🎯 本质：将「不知道哪步错了」的稀疏信用分配 → 「每一步都有老师盯着」的密集信用分配

核心论文

📄 Video-OPD：时序视频定位的高效 OPD 后训练

Jiaze Li, Hao Yin 等 · arXiv:2602.02994 (2026.02, 2026.06修订)

目标场景：时序视频定位（Temporal Video Grounding, TVG）
给定一段长视频和一个自然语言查询，模型需要定位出与查询对应的时间片段。这是视频理解的经典难题，需要同时理解视觉内容和时序结构。
GRPO 类方法（如 Time-R1）的两大致命缺陷
① 稀疏序列级奖励：只在最终定位结果上给奖励，无法对视频中间的视觉理解错误进行信用分配。
② 多 rollout 计算灾难：每步需要 8-16 个完整 rollout，在长视频上计算成本 prohibitive。
Video-OPD 的核心方法
① 逐 token Reverse KL 散度：用固定前沿教师（frontier teacher）的 token 级分布监督替代稀疏序列级奖励。
② 严格 on-policy：所有训练轨迹由当前策略采样，确保分布一致性。
③ TVDF 课程策略：优先训练教师-学生分歧大的轨迹（详见下页）。

核心机制

🔑 TVDF：Teacher-Validated Disagreement Focusing

TVDF 是一种课程学习策略，确保每条训练轨迹要么可靠、要么信息量大：

Step 1
学生采样轨迹
当前策略生成
时序定位的完整推理链
→
Step 2
教师验证
前沿教师在相同轨迹上
评估 token 级分布差异
→
Step 3
分歧度计算
KL 散度大的轨迹 =
学生理解薄弱的区域
→
Step 4
课程优先级
分歧大 → 优先训练
分歧小 → 后训练/跳过

✅ Teacher-Validated（教师验证通过）

教师-学生分布高度一致 → 轨迹可靠 → 作为正样本巩固正确行为

⚡ Max Informative（最大信息量）

教师-学生分布分歧大 → 学生理解薄弱 → 作为重点样本优先纠正

💡 TVDF 的核心洞见：不是所有轨迹都值得同等对待——让模型把算力花在它最不懂的地方。

🔮 PF-OPSD：特权未来自蒸馏 — 世界模型 + MLLM

Yucheng Zhou 等 · arXiv:2606.03603 (2026.06)

核心概念：将世界模型与 MLLM 融合

音频域特殊性

⚠️ 为什么音频标注数据比图像稀缺得多？

这个问题的答案触及了多模态数据生态的底层差异。音频标注数据比图像稀缺得多，背后是采集成本、标注效率、数据特性、应用生态四个维度的系统性落差。

🔴 信息密度与标注效率

图像是瞬间信息——看一眼毫秒级理解。音频是时序信息——必须完整听完才能判断发生了什么。标注一段30秒的音频至少花30秒听+写描述+切时间段，成本是图像的数十倍。

🟣 采集与获取的自然壁垒

互联网天生是视觉的——CLIP用4亿图文对直接从网上爬取。音频受隐私限制（对话含敏感信息）、环境控制（信噪比难保证）、缺乏"音频Instagram"——不存在大规模附带精细描述的音源平台。

🟢 类别体系与应用生态

图像有ImageNet（2万类/1400万张）、COCO等积累了十多年。音频主要数据集AudioSet虽有200万段，但标签是弱标注（视频级，无时间定位）。下游应用生态的马太效应：CV有自动驾驶/安防/医疗驱动，通用音频理解商业应用一直较窄。

端到端语音LLM在各种基准上的表现始终落后于其文本对应物——平均差距 11.29%（语音基准）和 5.51%（文本基准）。这种"cross-modal alignment gap"是语音LLM实用化的核心障碍。

范式2典范 · 内部教师

🎯 CORD：加权On-Policy跨模态蒸馏 (2026.01)

arXiv:2601.16547

核心方法：单一模型内的跨模态蒸馏
在单一模型内使用文本模态作为内部教师、音频模态作为学生——无需外部教师模型。结合 token级Reverse KL（重要性感知加权）和序列级GRPO，仅需 80k 合成样本即可实现一致的音频条件推理提升。
为什么用Reverse KL？
音频token分布天然高熵——Forward KL强制学生覆盖教师所有高概率区域会导致熵爆炸，学生输出模糊的"全均值分布"。Reverse KL通过mode-seeking让学生精准命中教师峰值，在音频这种天然高熵模态中保持判别力。结合重要性感知加权——对教师分布中置信度更高的token赋予更大权重，进一步压制噪声。
关键意义
OPD在极小数据规模下仍然有效——80k合成样本对比典型视觉域动辄百万级数据，差距达1-2个数量级。这证明了OPD是音频/语音域数据效率最高的训练范式。

适用域分析

🎯 "正向容易 · 逆向困难"：OPD+RLVR 的黄金地带

核心洞察
RLVR 适用的前提条件：存在一个客观的、可自动计算的单向验证函数。正向判别廉价且无歧义（给你结果 → 瞬间判断对错），逆向生成搜索空间巨大（给你需求 → 生成正确结果极难）。这正是 OPD+RLVR 量身定做的场景。

✅ 正向判别容易

• 代码 → 运行测试（毫秒级）

• 数学表达式 → 代入验证

• 动作序列 → 物理引擎仿真

• 棋局 → 终局胜负规则

• SQL → 返回结果集比对

• 化学合成路线 → 产物验证

❌ 逆向生成困难

• 需求 → 正确代码（空间巨大）

• 问题 → 完整推理链

• 目标 → 最优动作序列

• 初始状态 → 获胜策略

• 自然语言 → 精确查询

• 目标分子 → 合成路径

"单项"不是指简单，而是指存在可自动计算的单向验证函数。只要这个条件成立，RLVR 提供无偏终极信号，OPD 提供过程护航。

形式在变，本质未变：只要存在「教师有更多上下文 → 更强预测」的信息不对称，OPSD 就可以工作。文本域的特权是标准答案 / 推理链，视觉域的特权是视觉线索 / 局部感知——而扩散域的特权，是目标图像本身的多模态特征。这证明 OPSD 不是 LLM 特化的技巧，而是一种通用的分布匹配范式。

论文 ① · 图像扩散

D-OPSD：步蒸馏扩散模型的在线自蒸馏

On-Policy Self-Distillation for Continuously Tuning Step-Distilled Diffusion Models

Dengyang Jiang 等 · 阿里巴巴 Z-Image × 港科大 × UCSD × 港中文 · arXiv 2605.05204（2026.05）· 项目页 vvvvvjdy.github.io/d-opsd

🎯 要解决的问题 — 步蒸馏模型的持续调优
少步（step-distilled）扩散模型已把采样压缩到几步，但要持续定制新概念 / 新风格时，传统微调容易破坏来之不易的少步生成能力，且依赖偏好数据或奖励模型。
💡 核心发现 — 扩散模型继承了编码器的上下文学习能力
现代扩散模型以 LLM/VLM 作为条件编码器——D-OPSD 发现这类模型继承了编码器的 in-context learning 能力：同时输入文本提示 + 目标图像的多模态特征作为条件时，模型无需任何额外训练，就能生成保留目标概念 / 风格的变体图像。
🔗 这正是「教师」的免费来源 — 自蒸馏闭环
教师不必是更大的外部模型：同一个模型 + 更多条件（目标图像特征）= 更强的特权副本。这与 Part 0 的结论一脉相承——多模态 OPD 偏爱自蒸馏，因为特权信息让冻结副本天然强于训练副本，而在扩散域，这份特权「免训练」即可获得。

论文 ① · 优势与意义

D-OPSD：三大关键优势

✅ 在线策略 · 零分布偏移

始终在学生自身的 rollout 上优化——训练时看到的状态就是推理时会遇到的状态，从根源上消除训练-推理分布偏移。这正是 Part 0 三大瓶颈中「分布漂移」的扩散域解法。

✅ 无需奖励模型

仅需图文对即可训练：不需要偏好数据、不需要 reward function、不需要人工标注。对比 RLHF/DPO 式的生成模型对齐，数据门槛大幅降低。

✅ 学新不忘旧

LoRA 定制与全量微调两种方式下，均保留原始的少步生成能力——持续加入新概念 / 新风格而不牺牲步蒸馏成果，与具身域（Part 5）的抗遗忘结论互相印证。

🌌 深层意义 — OPSD 是通用的分布匹配范式
D-OPSD 证明 OPSD 不是 LLM 特化的技巧。它的成立条件只有一条：存在「教师有更多上下文 → 更强预测」的信息不对称。策略分布、速度场、生成分布——任何可采样、可对齐的分布，都能套用「学生 on-policy 采样 + 特权教师逐步监督」这一模板。OPD 的边界由此从判别模型正式扩展到整个生成式建模。

多教师仲裁

🟣 H-OPD：异构多教师 Token 级仲裁 (2026.07)

Qixiang Yin 等（北邮·字节跳动·中科大）· arXiv:2607.02592

关键洞察
现有 OPD 使用静态教师路由（按模态/任务分配教师），但不同的解码步骤需要不同的教师专长——视觉基础步需要 VLM 教师（知道图像里有什么），抽象推理步需要文本 LLM 教师（逻辑更强）。

❌ 静态路由

整个序列固定用同一个教师 → 视觉步被迫接受文本教师的弱视觉监督 → 推理步被 VLM 教师的弱推理拖累

✅ Token 级动态仲裁

每步置信度感知动态决定哪个教师更可信 → 视觉步用 VLM、推理步用文本 LLM、边界步两者融合

三大技术组件
① Token 级教师仲裁：沿共享学生轨迹每步动态选最优教师 ② 视觉到语言描述迁移：让纯文本教师也能访问视觉语义 ③ 置信度感知仲裁机制：动态融合 VLM 和文本教师在每个 token 的预测。

评估：11 个推理基准  |  意义：如同 MoE 中不同专家负责不同 token，未来 OPD 每个 token 都由最优教师组合监督

注意力级优化

🔴 RAL：优化"看哪里"，而非"说什么" (2026.02)

Bangzheng Li 等（UC Davis·Princeton·Google·DeepMind）· arXiv:2602.04884

范式转变
传统 RL/OPD 优化的是"生成什么 token"（输出空间），RAL 直接优化"注意力该放在哪里"（内部表示空间）——将模型内部注意力分布作为策略梯度优化的策略。这是多模态后训练从输出空间到内部表示空间的标志性跨越。
方法
① 注意力分布策略：每个生成 token 对所有前序位置（视觉+文本）的注意力权重 = 可学习的"策略" ② 优势加权注意力散度损失（JSD）：高奖励拉近，低奖励推远 ③ 联合优化：token 级 RL 损失 + 注意力级 RL 损失。
$$\mathcal{L} = \mathcal{L}_{\text{token-RL}} + \beta \cdot \mathcal{L}_{\text{attention-RL}}$$

On-Policy Attention Distillation：学生用自己的策略采样轨迹 → 教师提供注意力分布做对齐。相比传统 KD 仅对齐 logits，注意力蒸馏同时传递"答案是什么样的"和"证据该从哪里找"。

突破性发现

💡 RAL-zero：去掉 CoT，仅优化注意力就超越 GRPO

惊人发现
RAL-zero 完全去掉 <think> 推理文本（仅输出答案），仅靠优化注意力分布就超过了 GRPO。这证明：优化"看哪里"本身就能提升推理能力——不依赖显式思维链。多模态推理中，注意力质量可能是比 CoT 文本更本质的因素。
意义
RAL 将多模态后训练从"输出空间"推进到"内部表示空间"，为理解多模态推理的本质机制开辟了新路径。如果注意力 OPD 的有效性被进一步验证，未来的多模态模型可能不再需要手写 CoT 来提升推理——优化注意力本身就足够。

🌍 世界模型+OPD · 情感计算 OmniOPSD

🟡 世界模型 + OPD

核心思想：特权不再局限于"同一时刻的更多信息"，而是跨时间的因果信息。教师看到真实未来帧（特权上下文），学生在 on-policy rollout 中仅基于当前观测推理。

效果：VRQABench +10.6% · OpenWorldQA +10.9%

深层含义：将世界模型（生成未来帧）与 MLLM 的抽象推理结合，OPD 从空间特权 → 时间特权。

🟢 OmniOPSD · 情感计算

核心洞察：使用前沿模型生成的推理依据（rationale）作为教师侧特权证据——而非学生模仿目标。学生在无特权条件下自采样，教师用 rationale 提供密集监督。

意义：将 OPSD 扩展到情感计算——需要细粒度跨模态理解但对标签高度敏感的领域。

笔记 02 中 Czarnecki 2019 的 Theorem 1（梯度场不存在定理）在纯文本域已确立——多模态条件下的梯度场行为是否不同？跨模态梯度分量的相互作用尚无理论分析。视觉梯度和语言梯度的耦合是否会产生新的鞍点或局部最优？
问题 2：最优特权设计的形式化框架
ViCuR 提出了"可恢复特权"概念——但什么样的特权在数学上是最优的？是否存在一个类似信息瓶颈（Information Bottleneck）的框架来形式化特权质量？特权信息量、可恢复性、Shortcut 风险三者之间的 trade-off 需要理论建模。
问题 3：多教师仲裁的最优性
H-OPD 的 token 级教师仲裁是启发式的——能否从决策论或贝叶斯模型平均的角度给出最优仲裁策略？当教师间存在冲突时，如何保证仲裁不退化到"少数服从多数"的平庸解？
问题 4：视觉注意力的可优化性边界
RAL 证明了注意力分布可以通过策略梯度优化——注意力的哪些性质是可优化的？是否存在注意力的"可达集"（reachable set）概念？RAL-zero 的成功暗示注意力优化本身就能提升推理——其理论基础是什么？

工程瓶颈

⚡ 四个关键工程挑战

挑战 1：On-Policy 采样的计算开销
on-policy 采样需要每步生成完整 trajectory，对于长视频和高分辨率图像仍然是显著的 overhead。TVDF 等课程策略是第一步，但更高效的重要性采样方法尚未开发——能否像 PPO 中的 GAE 一样，为多模态 OPD 设计专用的信用分配加速方案？
挑战 2：教师质量依赖性
几乎所有 OPD 方法都假设教师比学生"更好"——但当师生差距过大（如 Visual-OPSD 中 VT 生成质量差）或过小（教师没有增量信息），OPD 如何自适应调节？需要一个教师质量的在线评估与动态权重机制。
挑战 3：多模态多教师协调
H-OPD 引入了异构教师——但在 3+ 教师场景下，仲裁机制的计算开销呈线性增长，教师间冲突如何解决？每个 token 都要跑 N 次教师推理，这对实时应用是不可接受的。
挑战 4：灾难性遗忘的持续监控
VLA-OPD 在机器人域证明了 OPD 有助于缓解遗忘——但缺乏在线遗忘检测和自动恢复的机制。当模型在新任务上训练时，如何实时感知旧能力的退化并触发保护性约束？

🟢 短期（6个月内）
