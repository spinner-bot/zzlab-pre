RL 基础概念

在深入三篇论文之前，先掌握强化学习的基本词汇—— 后面所有公式和算法都建立在这些概念之上。

R · 奖励信号 任务 · Task π · 策略 Q · 价值函数 神经网络表示
DAG位置：最顶层基础节点 → 向下支撑所有论文节点

📚 RL 核心概念 — R, 任务, π, Q

💬 讨论

🎯 R (Reward) — 即时奖励

智能体每执行一个动作，环境返回的数字分数。
例：机器人往前走一步 → R=+1；摔倒 → R=−10。
Rᵢ(s,a) = 在第i个任务中，状态s下做动作a的即时奖励。

📋 任务 (Task) — 由奖励函数定义

任务 = 要达成什么目标，由怎么给分来决定。
任务1 (走路)：速度越快R越高。
任务2 (导航)：离目标越近R越高，撞障碍R负。

🧭 π (Policy) — 策略，决策大脑

π(a|s) = 给定状态s，选择动作a的概率分布。
它是智能体的"行为准则"——看到什么状态，该做什么动作。

📊 Q(s,a) — 价值函数，未来预言

Q(s,a) = 从状态s执行动作a后，按照某策略继续走，未来能拿到的累积折扣奖励之和。
Q值告诉你：这个动作在长远来看有多好？

💡 在OPD中：每个任务i有自己的Rᵢ → 训练出πᵢ → πᵢ的Q值反映其"局部智慧" → 蒸馏到共享π₀

🤖 为什么π和Q要用神经网络表示？

💬 讨论

❌ 为什么不能手写？

实际RL场景中，状态s是高维连续向量（如机器人关节角度×速度×触地传感器 = 数百维）。可能的(s,a)对是天文数字，完全无法靠人列表格或写死规则。

✅ 神经网络的方案

神经网络是一种万能函数近似器，从数据中自动学习映射。
• 策略网络 π_φ(a|s)：输入s → 输出动作概率
• 价值网络 Q_θ(s,a)：输入s和a → 输出一个预期回报数值
可以内插推广：见到相似状态也能给出合理输出。

💡 理解了这个，才能明白后面"基座/backbone"、"网络共享"、"列/column"等概念

🔄 RL 核心循环 — 智能体与环境的对话

💬 讨论
🧠 智能体 Agent 策略 π + 价值 Q

观察状态 → 做出决策

动作 a →
← 状态 s, 奖励 R
🌍 环境 Environment MDP / 物理世界

接收动作 → 返回状态+奖励

每个时间步 t：
① 智能体观察状态 sₜ → ② 根据策略 π 选择动作 aₜ → ③ 环境执行 aₜ →
④ 环境返回新状态 sₜ₊₁ 和即时奖励 Rₜ → ⑤ 智能体用 (sₜ, aₜ, Rₜ, sₜ₊₁) 更新策略
目标：找到最优策略 π*，使累积折扣奖励 ΣγᵗRₜ 最大化

🤖 具体例子：训练机器人走路

💬 讨论

🎯 任务 1：学会走路

状态 s：关节角度、速度、触地传感器
动作 a：每个马达的力矩（连续值）
奖励 R：前进速度越快→R越高，能耗低→加分
策略 π："看到这个身体姿态，该用什么力度蹬腿"
Q值："在这个姿态下蹬这一腿，长远来看能走多远"

🎯 任务 2：学会导航

状态 s：位置坐标、障碍物距离、目标方向
动作 a：转向角 + 移动速度
奖励 R：离目标越近→R越高，撞障碍→R=−10
策略 π："看到障碍物在左前方，该往右绕"
Q值："在这个位置选择向右绕，长远能避开多少麻烦"

💡 关键观察：同一个机器人，任务1和任务2的奖励函数R不同，行为就完全不同。 在OPD中，每个任务i有自己专属的Rᵢ和策略πᵢ——这就是Distral公式里下标i的含义。 但问题来了：如果我们需要机器人学会跑、跳、翻滚，而这些动作的奖励函数很难人工编写（你很难用数学公式描述"什么是跑"），怎么办？这将是Part 2要解决的核心问题。

🔧 π 和 Q 具体怎么用神经网络实现？

💬 讨论

🧭 策略网络 π_φ(a|s)

输入：状态向量 s（关节角度、速度等拼接）或图像像素
离散动作（左/右/前进）：

s → FC → ReLU → FC → Softmax → [p₁,p₂,p₃]
每个动作一个概率，和为1

连续动作（马达力矩）：

s → FC → ReLU → FC → μ, σ (Gaussian)
从 N(μ,σ) 中采样实际动作值

训练：用策略梯度 / PPO 最大化期望累积奖励

📊 价值网络 Q_θ(s,a)

输入：状态 s + 动作 a（拼接为一个向量）
输出：一个标量数字 = 从(s,a)开始的累积折扣奖励预测

[s; a] → FC → ReLU → FC → 标量 Q(s,a)

训练：最小化 TD 误差 — 让 Q(s,a) ≈ r + γ·max_{a'} Q(s',a')

💡 为什么能内插推广？
神经网络见到训练中从未出现的 (s,a) 组合时，也能给出合理的近似值——这是查表法永远做不到的。

Distral (2017)

"理论家" — 蒸馏作为多任务通信协议

DAG位置：汇聚节点 — Policy Distillation + Actor-Mimic 两条支线在此汇合，形成统一框架。以下4页展开其核心内容。

🧠 Distral — 联合目标函数 J(π₀, {πᵢ})

两个层级：共享中心策略 π₀（捕获通用行为）+ 任务策略 πᵢ（专门解决第i个任务）

$$J(\pi_0, \{\pi_i\}) = \sum_i \mathbb{E}_{\pi_i}\left[\sum_{t \ge 0} \gamma^t R_i - c_{\text{KL}} \gamma^t \log\frac{\pi_i}{\pi_0} - c_{\text{Ent}} \gamma^t \log \pi_i\right]$$
①
标准RL奖励
ΣγᵗRᵢ
完成自己的任务
最大化累积回报
②
KL惩罚项
−c_KL·log(πᵢ/π₀)
别离中心策略太远
实现知识共享
③
熵奖励项
−c_Ent·log πᵢ
保持策略随机性
鼓励探索新动作

👆 点击展开公式拆解 (1/3)

🌊 软 Q 学习视角 — "硬选最大" vs "软分布"

💬 讨论

核心思想：把探索和偏离惩罚"揉"进奖励，让智能体追求一种"软"版本的最优动作

🔴 传统 Q 学习（硬）

目标：只最大化 ΣγᵗR
最优动作：a* = argmax_a Q(s,a)
策略：确定的——永远选Q值最高的
问题：没有探索机制，容易陷入局部最优

// 硬最大：只选最高的
a* = argmax(Q[s,:])

🟢 软 Q 学习（软）

目标：最大化 Σγᵗ(R + α·H(π))
最优动作：按 exp(Q/β) 的玻尔兹曼分布采样
策略：概率分布——高Q值的动作概率高，但低Q值的也有机会
软贝尔曼方程：V_soft = β·log Σ exp(Q/β)

// 软最大(LogSumExp)：概率分布
p(a) ∝ exp(Q[s,a] / β)

🔗 在 Distral 中的体现：
最优策略 πᵢ ∝ π₀^α · exp(Qᵢ/β) 就是软 Q 学习的直接推论——它不仅对 Q 值取 Softmax，还把先验 π₀ 作为额外权重因子。
好处：将带有多约束（探索 + 知识迁移 + 保持风格）的复杂策略优化，转化为标准的软 Q 迭代问题，可直接用 Q 学习工具求解。

🔍 KL散度深入 — 那把测量"差距"的尺子

💬 讨论
$$D_{KL}(P \| Q) = \sum_a P(a) \log\frac{P(a)}{Q(a)}$$

📐 核心性质

• 如果P和Q完全一样 → KL=0
• 只要有一点点不同 → KL > 0
• 不对称：D_KL(P‖Q) ≠ D_KL(Q‖P)
• 我们用的是前向KL：要求P覆盖Q的所有行为

🎯 在Distral中的作用

−c_KL · D_KL(πᵢ ‖ π₀) → 惩罚πᵢ偏离π₀
最大化J → 必须最小化KL散度 → πᵢ被迫靠近π₀。
这就是知识共享的数学机制。

🪢 比喻：家长划的"活动圈"

中心策略π₀ = 家长给孩子划的安全玩耍范围。
孩子(πᵢ)可以在圈内自由探索，但跑出圈外会被KL惩罚"拉回来"。圈的大小由c_KL调节。

🔑 关键理解

KL正则化 = "软"约束：不是禁止偏离，而是偏离了会扣分。算法自行权衡利弊——这正是不确定性下灵活决策的精髓。

🎯 最优策略闭式解 & 贝叶斯直觉

最大化J后，πᵢ的最优形式（可直接用Q学习迭代求解）

$$\pi_i(a|s) \propto \pi_0(a|s)^{\alpha} \cdot \exp\!\left(\frac{Q_i(s,a)}{\beta}\right)$$

α = c_KL/(c_KL+c_Ent) · β = c_KL+c_Ent

📜先验 Prior π₀^α · 集体智慧
×
🎯似然 Likelihood exp(Qᵢ/β) · 任务价值
=
✅后验 Posterior πᵢ · 最优任务策略
α
先验强度
α大 → 保守，紧跟中心
α→0 → 纯Q值驱动，不用先验
β
温度参数
β大 → 随机，偏探索
β小 → 贪婪，偏利用

💡 这就是软Q学习视角：不是硬选Q最大的动作，而是通过exp(Q/β)形成概率分布——"软"就软在这里

🔄 "蒸馏作为通信" — 双向知识循环

📥 蒸馏 Distill
π₁ → π₀ ← π₂

子策略把经验"上交"给中心
π₀ = argmin Σᵢ D_KL(πᵢ ‖ π₀)
汇聚共性智慧 → 集体笔记

🧑‍🏫 子策略=教师，中心=学生

⇄
循环
📤 广播 Broadcast
π₀ → π₁, π₂

中心把通用行为"广播"回去
通过KL正则 πᵢ∝π₀^α·exp(Qᵢ/β)
约束子策略，引导探索方向

🧭 中心=文化约束/行为锚点

关键洞察：蒸馏不再是单向教→学，而是双向、社会化的知识共享。π₀一开始可能是空的——它靠吸收所有πᵢ的经验成长，同时立刻广播回去影响πᵢ的探索。互为师生，共同进化。

Actor-Mimic (2016)

"工程师" — 条件蒸馏 + 特征回归 + 行为克隆

DAG位置：右侧分支 — RL基础 → Actor-Mimic → 汇入Distral。其"硬压缩"与KL的"软约束"形成对比。

🔬 条件蒸馏 — 只学教师"有把握"的状态

$$\mathcal{L}_{\text{distill}}(s) = \begin{cases} D_{KL}(p_T\|p_S) & \text{if } \max_a Q_T(s,a) > \theta \\ 0 & \text{otherwise} \end{cases}$$
✅ max Q_T(s,a) > θ
蒸馏！模仿教师

教师有把握 → 值得学

❌ max Q_T(s,a) ≤ θ
跳过，损失=0

教师也困惑 → 不学垃圾

🎯 Q值截断直觉

类比：只总结学霸有把握的解题方法，不学他们瞎蒙时的做法。防止噪声污染共享知识库。

🔗 特征回归

L_feature = ‖f_T(s) − W_r·f_S(s)‖²。不仅模仿"做什么"（动作输出），还模仿"怎么看"（中间层特征表征）。

🎓 专家策略 & 行为克隆 — "先揉到一起，再各自优化"

💬 讨论

👑 什么是"专家策略"？

先为每一个任务单独训练一个高性能智能体。这些训练好的π₁*, π₂*, ...就是专家策略——各自任务的"老手"，已经拿到很高奖励。它们被冻结，用作监督标签。

📝 什么是"行为克隆"？

用监督学习让学生网络π_multi(a|s,i)去模仿专家输出。损失=交叉熵（离散动作）或MSE（连续动作）。不需要环境交互，纯粹地模仿专家的动作分布。

🔀 Actor-Mimic 两步走

步骤一：多任务模仿（揉到一起）
学生网络输入(state, task_id)，模仿所有专家的行为 → "什么都会一点"的泛化策略。

步骤二：各自微调（各自优化）
以学生网络为初始化，每个任务单独用RL微调。因为起点已经很合理，微调所需样本远少于从头训练。

💡 这就是"先培养全能天才，再让他成为各领域专家"

⚖️ 软约束 vs 硬约束 — KL正则化 vs 行为克隆

💬 讨论

这一对比揭示了 OPD 设计中一个核心哲学选择：给不给策略"讨价还价"的空间？

🪢 KL正则化 — "软"约束

机制：目标函数中加惩罚项 −c_KL·D_KL(πᵢ‖π₀)
特点：允许偏离，但偏离了要扣分。算法自动权衡"多拿奖励"和"别走太远"。
比喻：橡皮筋拉着你——可以撑开走远，只是越来越费力。
结果：πᵢ可以超越π₀，只要有足够的任务奖励支撑。

🔒 行为克隆 — "硬"压缩

机制：监督学习——学生输出必须和专家一模一样。
特点：没有"适度偏离"的余地，强行复制专家行为。
比喻：抄作业——只能原样照抄，不能有自己的解法。
结果：学生能力上限 ≤ 专家。但作为初始化很好用。

在DAG中的位置：KL软约束来自Distral，硬压缩来自Actor-Mimic——两条线最终都汇入OPD的技术工具箱，各有适用场景。

🏗️ 基座网络 & 共享特征 — 多任务学习的结构基础

🧱 什么是基座 (Backbone)？

多个任务共享的那部分网络层。
前面几层（靠近输入的）学通用特征：如边缘、纹理、运动原语。后面每个任务各自接一个"头"做特定输出。基座可以硬共享（强制共用）或软共享（参数相近但不完全一样）。

📊 为什么需要共享基座？

• 样本效率：通用特征一次学习，所有任务受益
• 知识迁移：任务A学到的边缘检测自然用于任务B
• 与OPD的关系：蒸馏出的π₀本质上就是一个"行为基座"——捕获所有任务共有的动作模式

软/硬共享对比：KL正则 → 基座的"软共享"（允许偏离但惩罚）。Actor-Mimic的行为克隆 → 基座的"硬共享"（强制复制）。这和我们Slide 17讨论的软vs硬约束是同一哲学的不同体现。

🏛️ Progressive Nets — 另一条解决路径

💡 核心思想

学新任务时不动旧网络参数，新增一整套路网络（称为一"列"），并通过横向连接把之前所有旧列的特征都接进来。彻底解决灾难性遗忘。

progressive_net.py
# 列1 (任务1) → 冻结
col1_l1 → col1_l2 → col1_l3 → output1
   ↘ adapter
# 列2 (任务2) → 可训练
concat(col2_l1, col1_l1) → col2_l2 → ...
# 每一列 = 一整套网络（多层）

⚠️ 参数增长问题

1个任务 = 100万参数。10个任务 = 1000万+参数（线性增长）。任务多了存不下、跑不动。

后续优化方向：
• PackNet：剪枝+复用空置权重
• EWC：用Fisher信息矩阵保护重要权重
• PathNet：固定大小的模块库，按需组合
• 趋势：从全量硬增长 → 灵活模块化复用

🔗 与OPD的关系

KL正则 → "软"约束。Actor-Mimic → "硬"压缩。Progressive Nets → 第三种路径：不约束也不压缩，直接扩展。它的扩展性局限直接引出了后续更灵活的模块化方法。

🔮 UNREAL (2016) — 辅助预测头：让特征"理解世界"

💬 讨论

❓ 问题：蒸馏只学了"做什么"

在 Actor-Mimic 的蒸馏中，中心策略只模仿了子策略的动作概率分布 p_T。但这忽略了一个关键：环境的运转规律——球推一下滚多远、踩地摩擦力如何、开关按下灯会亮——这些"世界模型"没有被蒸馏。

💡 UNREAL 的解决方案

在 A3C 基础网络上并行挂多个辅助预测头，与主 RL 任务同时训练：
• 像素控制头：预测动作后画面哪些像素会变
• 奖励预测头：预测接下来几步的奖励序列
• 价值回放头：对历史经验再做价值估计训练

🔧 如何影响模型？

辅助头不是死输出——每个头都有自己的损失函数。总损失 = 主RL损失 + λ₁·像素损失 + λ₂·奖励损失 + ...。

通过反向传播（梯度下降），辅助任务的梯度分量也流入共享基座层，强制基座在提取特征时编码环境动态信息。

📈 效果：样本效率

用更少的数据达到同等性能。因为基座已经对"世界怎么运转"有了内部模型，主任务不需要从零摸索所有因果。在OPD语境下，把这种特征蒸馏进π₀ → 中心策略不仅"知道该做什么"，还"知道世界怎么运转"。

🌿 支线的支线 — Progressive Nets 参数增长问题的替代方案

仅了解

以下三种方法各自解决了"参数随任务数线性增长"的问题，但走的是不同的路。 此处仅作概念了解，不做深入展开。

✂️ PackNet

策略：训练完一个任务后剪枝（去掉不重要的权重），冻结剩余。下一个任务只用空出来的权重。
优势：参数总量恒定不变。
代价：任务间不共享特征表达，每个任务占用独立子空间。

🧲 EWC

策略：用Fisher信息矩阵识别对旧任务重要的权重，给这些权重的变化施加惩罚——重要参数锁定，不重要参数自由调整。
优势：所有任务共用一个网络，参数不增长。
代价：难以完美平衡新旧任务的性能。

🧩 PathNet

策略：预定义一堆小型模块（模块库大小固定），每个任务通过进化算法或梯度学习选择哪些模块组合最适合自己。
优势：模块库不随任务增长，自然支持模块复用。
代价：模块路由的学习本身有开销。

🔀 趋势：从 Progressive Nets 的"全量硬增长" → PackNet的"剪枝复用" → EWC的"受控遗忘" → PathNet的"模块化组合"。 核心方向：灵活复用 > 线性扩展

🤖 机器人的困境 — 有些技能，R函数根本写不出来

💬 讨论

✅ 容易写 R 的技能

• 走路：前进速度 → R = 速度×Δt − 能耗×c
• 导航：距离目标 → R = −distance(target, pos)
• 抓取：物体是否被拿起 → R = +1 if grasped else 0
这些都有明确的数学定义。

❌ 极难写 R 的技能

• 跑：怎么用数学定义"跑"vs"走"？速度阈值？太粗暴
• 跳：四足离地？那摔倒也算"跳"吗
• 翻身：角度变化？用哪个轴？
• 跳舞：基本无法用公式描述
这些需要无监督方法。

🔥 这就是萌芽期框架的致命缺口：Distral 要求每个任务都有明确的奖励函数 Rᵢ。但现实中，大量有价值的技能根本没有清晰的奖励定义。
如果不能解决这个问题，OPD 的技能库就被限制在"人能写清楚奖励"的狭窄范围内。

🔮 预览：无监督技能发现 — 不靠R也能"玩"出技能

💬 讨论

🔑 核心思路 (DIAYN, 2018)

① 随机分配技能编号 z（z=0,1,...,K−1）
② 训练判别器 D(z|s)：根据机器人状态猜它正在执行哪个技能
③ 伪奖励 = log D(z|s)：如果判别器能轻松识别出技能z，就给高分
④ 同时最大化策略熵：防止技能坍缩为同一个动作

结果：不同z自动演化出不同运动模式——跑、跳、翻身，完全不需要人定义"什么是跑"。

🔗 如何与OPD衔接？

这些无监督发现的技能，就可以作为Distral里的"教师策略"πᵢ——即便它们根本没有任务奖励Rᵢ。

中心策略π₀从这些"自己玩出来的技能"中蒸馏出通用运动基座，以后微调到具体任务（如追赶目标）时速度极快。

这填补了"没有奖励信号怎么办"的缺口。

🛠 工程实践

K个技能通常设得比目标动作多（如设50个），自由分化后人工筛选（看视频选出"最像跑"的z*）。选出后用真实奖励R微调，或用KL约束保持原始技能风格——最终把它打磨成真正可用的技能。

🔬 K-means 类比 — 技能发现 vs 静态聚类

💬 讨论

📊 K-means（静态聚类）

• 对已有的数据点分组
• 需要人工定义特征维度
• 分配标签后不改变数据本身
• 聚类质量取决于初始中心点

🤖 DIAYN 技能发现（动态生成）

• 智能体主动修改数据生成过程
• 维度由传感器硬件决定（关节角度/速度/触地）
• 神经网络自动抽取区分特征
• 策略被驱动使簇间差异最大化

💡 本质区别：K-means 是对已存在数据贴标签；DIAYN 是让智能体主动改变自己的行为来产生更容易被区分的状态轨迹。这是"被动分类"和"主动塑造"的根本不同。

📐 互信息 I(S;Z) — 技能多样性的数学保证

💬 讨论
$$I(S; Z) = H(S) - H(S|Z)$$

🔑 三个核心概念

H(S)：状态总不确定性—所有技能混合在一起时，状态分布有多"乱"

H(S|Z)：已知技能编号后的剩余不确定性—知道是哪个技能后，还能猜中状态吗？

I(S;Z)：互信息—知道技能编号能减少多少状态的不确定性。越大 → 技能之间越容易区分

🎯 最大化 I(S;Z) 的效果

强迫 H(S|Z) 尽可能小 = 给定技能编号就能猜出状态
→ 不同技能必须访问不同的状态区域
→ 自然涌现可区分的运动模式

📊 状态访问分布 d^π(s)

策略 π 长期运行时，处于各状态的概率分布。"跳"的状态分布在关节高频震荡区，"走"在低频摆动区。统计依赖：两个变量不独立，知道一个就能预测另一个——互信息是量化这种依赖的最高指标。

💡 伪奖励 log D(z|s) — 判别器猜得越准→互信息越大→技能越多样化→自然分簇

🔧 选出技能后，如何精细优化？— 三种微调方法

💬 讨论

无监督发现的技能只是"接近"目标，需进一步精炼。K个技能设得比目标多（如50个），人工筛选后微调。

🎯 1. 微调 + 任务奖励 R

为选出的技能设计真实奖励函数（如"速度越快分越高"）。以无监督策略为初始化，用RL（PPO/SAC）继续训练。
优势：起点已经很接近，只需少量样本。

👁️ 2. RLHF (人类反馈)

写不出R时，让人当评判：看视频 → 选"更像跑"的那段 → 用偏好信号训练奖励模型 → 用奖励模型微调策略。
优势：把模糊的人类感觉变成可优化的目标。

🔒 3. KL 约束微调

微调时加 KL 散度项约束新策略不要偏离原始无监督策略太远。
优势：防止为追求高奖励而动作变形，保持技能原有"风格"——这正是Distral框架思想的延续。

🚀 Kickstarting Deep RL (2018)

📄 Schmitt et al., DeepMind · arXiv: 1803.03835 · DMLab-30 平台

核心思想：教师先推一把，然后放手让学生自己跑

$$\boxed{\mathcal{L}_{\text{kick}}(\omega, x, t) = \underbrace{\mathcal{L}_{\text{RL}}(\omega, x, t)}_{\text{标准RL目标}} + \underbrace{\lambda_k \cdot H\big(\pi_T(\cdot|x_t) \;\|\; \pi_S(\cdot|x_t, \omega)\big)}_{\text{逐渐衰减的蒸馏信号}}}$$

🔑 关键创新：λ_k → 0

ω = 学生网络权重；x_t = 当前状态
H(π_T‖π_S) = 交叉熵，等价于最小化 D_KL(π_T‖π_S)
λ_k 训练初期大（强引导）→ 中期减弱 → 后期为 0（完全自主）

💡 为什么不用 KL 散度？

交叉熵 H(π_T‖π_S) = −Σ π_T log π_S
与 D_KL(π_T‖π_S) 相差一个常数（教师熵不依赖学生参数），优化等价但计算更简单。

🎯 为什么 Kickstarting 能超越教师？

❌ 问题：如果学生只模仿

如果学生在整个训练过程中始终强依赖教师信号（λ_k 不衰减），学生的性能上限就是教师水平——永远无法超越。

✅ 解决方案：逐渐放手

蒸馏应该像教孩子骑自行车——开始时父母扶着（大λ_k），然后慢慢松开（λ_k衰减），最后孩子完全自己骑（λ_k=0），可能比父母骑得更好。

🧬 PBT：自动调参

Population Based Training：40个智能体并行训练。表现差的复制表现好的超参数（λ_k、衰减率、学习率、熵系数）并加扰动。自动找到最优衰减曲线。

设置结果
单教师训练速度 1.5×
多教师（每任务一专家）9.58× 加速！性能超越 42.2%
学生 vs 教师多任务上学生显著超越

📐 先理解：什么是"梯度场"？

📊 梯度 = 方向指示器

训练神经网络时，对损失函数求参数 ω 的导数，得到梯度向量——它指向"损失下降最快的方向"。梯度下降 = 沿着反方向走。

ω_{new} = ω_{old} − η · ∇_ω L(ω)

🗺️ 梯度场 = 所有位置的梯度集合

参数空间里每个点都对应一个梯度向量。这就像一片"场"——每个位置都有箭头告诉你该往哪走。

梯度场不存在 = 某些区域的箭头全部消失（为零向量），梯度下降卡住，无法继续优化。

⚠️ Theorem 1: 梯度场不存在定理

⚠ Theorem 1

核心发现：标准的 on-policy 蒸馏更新规则不对应于任何损失函数的梯度。

$$\Delta\theta = \mathbb{E}_{s \sim d_{\pi_\theta}} \left[\nabla_\theta H(\pi_T(\cdot|s) \;\|\; \pi_\theta(\cdot|s))\right]$$

学生参数 θ 变了 → 策略变了 → 访问的状态分布 d_{π_θ}(s) 变了 → 蒸馏损失的定义域已经漂移。永远在追一个因自己移动而移动的目标。

🔑 一句总结

如果学生策略是随机的（softmax输出），在学生已收敛到某个局部最优时，梯度完全消失——即使学生还很差。训练停止，无法逃离。

🔍 根因：学生状态分布差

🤖 学生策略差
→
🕳️ 只访问差状态
→
👀 看不到教师妙手
→
💀 梯度消失

🎯 核心矛盾

学生只能从自己实际跑出来的状态里学习教师。但学生策略不成熟 → 永远访问低奖励状态 → 在这些状态下，教师也只会给出平庸动作 → 学生永远看不到教师真正的"神之一手"。

♟️ 围棋类比

一步错棋 → 100步后局面崩溃 → 学生整盘都在劣势区挣扎 → 根本看不到教师妙手所在的"优势区"。
长horizon下，状态分化更严重。

🎬 "定义域漂移"到底是什么意思？

▲ 学生每走一步，山峰就变形一次——目标永远在移动

🏔️ 类比：在山峰上找最低点

想象你站在一座山上，想走到最低的谷底。

正常梯度下降：看脚下坡度 → 往最陡的下坡走。

定义域漂移：你每走一步，整座山就变形一次——因为学生策略变了，访问的状态分布也变了，损失函数的"地形"随之改变。

你永远在追一个因自己移动而移动的目标。

🏔️ 3D 损失景观 — "平坦高原"如何困住学生

参数空间 (θ₁, θ₂) → 损失 L(θ₁, θ₂) 构成三维曲面。红色球 = 学生当前位置。

🔴 红色球 = 学生被困在高原

🟢 绿色十字 = 教师的真正最优解

🟡 箭头 = 梯度方向（在高原上 → 0）

平坦高原 = 梯度为零的区域 = "梯度场不存在"。学生滑入这个区域后，再也收不到任何方向信号。

而定义域漂移让这座山不断变形——高原区域可以出现在任何地方，困住任何位置的学生。

🔧 对比：教师轨迹如何打破困境

❌ 同策略蒸馏（Before）

学生只看自己跑出来的状态
→ 永远在低价值区打转
→ 梯度消失，训练停止

✅ N-step 未来蒸馏（After）

注入教师的高价值轨迹
→ 即使学生没去过也能学习
→ 梯度信号源源不断

✅ Theorem 2: 梯度场重建

✅ Theorem 2 · 修正

核心思路：打破"状态必须来自学生"的限制。在每个时间步添加"未来蒸馏损失"作为修正奖励。

$$\mathbb{E}_{\pi_\theta}\!\left[\sum_t -\nabla_\theta \log\pi_\theta \cdot \sum_{i=t}^{\infty} \hat{r}_i + \nabla_\theta \ell_t\right]$$

🔧 方法一：N步未来蒸馏损失

沿教师轨迹看未来N步，每一步计入损失：

$$\mathcal{L}_{\text{future}} = \mathbb{E}_{\mathcal{D}_T}\!\left[ \sum_{k=0}^{N-1} \gamma^k D_{KL}(\pi_T \| \pi_S) \right]$$

🔧 方法二：教师价值加权

教师价值越高的状态，学生越认真模仿：

$$\mathbb{E}_{\mathcal{D}}\!\left[ \exp\!\left(\frac{V_T(s)}{\beta}\right) \cdot D_{KL}(\pi_T \| \pi_S) \right]$$

🕰️ 长 Horizon 任务 — N-distill 的最佳舞台

📏 Horizon 是什么？

Horizon = 一个 episode 的时间步数量。走迷宫200步到达出口（horizon=200）；围棋一局200手（horizon=200）；长horizon = 步骤极多、奖励极其稀疏（甚至只在终点给一个奖励）。

短Horizon
学生容易碰运气到达终点
梯度场问题影响较小

长Horizon
学生靠自己几乎摸不到终点
N-distill 是救命稻草

💡 为什么 N-distill 适用长 Horizon？

教师轨迹 D_T 包含了完整的成功路径。训练时，学生被强制在教师的高价值状态上模仿：
• 看到好状态——虽然自己还去不了，但网络已学会"如果到了这个状态该怎么做"
• 引导探索——一旦偶发接近好状态，模仿过的经验让它做出合理动作 → 正反馈

就像给你一张藏宝图——即使你一开始在沙漠，也知道该往宝藏方向走。

🎲 Expected Entropy Regularization

📐 策略熵 H(π) = 随机性度量

$H(\pi(\cdot|s)) = -\sum_a \pi(a|s) \log \pi(a|s)$
熵大 → 动作均匀（探索性强）
熵=0 → 完全确定选一个动作（无探索）
期望熵 = 对状态分布取期望：E_{s∼d^π}[H(π(·|s))]

🔧 熵正则化

在损失函数中显式加入学生策略熵：

$$\mathcal{L} = \mathcal{L}_{\text{imitation}} - \lambda_{\text{ent}} \cdot \mathbb{E}_{s}[ H(\pi_S(\cdot|s)) ]$$

作用：防止学生模仿时变成完全确定的拷贝，保持探索能力。笔记标注为"最通用（作者推荐）"。

💡 与 Part 1 的联系

这和 Distral 里的熵奖励项 −c_Ent·log πᵢ 是一脉相承的——都在防止策略过早坍缩到确定性策略。

🏆 Teacher V Reward — 教师变成奖励函数

💬 讨论

🔀 完全不同的思路

不需要模仿动作分布。教师直接用自己的价值函数 V_T(s) 或 Q_T(s,a) 构造奖励信号：

$$r_t^{\text{teacher}} = V_T(s_{t+1}) - V_T(s_t)$$

或直接用 $r_t = Q_T(s_t, a_t)$

学生不模仿动作，而是用自己的策略去最大化这个"教师奖励"——完全从头跑RL。

🎯 DPO — 把 RLHF 变成分类问题

DPO 发现：带KL惩罚的最优策略有闭式解——根本不需要奖励模型！

📐 推导链（3步）

① OPD闭式解：
$\pi^*(y|x) \propto \pi_{\text{ref}}(y|x) \cdot \exp(R(x,y)/\beta)$

② 反解出 R：
$R(x,y) = \beta \log\frac{\pi^*(y|x)}{\pi_{\text{ref}}(y|x)} + \beta\log Z(x)$

③ 代入偏好模型 → DPO损失：

$$\mathcal{L}_{\text{DPO}} = -\mathbb{E}\left[\log \sigma\left(\beta \log\frac{\pi_\theta(y_w|x)}{\pi_{\text{ref}}(y_w|x)} - \beta \log\frac{\pi_\theta(y_l|x)}{\pi_{\text{ref}}(y_l|x)}\right)\right]$$

✅ 为什么这是革命性的？

• 零奖励模型——损失只依赖π_θ和π_ref
• 直接从静态偏好对 (x, y_w, y_l) 学习
• 本质是二分类：给好回答更高相对概率
• 训练稳定、实现简单、无需PPO

关键转化："先训RM再PPO"的两阶段流水线 → 一个简单的分类损失函数。OPD的KL约束结构是这一切的数学起点。

🧠 什么是"推理链" (Chain-of-Thought)？

推理链 = 不仅给出最终答案，还给出中间推导步骤的文本序列。它是 LLM "思考过程"的文字化。

推理链示例
// 问题：小明有5个苹果，吃掉2个，又买了3个，还剩几个？
推理链：
  ① 小明最初有 5个 苹果
  ② 吃掉2个 → 剩下 5−2=3个
  ③ 再买3个 → 变成 3+3=6个
  ④ 所以最终答案是 6
// 中间步骤 = 推理框架：分解/引用/检查/回溯

为什么推理链成为OPD的新焦点？
传统OPD：蒸馏的知识载体 = 动作概率分布 π(a|s)
LLM OPD：蒸馏的知识载体 = 推理文本本身
→ 我们不再只让学生学会"选正确动作"，而是让它学会如何思考。

💥 为什么LLM场景打破了传统OPD假设？

💬 Q0

✅ 传统OPD假设

• 状态/动作空间小或连续（Atari~18动作，MuJoCo连续力矩）
• 奖励相对稠密：每步都有反馈
• 轨迹长度适中：几百步内随机探索能碰好运
• 师生面对同一个MDP：状态动作空间完全对齐

❌ LLM推理场景的现实

• 动作空间极大且离散：每token是词表中几万类之一
• 奖励极度稀疏：只有最终答案对/错的0/1信号
• 序列极长：推理链上千token，累积误差严重
• 状态是已生成的token序列：随序列增长不断变化

→ 传统在线OPD（学生采样自身轨迹+KL拉近教师）几乎失效——梯度场不存在问题被放大到极致。催生：教师轨迹离线数据、位置加权、仅蒸馏高熵token、两阶段训练等新设计。

💬 Q5/Q5.1

🔒 传统在线OPD（严格）

学生必须在自己当前采样到的状态上模仿教师。但学生推理链质量差 → 教师在烂链上无指导意义（与梯度场不存在同根）。

🔓 REOPOLD（松弛）

混合使用教师轨迹（离线数据）和学生轨迹（在线数据）。学生既能得到教师成功范例的引导，又不会完全被自己的差分布带偏。

📡 在线数据

当前策略π_θ自己与环境交互生成。数据分布随策略更新而改变。

💾 离线数据

由教师/历史策略生成并固定。教师轨迹存入D_T，训练时不再运行教师。

💥 问题一：重尾负奖励 → 梯度爆炸

⚠️ 现象

学生生成教师认为概率为0（或极低）的token时：
$R_t = \log\pi_T - \log\pi_\theta \to -\infty$
→ KL散度爆炸 → 梯度爆炸

✅ 解决：奖励裁剪 (钳位)

设定阈值 ε：当 $\frac{\pi_T}{\pi_S} < \epsilon$ 时 → 裁剪到 ε
$\hat{R}_{i,t}^\lambda = \max(R_{i,t}, \frac{\log \lambda}{1-\lambda})$
λ来自师生混合分布分位数动态计算

混合分布分位数：构造 P_mix = α·π_T + (1−α)·π_S，取该分布token概率的某分位数（如10%）作阈值ε。随上下文动态调整，比固定阈值更平滑。

🫥 问题二：近零奖励 → 信号被稀释

💬 Q6.2

⚠️ 现象

推理链中大量token是常识填充词（"的""了""首先""因为"）。对这些词，师生分布几乎一样 → KL≈0。
它们占计算的70–90%，却贡献极小的学习信号 → 关键信号被稀释。

✅ 解决：熵引导动态Token采样

只选择学生策略熵较高的token计算蒸馏损失。

高熵token = 有多种选择、需推理决策的位置（选择运算符、判断逻辑分支）→ 浓缩了大部分决策信息。
跳过70–90%的低信息量token → 信号密度大幅提升。

📉 问题三：熵崩塌 → 失去多样性

💬 Q6.3

⚠️ 现象

使用反向KL D_KL(π_S‖π_T)蒸馏时，学生会追求"模式追寻"——把概率集中在教师概率最高的几个token上 → 分布越来越尖锐 → 失去多样性 → 无法探索其他合理路径。

✅ 解决：两阶段训练

Phase 1 (Exploration)：过滤强负奖励，保留更多探索，保持熵。

Phase 2 (Refinement)：聚焦高熵token，锐化关键决策，同时防止整体熵崩塌。

本质：探索与精炼的平衡——既要掌握确定性模式，又不丧失生成多样化推理路径的能力。

📍 位置加权 — 为什么后期token更可靠？

💬 Q7/Q7.1/Q7.3
$$\mathcal{L}_{\text{PW}} = \sum_{t=1}^T w(t) \cdot D_{KL}(\pi_\theta \|\pi_T)$$

w(t) = 单调递增权重函数（如线性：w(t) = α + (1−α)·t/T）

🔑 核心发现

Token的位置是教师可靠性的最强预测器：
AUROC 0.83 vs 熵方法 0.57

推理是累积性的——错误往往在早期（一步错步步错），越往后逻辑越收敛，教师输出越可靠。

📐 AUROC 是什么？

Area Under ROC Curve——衡量二分类器排序能力的指标，最大=1。这里用它评价"位置"能否区分教师输出是否正确。
0.83 = 仅靠位置就能相当准地预测教师是否犯错，远超其他指标。

给后期token更高权重 → 模型更重视模仿教师推理后期的关键步骤，忽略早期可能带噪声的引导。

💬 Q1

📝 蒸馏数据 ≠ 蒸馏模型

我们之前讲的"蒸馏"是指得到一个学生模型。但在训练时，蒸馏依赖具体的训练数据。每条数据 = 前缀(Prompt) + 目标(Target)。

这个"问题/上文"是谁生成的？

学生前缀：由学生自己在线生成 → 分布随学生策略变化 → 学生就在自己造成的"局面"下学习 → 在线数据

🎯 CR-OPD 精讲 — 反事实路由

arXiv 2606.22793 | 核心: 只在"合理备选token"上计算KL

📐 问题: 大词表噪声

词表50k-200k token。教师和学生对于绝大多数token概率≈0，但log比值放大后贡献大量噪声项。微小数值波动→梯度估计方差巨大→淹没真正关键的决策点。

$$\mathcal{L}_t = \sum_{v \in \mathcal{V}} \pi_S(v|s_t) \log \frac{\pi_S(v|s_t)}{\pi_T(v|s_t)}$$

✅ 创新: 动态支持集+重新归一化

取师生各自Top-K并集=动态支持集C_t，在此集合上重新归一化→计算KL:
C_t = TopK(π_T, K_T) ∪ TopK(π_S, K_S)

$$\mathcal{L}_t^{\text{CR}} = \sum_{v \in \mathcal{C}_t} \hat{\pi}_S(v) \log \frac{\hat{\pi}_S(v)}{\hat{\pi}_T(v)}$$

"反事实"= 教师认为可能的token才考虑，否则忽略。有效信号提升~3倍。

⏱️ GAE-OPD 精讲 — 时序信用分配

arXiv 2606.22793 | 核心: 将未来KL信号向前传播到早期决策token

📐 问题: 自回归的时间依赖被忽略

生成是自回归的: s_t = (x, y_{<t})。前面token决定后面语境。早期关键决策(分支/解法选择)只在自己那一步受轻微KL惩罚，但后果影响后续整条链。标准OPD无法追溯归因。

✅ 创新: GAE累积未来KL加权和

每个token的学习目标不是即时d_t，而是未来累积KL的GAE估计G_t:

$$G_t = \sum_{l=0}^{\infty} (\gamma \lambda)^l \delta_{t+l}$$

后期高KL(推理失败) → 信号向前传播 → 增强早期决策token权重。与CR-OPD结合后效率提升1.5-2×。

📶 StepOPSD 精讲 — Token级→步骤级

arXiv 2605.27140 | 核心: 每步信用预算归一化，防止长步骤主导损失

📐 问题: Token数与重要性不成正比

人类推理分层级: 题目→理解→列式→计算→验证→答案。一个"答案"步骤可能只有几个token，而"计算"步骤可能占几十个token。按token平均加权→长步骤获得不成比例的损失占比→模型过度优化冗长部分，忽略核心逻辑跳跃。

✅ 创新: 步骤切分+信用预算归一化

切分推理链为M个有意义的步骤(规则/分段器)→每步token数L_k:

$$\mathcal{L} = \sum_{k=1}^{M} w_k \cdot \frac{1}{L_k} \sum_{t \in \text{step}_k} D_{KL}(\pi_S \|\pi_T)$$

w_k可均等或按步骤类型加权(答案步骤给更高权重)。确保每个逻辑步骤对总损失贡献不受token数量影响。

🩺 失效一精讲：学生前缀扭曲教师

⚠️ 恶性循环

学生弱 → 生成混乱/低质前缀 → 教师被迫"将错就错"输出 → 学生从污染信号中学习 → 生成更差的前缀 → 循环加剧。教师被拉入其从未训练过的低质量区域。

✅ 修复两步走

① Stop-Gradient: 确保梯度不会从学生流向教师——显式切断路径，保证教师输出完全冻结，不受学生污染。
② Top-K KL: 教师只对学生前缀中自己有把握的Top-K token蒸馏。教师="你这个前缀我只在少数确信的token上给你指导，其余你自己看着办"。

🩺 失效二精讲：Top-K +1 偏差 — "截断"破坏了什么？

📐 什么是截断？

词表50k-200k token。全词表KL计算开销巨大 → 工程上取Top-K(如256)近似。直接扔掉剩余概率质量 → ΣP≠1。

缺失质量偏差: P_rest被忽略，尾部信息丢失。
归一化偏差: 学生分布在K上重新归一化不一致 → KL估计既不无偏也不一致。长期累积→策略偏离预期。

✅ 修复: 显式"其他"类别

创建虚拟<other> token，吸收剩余概率质量P_rest。得到严格有效的(K+1)分布:

$$\hat{P}(v) = \begin{cases} P(v) & v \in \mathcal{K} \\ P_{\text{rest}} & v = \text{[other]} \end{cases}$$

学生分布同样处理→在(K+1)类上计算KL→数学严格，从根本上消除截断偏差。

🩺 失效三精讲：PI-free margin — 背答案≠学推理

⚠️ 表象与根因

表象: 训练分布内逼近教师性能，分布偏移后断崖式下跌。

根因: 学生找到了PI-free margin(策略不变安全区)。在训练分布内KL≈0，但依赖的是表面统计关联(如"看到'总共'就猜答案在最后"),非因果推理。测试分布改变→关联失效→策略崩溃。

✅ 修复: RLVR-adapt教师+SFT-warm学生

Step 1 RLVR-adapt: 用可自动验证的奖励(答案对错)对教师RL微调。教师暴露在多样化交互中→输出经环境验证的鲁棒推理链。

Step 2 SFT-warm: 用压力测试后的教师数据对学生SFT热身。学生继承的是"为何如此推理"而非"如此措辞"。

类比: 原教师=只解标准题的学霸→RLVR=参加模拟考被自动判卷纠正→SFT-warm学生=用修正笔记学习→原学生=抄作业,换题就废。

Module 1 总结与展望

OPD 的发展历程是一部"从工具到范式"的演进史。2015年，Rusu等人首次提出"在线蒸馏"概念时，蒸馏还只是训练后的模型压缩手段。短短三年内，Actor-Mimic为在线信号精炼提供了技术组件，Distral则用KL正则化和交替优化搭建了理论框架——蒸馏从此成为一种在训练中持续发生的知识传递过程。

2018-2019年的理论深化期给出了OPD最重要的数学基石。Kickstarting证明了学生可以超越教师——只要放手够早。Czarnecki的梯度场定理则揭示了一个反直觉的事实：标准的在线蒸馏在数学上并不对应任何梯度场。这一发现催生了N步未来蒸馏、教师价值加权等修正方法，将OPD从经验直觉推向了科学体系。

2020-2023年，OPD从RL的小众技术走向更广阔的舞台。DPO证明了KL约束+偏好优化的范式可以简化为优雅的分类问题，将RLHF从三模型流水线解放出来。多智能体集中训练-分散执行、机器人Sim-to-Real迁移——同一个数学结构在不同领域反复奏效。

2024-2026年，LLM革命将OPD推向了AI领域的中心。DeepSeek-R1用一个震撼的数据（蒸馏32B +25.6分超越纯RL）确立了新范式：RL发现能力，蒸馏传播能力。REOPOLD的松弛设计、PW-OPSD的位置加权、GAR的对抗推理——每一项都在解决从"蒸馏动作"到"蒸馏思维"这一根本转变中的具体瓶颈。

2026年见证了OPD从经验试错走向系统理论。2×2前缀-KL矩阵统一了四种蒸馏范式，CoPD打破了"教师必须更强"的假设开启闭环进化，UIUC的失效诊断则提供了工程落地的安全网。OPD不再是某个算法的附属品——它已成为连接RL、蒸馏、对齐、多智能体系统的通用语言。

展望：未来OPD将走向何方？多模态推理蒸馏、自蒸馏闭环系统、统一对齐-蒸馏数学框架——这些前沿方向正在被积极探索。而"子空间锁定"的发现提示我们：OPD的参数更新可能存在内在的低维结构，理解它或许是打开下一个突破的钥匙。从蒸馏动作到蒸馏思维，从经验技巧到科学体系——OPD的故事才刚刚开始。
