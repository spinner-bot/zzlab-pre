# E3 学习文档：泰坦尼克号生还预测（Kaggle 竞赛复现）

## 1. 任务
对泰坦尼克数据集进行**生还预测**，至少对比 **2 种不同类别模型**，用**网格/随机搜索调参**，生成 Kaggle 格式 `submission.csv`，并撰写技术报告。

## 2. 交付文件
```
Software_E3/
├── titanic_solution.py   完整管线（清洗->特征工程->多模型对比->网格搜索->预测）
├── data/titanic.csv      数据（train 集，891 行，含 Survived）
├── submission.csv        Kaggle 格式预测结果
└── 学习文档.md            本文档
```

## 3. 数据清洗与特征工程
- **缺失值**：`Age` 按称谓分组的**中位数**填充；`Fare`/`Embarked` 用中位数/众数填充。
- **特征工程**：
  - `Title`：从姓名提取称谓并归类（Miss/Mrs/Mr/Rare）
  - `HasCabin`：是否有客舱（0/1）
  - `FamilySize`、`IsAlone`：家庭规模与是否独行
  - 对类别列做 **one-hot**（Sex/Embarked/Title）

## 4. 模型对比（5 折交叉验证）
| 模型 | CV 准确率 |
|------|-----------|
| LogisticRegression | 0.8146 |
| RandomForest | 0.7965 |
| **GradientBoosting（最佳）** | **0.8259** |

- 选用**最优模型 GradientBoosting** 做网格搜索调参。
