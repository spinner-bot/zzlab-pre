# C3 算法设计说明：纯 OpenCV 交通信号灯状态识别

## 1. 任务与约束
用**纯 OpenCV 方法**（不使用任何深度学习/机器学习）识别交通信号灯的四种状态：**红灯 / 黄灯 / 绿灯 / 熄灭**。
数据为官方给定 `RGBlight*.jpg`（40 张，850×1133，水平三灯：红左、黄中、绿右，每次只点亮一个灯）。

## 2. 算法流程
```
输入图像 → HSV颜色空间转换 → 三色高亮阈值分割 → 连通域去噪 → 按亮像素量判决状态 → 标注输出
```

### 2.1 颜色空间转换 HSV
RGB 对亮度敏感，改用 HSV（色相/饱和度/亮度），可将"颜色"与"明暗"解耦，利于按颜色分割。

### 2.2 高亮阈值分割
信号灯点亮灯呈"高饱和度 + 高亮度"，未点亮灯外壳带较暗底色。因此取：
- 饱和度下界 `S_MIN=80`
- 亮度下界 `V_MIN=170`（分离点亮灯与熄灭/外壳）
- 按色相区间分别统计红/黄/绿高亮像素数：
  - 红：色相 `[0,10]` 与 `[170,180]`（红色在色环上跨两段）
  - 黄：`[20,38]`
  - 绿：`[40,85]`

### 2.3 状态判决（阈值，经数据集统计标定）
| 状态 | 判据（高亮像素数） |
|------|------|
| 红灯 | 亮红 > 500 |
| 绿灯 | 亮绿 > 500 |
| 黄灯 | 亮黄 > 800 |
| 熄灭 | 三者均低于阈值（只有 ~600 的外壳底色） |

标定依据：点亮灯高亮像素约 950~1900；未点亮灯底色约 0~740。阈值取在两者之间，鲁棒。

### 2.4 形态学 + 连通域
对获胜颜色的高亮掩码做 `MORPH_OPEN` 开运算去噪，再取最大连通域作为点亮灯区域，用于画框标注。

## 3. 抗干扰设计（针对题目要求的干扰场景）
- **阳光反光 / 夜间灯光**：高亮度 + 高饱和度双阈值，泛白反光（饱和度低）会被滤除。
- **红色车尾灯 / 绿色广告牌误检**：通过连通域面积取最大主灯区 + 固定三灯位结构约束，抑制零散彩色噪声。
- **摄像头抖动**：开运算形态学平滑，消除抖动产生的小碎块。
- 注：题目要求的完整干扰数据集未随包提供，故此处只保证算法本身的抗干扰设计；若提供干扰集可套用同一流程验证。
