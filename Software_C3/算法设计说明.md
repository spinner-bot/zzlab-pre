# C3 算法设计说明：纯 OpenCV 交通信号灯状态识别

## 1. 任务与约束
用**纯 OpenCV 方法**（不使用任何深度学习/机器学习）识别交通信号灯四种状态：**红灯 / 黄灯 / 绿灯 / 熄灭**。
数据为官方给定 `RGBlight*.jpg`（40 张，850×1133，水平三灯：红左、黄中、绿右，每次只点亮一个灯）。
并须构建干扰数据集验证算法抗干扰鲁棒性。

## 2. 算法流程
```
输入图像 → 信号灯ROI裁剪 → HSV颜色空间转换 → 三色高亮阈值分割 → 形态学+连通域去噪 → 按亮像素量判决状态 → 标注输出
```

### 2.1 信号灯 ROI（抗干扰关键）
摄像头固定，信号灯位于画面中央恒定区域（三灯横向排列）。将分类限制在 **ROI = x:[0.26,0.72], y:[0.18,0.50]** 内，
从而把画面边缘的红车尾灯、绿色广告牌等干扰排除在统计之外。

### 2.2 颜色空间转换 HSV
RGB 对亮度敏感，改用 HSV（色相/饱和度/亮度），把"颜色"与"明暗"解耦，便于按颜色分割。

### 2.3 高亮阈值分割
信号灯点亮灯呈"高饱和度 + 高亮度"，未点亮灯外壳带较暗底色。取 `S_MIN=80`、`V_MIN=170`，
按色相区间统计红/黄/绿高亮像素：
- 红：`[0,10]` 与 `[170,180]`（红色跨色环两段）
- 黄：`[20,38]`
- 绿：`[40,85]`

### 2.4 状态判决（阈值经数据集标定）
| 状态 | 判据（ROI 内高亮像素数） |
|------|------|
| 红灯 | 亮红 > 500 |
| 绿灯 | 亮绿 > 500 |
| 黄灯 | 亮黄 > 800 |
| 熄灭 | 三者均低于阈值（仅剩外壳底色） |

### 2.5 形态学 + 连通域
对获胜色高亮掩码做 `MORPH_OPEN` 开运算去噪，取最大连通域作为点亮灯区域并画框。

## 3. 干扰数据集与鲁棒性验证（`robustness_test.py`）
用数据增强由基准集生成 5 类干扰图，覆盖题目要求场景，再送入同一算法验证：

| 干扰场景 | 增强方式 | 识别正确率 |
|------|------|------|
| 阳光反光 | 加白色高光晕、局部提亮去饱和 | **90%** |
| 夜间 | 整体压暗、降饱和 | 20%（局限，见下） |
| 红色车尾灯误检 | 画面底部加红色发光圆点 | **100%** |
| 绿色广告牌误检 | 左上角加亮绿大块 | **100%** |
| 摄像头抖动 | 高斯模糊模拟运动模糊 | **100%** |

4/5 干扰场景稳健（≥90%）。**夜间场景局限**：整体压暗会把点亮灯亮度压到 `V_MIN=170` 以下而漏检——这是纯亮度阈值法的固有难点，可在低亮度场景配合自适应阈值/直方图均衡进一步改进。
