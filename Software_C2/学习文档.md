# C2 学习文档：YOLO 目标检测（社区人员 / 非社区人员 / 电动车）

## 1. 任务
对官方数据集中的三类目标——**社区人员、非社区人员、电动车**——进行标注并训练 YOLO 检测模型，
分析训练曲线、调参提高准确度与泛化能力。

## 2. 数据集情况（关键）
- `Software_C2/datas/people_electrocar_*.jpg` 共 **68 张**，仅含图像。
- **无现成标注文件**，需先标注（YOLO 训练必须要有边界框标签）。
- 参考标注规范图 `红色框内的是非社区人员，其余为社区人员.png`。

## 3. 完整流程（在 H200 上执行）
1. **标注**：用 LabelImg / labelme 对每张图框出三类目标，导出 YOLO 格式
   `class_id cx cy w h`（归一化），按 `data.yaml` 的 `images/train|val`、`labels/train|val` 组织。
   - 类编号：0=社区人员，1=非社区人员，2=电动车
2. **安装依赖**：`pip install ultralytics`
3. **训练**：`python train_yolo.py`（YOLOv8n，epochs=100，imgsz=640，GPU）
   → 权重存 `runs/detect/weights/best.pt`，训练曲线存 `runs/detect/`
4. **推理**：`python infer.py best.pt <图片>` → 标注结果存 `results/`
5. **分析**：查看 `runs/detect/results.png`（mAP/loss 曲线），小数据量注意过拟合，可用
   数据增强 + 迁移学习（yolov8n.pt）提升泛化。

## 4. 交付文件
```
Software_C2/
├── data.yaml         数据集与类别配置
├── train_yolo.py     YOLOv8 训练脚本（GPU）
├── infer.py          推理标注脚本
├── 学习文档.md       本文档
├── runs/detect/      训练曲线与 best.pt（训练后生成）
└── results/          推理标注结果（训练后生成）
```

## 5. 说明
本目录已提供完整可运行的 YOLO 训练脚手架；**因数据集无标注、且训练需 GPU 耗时，
实际训练与标注结果需在具备标注与 H200 环境后补全**。若时间允许可继续完成。
