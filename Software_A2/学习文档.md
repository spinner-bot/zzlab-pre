# A2 学习文档：C++ 图形类体系 Shape

## 1. 任务
用 C++ 设计 `Shape` 图形类体系：**抽象基类（至少一个纯虚函数）** + 派生类**圆形 Circle、矩形 Rectangle、三角形 Triangle**，分别计算**面积和周长**，并展现**动态绑定**。

## 2. 实现要点（`图形设计.cpp`）
- **抽象基类 Shape**：定义纯虚函数 `virtual double area() = 0` 与 `virtual double perimeter() = 0`，并给**虚析构函数**（防止派生类析构时内存泄漏）。
- **派生类**：`Circle`、`Rectangle`、`Triangle`，用 `override` 实现面积/周长：
  - 圆：`πr²` / `2πr`
  - 矩形：`w·h` / `2(w+h)`
  - 三角形：**海伦公式** `sqrt(s(s-a)(s-b)(s-c))`，`s=(a+b+c)/2`
- **动态绑定**：用基类指针数组 `Shape* shapes[] = {&c,&r,&t}` 统一遍历，调用各自重写的虚函数——运行时多态的核心体现。

## 3. 关键代码片段
```cpp
class Shape {
public:
    virtual double area() = 0;        // 纯虚函数 -> 抽象类
    virtual double perimeter() = 0;
    virtual ~Shape() {}
};
Shape* shapes[3] = {&c, &r, &t};      // 基类指针 -> 动态绑定
for (int i=0;i<3;i++) shapes[i]->area();
```

## 4. 踩坑记录
- 抽象类不能实例化，必须派生类实现所有纯虚函数。
- 基类析构函数要加 `virtual`，否则 delete 基类指针时派生类析构不被调用。
- 三角形需用海伦公式支持任意三边，但未校验是否能构成三角形（如 1,1,3 会得 NaN）。

## 5. 运行
```bash
# g++ 图形设计.cpp -o shape && ./shape
```
测试：Circle(5) 面积78.54/周长31.42；Rectangle(4,6) 面积24/周长20；Triangle(3,4,5) 面积6/周长12。
