# E1 学习文档：BP 多层感知机（numpy 实现）

## 1. 任务
不借助任何深度学习框架，仅用 numpy 手动实现**多层感知机 MLP**，拟合不同的一元/二元函数。
基于官方模板 `test.py` 完成，模板要求：
- `NeuralNetwork1D.predict(x)` 逼近 `sin(x)`（x∈[0,2π]）
- `NeuralNetwork2D.predict(x1,x2)` 逼近 `sin(x1)·cos(x2)`
- 平均绝对误差 ≤ 1e-2 判为 Success

## 2. 实现要点（`test.py`）
- 网络结构：输入层 → 隐层(128) → 隐层(128) → 输出层(1)，激活函数 `tanh`，MSE 损失。
- **反向传播**：手写链式法则求各层梯度；`tanh` 导数为 `1 - tanh²`。
- **优化器**：Adam（一阶矩/二阶矩 + 偏差修正），收敛远快于朴素批量梯度下降。
- 权重 He 初始化，输入在 `[0,2π]` 均匀采样训练。
- 训练在 `__init__` 中完成（模板 `Test` 实例化后立即测试），收敛到误差 <1e-3 或达最大轮数即停。

## 3. 关键代码
```python
# 前向
z1 = X@W1+b1; a1 = tanh(z1); z2 = a1@W2+b2; a2 = tanh(z2); out = a2@W3+b3
# 反向（链式）
gW3 = a2.T@err/N; da2 = (err@W3.T)*(1-a2**2); da1 = (da2@W2.T)*(1-a1**2); ...
# Adam 更新
m = beta1*m + (1-beta1)*g; v = beta2*v + (1-beta2)*g*g
p -= lr * m_hat/(sqrt(v_hat)+eps)
```

## 4. 遇到的问题与解决
1. **模板 `Test.output_y` 同名重载 bug**：Python 中同名方法后者覆盖前者，1D 调用会报缺 `input_x2`。改为 `output_y(*args)` 按参数个数分派到 1D/2D。
2. **朴素批量 GD 收敛慢**：20000 轮仍 >1e-2，且耗时 10 分钟。改用 Adam 后秒级收敛到 1e-3 以下。
3. 梯度维度不匹配：`db3` 用 `keepdims` 变 (1,1) 无法广播到 `b3`(1,)，去掉 keepdims 解决。
